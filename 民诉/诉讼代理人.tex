\section{诉讼代理人}
\begin{enumerate}
  \item 法定代理人。代理无诉讼行为能力人进行诉讼活动。
        \begin{enumerate}
          \item 代理权限来源于法律直接规定，不需要当事人授权。
          \item 是一种全权代理，诉讼行为效力相同。
        \end{enumerate}

  \item 委托代理人。
        \begin{enumerate}
          \item 代理权限。
                \begin{enumerate}
                  \item 一般授权：委托授权书。
                  \item 特别授权：+ 一项一项的\zd{明示授予}（否则视为一般授权）。涉及到当事人实体权利。
                        \footnote{代为承认、放弃、变更诉讼请求、和解、调解、上诉、反诉。}。
                \end{enumerate}
          \item 法律后果。
                \begin{enumerate}
                  \item 在法定范围内代理人的诉讼行为直接对被代理人发生法律效力。
                  \item 本人可以不出庭。例外：离婚必须亲去，除非不能正确表达，却有困难，书面意见。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
