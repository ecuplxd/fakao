\section{诉讼代理人}
\begin{enumerate}
  \item 法定代理人。代理\zd{无、限制诉讼行为能力人}进行诉讼活动。
        \begin{enumerate}
          \item 代理权限来源于法律直接规定，不需要当事人授权。
          \item 是一种全权代理，诉讼\zd{行为}效力相同。
        \end{enumerate}
  \item 委托代理人。取得授权。\al{法定代理人自动转为委托代理人 \cuo}。
        \begin{enumerate}
          \item 代理权限。
                \begin{enumerate}
                  \item 一般授权。委托授权书。
                  \item 特别授权。
                        \begin{enumerate}
                          \item 涉及到当事人实体权利。代为承认、放弃、变更诉讼请求、和解、调解、上诉、反诉。
                          \item 要一项一项的\zd{明示授予}，否则视为一般授权。
                        \end{enumerate}
                \end{enumerate}
          \item 法律后果。
                \begin{enumerate}
                  \item 在法定范围内代理人的诉讼行为直接对被代理人发生法律效力。
                  \item 本人可以不出庭。
                  \item 离婚必须亲去。例外。不能正确表达 + 却有困难 + \zd{书面意见}。
                        \al{甲与乙离婚后和丙再婚，后甲因中风不能自理，常年卧病在床}。
                \end{enumerate}
          \item 律师参加诉讼。执业证、律师事务所证明、授权委托书。
        \end{enumerate}
\end{enumerate}
