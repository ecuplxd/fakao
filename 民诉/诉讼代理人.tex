\section{诉讼代理人}
\begin{enumerate}
  \item 法定代理人。代理无、限制诉讼行为能力人进行诉讼活动。
        \begin{enumerate}
          \item 代理权限来源于法律直接规定，不需要当事人授权。
          \item 是一种全权代理。诉讼行为效力 \ydy 本人 \yjt 实施所有诉讼行为。
          \item 死亡问题。法律后果不一样。法代死 \yjt 换个人。当事人死 \yjt 走向不确定。
          \item 无民离婚，当事人的法代不能到庭的，法院应当在查清事实的基础上，依法作出缺席裁判。
        \end{enumerate}
  \item 委托代理人。取得授权。\al{法定代理人自动转为委托代理人 \cuo}。
        \begin{enumerate}
          \item 代理权限。
                \begin{enumerate}
                  \item 一般授权。委托授权书。
                  \item 特别授权。
                        \begin{enumerate}
                          \item 涉及到当事人实体权利。代为\zx{承认、放弃、变更诉讼请求；和解、调解；上诉、反诉}。
                          \item 要逐一明示授予，否则\zd{视为一般授权}。
                        \end{enumerate}
                \end{enumerate}
          \item 法律后果。
                \begin{enumerate}
                  \item 在法定范围内代理人的诉讼行为直接对被代理人发生法律效力。
                  \item 本人可以不出庭。离婚必须亲去。例外。不能正确表达 + 却有困难 + 书面意见。
                        \al{甲与乙离婚后和丙再婚，后甲因中风不能自理，常年卧病在床}。
                \end{enumerate}
          \item 律师参加诉讼。执业证、律师事务所证明、授权委托书。禁止外国律师以律师身份担任代理人。
        \end{enumerate}
\end{enumerate}
