\section{仲裁程序}
\begin{enumerate}
  \item 仲裁前的保全和证据保全跟诉前的保全一样；仲裁中的保全和证据保全向仲裁委申请转交\zd{法院做决定}。
  \item 仲裁庭的组成。约定 \hz 主任指定。
        \begin{enumerate}
          \item 3 名仲裁员组成合议庭。各自/\zd{共同}(选定 \hz 委托主任) \yjt 边裁 2 名/ 1 名\zd{首席仲裁员}。
          \item 1 名仲裁员独任庭。同上。
        \end{enumerate}
  \item 回避。缺人了重新选定 \hz 指定；仲裁程序要不要重新进行\zd{仲裁庭决定}。
  \item \zd{仲裁以不公开开庭审理为原则}。协议的 \yjt 书面。
  \item 结案方式。
        \begin{enumerate}
          \item 和解。可以根据和解协议\zd{制作裁决书} \hz 撤回。
          \item 调解。\zd{制作裁决书} \hz \zd{调解书}。
          \item 裁决。边裁 1 票。首裁 1.5 票。
                \begin{enumerate}
                  \item 少数服从多数是原则；\zd{无法形成多数意见}（三个人三个意见）\yjt \zd{首席仲裁员}。
                  \item 裁决书要由仲裁员\zd{签}名，对裁决\zd{持不同意见}的仲裁员\zd{可以拒绝签名}。
                  \item 1 个签名 \yjt 首席；2 个 \yjt 多数意见；3 个 \yjt 都同意。
                  \item \zd{签名要承担责任}（署名不用），不同意见我要表达怎么表达，不签对不对。
                \end{enumerate}
        \end{enumerate}
  \item 纠纷的解决，起诉还是仲裁。做题判断当事人之间\zd{有没有有效的仲裁协议}。
        \begin{enumerate}
          \item 有 \yjt \zd{应当重新申请仲裁}。
          \item 没有 \yjt \zd{重新达成仲裁协议申请仲裁} \hz 去法院起诉。
        \end{enumerate}
\end{enumerate}
