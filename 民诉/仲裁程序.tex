\section{仲裁程序}
\begin{enumerate}
  \item 仲裁前的保全同诉前的保全，直接找法院；仲裁中的保全向仲裁委申请，转交\zd{法院做决定}。
  \item 商事仲裁\zd{不存在先予执行程序}。
  \item 仲裁庭的组成。约定 > 主任指定。\al{约定由仲裁委 3 名仲裁员组成合议庭裁决}。
        \begin{enumerate}
          \item 3 名仲裁员组成合议庭。\al{甲选定 A，乙未选，甲乙也未共同选定第三名仲裁员}。
                \begin{enumerate}
                  \item 各自选定 \hz 各自委托主任指定 1 名仲裁员 \yjt 未选定 \yjt 主任指定。
                  \item 共同选定 \hz 共同委托主任指定 1 名首席仲裁员 \yjt 未选定 \yjt 主任指定。
                \end{enumerate}
          \item 1 名仲裁员独任庭。同上。
        \end{enumerate}
  \item 回避。
        \begin{enumerate}
          \item 仲裁员 \yjt 仲裁委员会主任决定；仲裁委员会主任 \yjt 仲裁委员会集体决定。
          \item 缺人了按原来程序重新选定 \hz 指定；仲裁程序要不要重新进行\zd{仲裁庭决定}。
        \end{enumerate}
  \item \zd{仲裁以不公开、开庭审理为原则}。协议不开庭的 \yjt 书面审理；协议公开 \yjt 公开，涉及国家秘密除外。
  \item 结案方式。
        \begin{enumerate}
          \item 和解。可以根据和解协议\zd{制作裁决书} \hz 撤回仲裁申请。
          \item 调解。制作\zd{调解书 \hz 裁决书}。\al{没有什么依职权调解这种说法}。
          \item 裁决。边裁 1 票，首裁 1.5 票。\zd{作出之日生效}。
                \begin{enumerate}
                  \item 少数服从多数原则，\zd{无法形成多数意见}（3 个人 3 个意见）\yjt \zd{首席仲裁员}。
                  \item 裁决书要由仲裁员\zd{签名}，\zd{持不同意见}的仲裁员\zd{可以拒绝签名}。
                  \item 1 个签名 \yjt 首席；2 个 \yjt 多数意见；3 个 \yjt 都同意。
                  \item \zd{签名即担责}（署名不用），不同意见我要表达怎么表达，不签对不对。
                  \item 裁决书应当写明仲裁请求、\zd{争议事实、裁决理由}（不写需经同意）、裁决结果、仲裁费用的负担、裁决的时间和地点。
                \end{enumerate}
        \end{enumerate}
  \item 结案后纠纷的解决，起诉 vs 仲裁。做题判断当事人之间\zd{还有没有有效的仲裁协议}。
        \begin{enumerate}
          \item 有 \yjt \zd{应当重新申请仲裁}。
          \item 没有（仲裁被否定 \yjt 无效、撤销、不予执行）\yjt \zd{重新达成仲裁协议，申请仲裁} \hz 起诉。
        \end{enumerate}
\end{enumerate}
