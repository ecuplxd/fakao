\section{仲裁程序}
\begin{enumerate}
  \item 仲裁前的保全同诉前的保全，直接找法院。仲裁中的保全向仲裁委申请，转交法院决定。
  \item 仲裁没有先予执行制度。
  \item 仲裁庭的组成。约定 \dy 主任指定。\al{约定由仲裁委 3 名仲裁员组成合议庭裁决}。
        \begin{enumerate}
          \item 合议庭。\al{甲选定 A，乙未选，甲乙也未共同选定第三名仲裁员}。
                \begin{enumerate}
                  \item 仲裁员。各自选定 \hz 各自委托主任指定 1 名 \yjt 未选定 \yjt 主任指定。
                  \item 首席仲裁员。共同选定 \hz 共同委托主任指定 1 名 \yjt 未选定 \yjt 主任指定。
                \end{enumerate}
          \item 独任庭。同上。
        \end{enumerate}
  \item 回避。
        \begin{enumerate}
          \item 仲裁员 \yjt 仲裁委员会主任决定。仲裁委员会主任 \yjt 仲裁委员会集体决定。
          \item 缺人了按原来程序重新选定 \hz 指定。仲裁程序要不要重新进行仲裁庭决定。
        \end{enumerate}
  \item 仲裁以不公开、开庭审理为原则。
        \begin{enumerate}
          \item 除涉及国家秘密外，可协议公开审理。
          \item 可依[申请 \hz 自行决定]书面审理。
        \end{enumerate}
  \item 当事人可以变更仲裁请求，仲裁庭可以拒绝。
  \item 结案方式。
        \begin{enumerate}
          \item 和解。可以根据和解协议制作裁决书 \hz 撤回仲裁申请。
          \item 调解。\al{依职权调解 \cuo 它又不是法院}。
                \begin{enumerate}
                  \item 制作调解书 \hz 裁决书。
                  \item 不要和诉讼调解混。\al{当事人、仲裁员在协议上签字后发生效力 \cuo}。
                \end{enumerate}
          \item 裁决。边裁 1 票，首裁 1.5 票。作出之日生效。\al{甲公司拒绝签收，不影响生效 \dui}。
                \begin{enumerate}
                  \item 在作出裁决前，可以先行调解。
                  \item 少数服从多数原则。无法形成多数意见（3 个人 3 个意见） \yjt 首席仲裁员。
                  \item 1 个签名 \yjt 首席。2 个 \yjt 多数意见。3 个 \yjt 都同意。
                \end{enumerate}
          \item 裁决书。
                \begin{enumerate}
                  \item 内容。应当写明请求、争议事实、裁决理由（经同意可忽略）、结果、费用负担、裁决的时间和地点。
                  \item 签名。持不同意见的可以拒绝签名 \yjt 签名即担责（署名不用）。无声的反抗。
                \end{enumerate}
        \end{enumerate}
  \item 结案后纠纷的解决。起诉 vs 仲裁。做题判断当事人之间还有没有有效的仲裁协议。
        \begin{enumerate}
          \item 有 \yjt 应当重新申请仲裁。\al{撤回仲裁 = 未经实体审理 \yjt 仲裁协议仍有效}。
          \item 没有（仲裁被否定 \yjt 被裁定无效、撤销、不予执行） \yjt \yi 重新达成仲裁协议 \yjt 仲裁。\er 去起诉。
        \end{enumerate}
\end{enumerate}
