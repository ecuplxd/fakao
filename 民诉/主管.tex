\section{主管}
\begin{enumerate}
  \item 这个案件归不归法院管。
  \item 诉讼调解。立案为界。
  \item vs 人民调解。
        \begin{enumerate}
          \item 不具有法律约束力。法律效力 \ydy 合同，只约束双方当事人。
          \item 没有强制执行力。
          \item 只能就调解协议向法院起诉 \hz 申请确认调解协议效力。不能就原纠纷起诉。
        \end{enumerate}
  \item 仲裁委员会。说仲裁一般指的是这个仲裁。
  \item \zd{劳动争议仲裁委员会}。强调了劳动仲裁么，就指的是劳动仲裁。
        \begin{enumerate}
          \item 和解、调解。\zd{劳动争议调解委员会}。
          \item 劳动纠纷仲裁前置。\zx{未经劳动仲裁直接起诉的，法院不予受理 \hz 驳回起诉}。
          \item 存在先予执行，由仲裁庭裁决，移交法院执行。
        \end{enumerate}
\end{enumerate}
