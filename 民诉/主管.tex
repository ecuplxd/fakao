\section{主管}
\begin{enumerate}
  \item 这个案件\zd{归不归法院管}。
  \item 和人民调解的关系。
        \begin{itemize}
          \item 具有法律约束力，法律效力类似于合同，约束双方当事人。
          \item \zd{没有强制执行效力}。
          \item 只能\zd{就调解协议起诉}，不能就原纠纷起诉。
          \item 可以就调解协议向法院\zd{申请确认调解协议的效力}。
        \end{itemize}
  \item 与仲裁委员会的关系。说仲裁一般指的是这个仲裁。
  \item 与劳动争议仲裁委员会的关系。强调了劳动仲裁么就指的是劳动仲裁。
        \begin{enumerate}
          \item 和解。
          \item 调解。
          \item 劳动纠纷仲裁前置 \yjt 诉讼。\zd{未经劳动仲裁直接起诉的，法院不子受理}。
        \end{enumerate}
\end{enumerate}
