\section{主管}
\begin{enumerate}
  \item 这个案件\zd{归不归法院管}。
  \item 诉讼调解。立案为界。
  \item vs 人民调解。
        \begin{enumerate}
          \item 不具有法律约束力。法律效力 \ydy 合同，只约束双方当事人。
          \item \bs{没有强制执行效力}。
          \item \bs{只能就调解协议向法院起诉 \hz 申请确认调解协议效力}。不能就原纠纷起诉。
        \end{enumerate}
  \item 仲裁委员会。说仲裁一般指的是这个仲裁。
  \item 劳动争议仲裁委员会。强调了劳动仲裁么，就指的是劳动仲裁。
        \begin{enumerate}
          \item 和解。
          \item 调解。
          \item \zd{劳动纠纷仲裁前置}。未经劳动仲裁直接起诉的，法院不子受理。
        \end{enumerate}
\end{enumerate}
