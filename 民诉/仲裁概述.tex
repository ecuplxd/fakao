\section{仲裁概述}
\begin{enumerate}
  \item 考试性价比是比较高的，每年就考两分三分，没有那么多干扰选项，那么多复杂的案情，题目相对简单。
  \item 设计的原理。为什么有人愿意去仲裁，它比诉讼有优势优势在哪里。
  \item 专业/行业领域的纠纷。专业性、效率高、保密。\zd{愿赌服输，一裁终局}。
  \item 仲裁委最低设在\zd{设区的市}\footnote{北京上海天津重庆深圳市有两个仲裁委，其他的一个城市都只有一个。}。
  \item 范围：\zd{财产纠纷}。
  \item 原则与制度：自愿原则、\zd{公平合理原则}、独立（以仲裁庭为单位独立）仲裁。
\end{enumerate}
