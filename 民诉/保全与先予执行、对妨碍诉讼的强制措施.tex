\section{保全与先予执行、对妨碍诉讼的强制措施}
\begin{enumerate}
  \item 从标的物分。
        \begin{enumerate}
          \item \zd{行为}保全。责今对方当事做出 \hz 不得做出一定的行为。\al{诉前禁令}。
          \item \zd{财产}保全。查封 \yjt 不动产。扣押 \yjt 动产。冻结 \yjt 账户。
          \item \zd{证据}保全。最迟举证期限届满前、后果就是\zx{免除相应的举证责任}。
        \end{enumerate}
  \item 从时间分。以是否受理了起诉分。\zd{是否担保，看风险大小}。
        \begin{enumerate}
          \item 诉/仲裁前保全。\bs{看到法院主动不要选}。\al{甜橙开始腐烂……法院可以主动采取保全措施，减少损失}。
                \begin{enumerate}
                  \item \yi \zd{只能依申请}。\er \zx{应当提供担保}。没起诉，法院根本不了解实际情况。
                  \item \zx{向被申请人住所地、被保全财产/证据所在地、将来对案件有管辖权的法院申请}。
                        \al{A 县甲和 B 县乙水果买卖，甲向水果仓库所在地 D 县法院申请保全}。
                  \item 必须 48 小时内裁定，30 日内起诉（保全手续移送受理法院） \hz 仲裁，否则法院\zd{裁定解除}保全。
                \end{enumerate}
          \item 诉中保全。（举证期届满前）向受案法院申请、可依职权、\zd{紧急}（法院觉得而不是当事人觉得）的 48 小时内裁定，非紧急不做要求。
          \item \sjt 需要提供担保而不提供的，裁定驳回申请。\zd{担保你瞎申请保全}。
          \item \zd{执行前的保全}。
                \begin{enumerate}
                  \item \zd{判决生效后履行期限届满前}（空档期）。
                  \item 为了\zd{方便}执行，向\zx{一审法院 \hz 与之同级的被执行财产所在地法院}。
                  \item 履行期限届满后 \zd{5} 日内申请执行，否则法院解除保全。
                \end{enumerate}
        \end{enumerate}
  \item 共同问题。
        \begin{enumerate}
          \item 保管问题。
                \begin{enumerate}
                  \item 不宜长期保存的。当事人处理 \hz 法院变卖（必须是诉中的保全） \yjt 法院提存。
                  \item \bs{保全不影响担保物权}。
                        \begin{enumerate}
                          \item 可以对抵押物、质押物、留置物保全。\zd{不影响}担保权的\zd{优先受偿权}，\zd{不需要}担保物权人\zd{同意}。
                          \item 不影响 = 实质上绝对不影响 + 形式上尽量不影响。
                        \end{enumerate}
                \end{enumerate}
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
          \item 解除与变更。\bs{错、撤、驳、超}。
                \begin{enumerate}
                  \item 保全\zd{错}误。
                  \item 申请人\zd{撤}回。
                  \item 申请起诉 \hz 诉讼请求被生效裁判\zd{驳}回。
                  \item 诉前保全后\zd{超} 30 日未申请起诉/仲裁。\al{自动解除 \cuo 解除 \bdy 自动解除}。
                \end{enumerate}
        \end{enumerate}
  \item 先予执行。可怜的人申请可怜的钱。
        \begin{enumerate}
          \item \zd{山穷水尽}。权利人已经穷的揭不开锅了、情况紧急。
          \item 当事人权力关系明确、\zd{只能依申请、担保不是必须的}、被申请人有履行能力、裁定做出后马上执行。
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
        \end{enumerate}
  \item 妨碍诉讼的强制措施。了解一下就好了。
        \begin{enumerate}
          \item 拘传。
                \begin{enumerate}
                  \item 仅适用于必须到庭的当事人。\al{具有赠养抚养抚育义务的人}。
                  \item 由院长签发拘传票。
                  \item \bs{必须是经过 2 次合法传票传唤，仍不到庭的}。
                \end{enumerate}
          \item 罚款、15 日以下拘留。决定书 + 院长批准。拘留换个词 \yjt \zd{强制措施} \yjt 仅限单位、毁证行为。
                \begin{enumerate}
                  \item 妨碍诉讼 \yjt \zd{毁灭伪造}证据、扰乱法庭秩序、打击报复司法工作人员/证人。\al{把原件烧毁 \dui}。
                  \item 妨碍执行 \yjt 转移、隐匿、变卖、毁损已经查扣冻的财产。拒不履行。拒不协助（另一相关主体，vs 配合 \yjt 人）。
                  \item 罚款。\zd{个人 10W 以下，单位 5 - 100W}。
                  \item 单位拒不协助的。对单位负责人罚款 \yjt 不履行 \yjt 可以拘留。构成犯罪的，依法\zd{追究刑事责任}。
                  \item 救济。向上级法院复议，不停止原决定的执行。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
