\section{保全与先予执行、对妨碍诉讼的强制措施}
\begin{enumerate}
  \item 从标的物分。
        \begin{enumerate}
          \item 行为保全。责今对方当事做出 \hz 不得做出一定的行为。
          \item 财产保全。查封 \yjt 不动产；扣押 \yjt 动产；冻结 \yjt 账户。
          \item 证据保全。
        \end{enumerate}
  \item 从时间分。\zd{是否担保，看风险大小}。
        \begin{enumerate}
          \item 诉/仲裁前保全。\zd{看到法院主动不要选}。\al{甜橙开始腐烂……法院可以主动采取保全措施，减少损失}。
                \begin{enumerate}
                  \item \yi \zd{只能依申请} \er 应当提供担保。没起诉，法院根本不了解实际情况。
                  \item 向被保全财产/证据所在地、被申请人住所地、将来对案件有管辖权的法院申请。
                        \al{A 县甲和 B 县乙水果买卖，甲向水果仓库所在地 D 县法院申请保全}。
                  \item 48 小时内裁定，30 天内起诉（保全手续移送受理法院）\hz 仲裁，否则法院\zd{裁定解除}保全。
                \end{enumerate}
          \item 诉中保全。可依职权；（举证期届满前）向受案法院申请；紧急的 48 小时内裁定，非紧急不做要求。
          \item \sjt 需要提供担保而不提供的，裁定驳回申请。\zd{担保你瞎申请保全}。
          \item \zd{执行前的保全}。
                \begin{enumerate}
                  \item 判决生效后履行期限届满前（\zd{空档期}）。
                  \item 为了\zd{方便}执行，向\zd{执行法院}（一审法院 \hz 与之同级的被执行财产所在地法院）申请。
                  \item 申请执行的时间 \yjt 履行期限届满后 \zd{5} 日内，否则法院解除保全。
                \end{enumerate}
        \end{enumerate}
  \item 共同问题。
        \begin{enumerate}
          \item 保管问题。
                \begin{enumerate}
                  \item 不宜长期保存的，当事人处理 \hz 法院变卖（必须是诉中的保全）\yjt 法院提存。
                  \item 可以对抵押物、质押物、留置物保全，\zd{不影响}担保权的\zd{优先受偿权}，\zd{不需要}担保物权人\zd{同意}。
                  \item \zd{保全不影响担保物权}。实质上绝对不影响 + 形式上尽量不影响。
                \end{enumerate}
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
          \item 解除与变更。
                \begin{enumerate}
                  \item 保全\zd{错}误。
                  \item 申请人\zd{撤}回。
                  \item 申请起诉 \hz 诉讼请求被生效裁判\zd{驳}回。
                  \item 诉前保全后\zd{超} 30 天未申请起诉/仲裁。
                \end{enumerate}
        \end{enumerate}
  \item 先予执行。可怜的人申请可怜的钱。救命钱。
        \begin{enumerate}
          \item 权利人已经穷的揭不开锅了、情况紧急。\zd{山穷水尽}。
          \item 当事人权力关系明确；\zd{只能依申请}；被申请人有履行能力；担保不是必须的；裁定做出后马上执行。
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
        \end{enumerate}
  \item 妨碍诉讼的强制措施。了解一下就好了。
        \begin{enumerate}
          \item 拘传。
                \begin{enumerate}
                  \item 仅适用于必须到庭的当事人。\al{具有赠养抚养抚育义务的人}。
                  \item 由院长签发拘传票。
                  \item 必须经过 \zd{2} 次合法传票传唤不到的。
                \end{enumerate}
          \item 罚款、拘留（15 天以下）。
                \begin{enumerate}
                  \item 妨碍诉讼 \yjt 毁灭伪造证据、扰乱法庭秩序、打击报复司法工作人员/证人。
                  \item 妨碍执行 \yjt 转移、隐匿、变卖、毁损已经查封、扣押、冻结的财产；拒不履行；拒不协助（另一相关主体，vs 配合 \yjt 人）。
                  \item 决定书 + 院长批准。
                  \item 罚款个人 10W 以下，单位 5W 以上 100W 以下，
                  \item 单位拒不协助的，对单位负责人罚 \yjt 不履行 \yjt 可以拘留。
                  \item 向上级法院复议，复议不停止原决定的执行。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
