\section{保全与先予执行、对妨碍诉讼的强制措施}
\begin{enumerate}
  \item 从标的物分。
        \begin{enumerate}
          \item 行为保全。责今对方当事做出 \hz 不得做出一定的行为。
          \item 财产保全。查封 \yjt 不动产；扣押 \yjt 动产；冻结 \yjt 账户。
        \end{enumerate}
  \item 从时间分。\zd{是否担保，看风险大小}。
        \begin{enumerate}
          \item 诉前的保全。
                \begin{enumerate}
                  \item \yi 只能依申请 \er 应当提供担保。没起诉，法院根本不了解实际情况。
                  \item 申请：被保全财产所在地、被申请人住所地、将来对案件有管辖权的法院。
                  \item 48 小时内裁定，30 天内起诉 \hz 申请仲裁，否则法院裁定解除保全。
                \end{enumerate}
          \item 诉讼中的保全。跟法院有关系，可以依职权；受案法院管辖；紧急的 48 小时内裁定，非紧急不做要求。
          \item \zd{执行前的保全}。
                \begin{enumerate}
                  \item 判决生效后履行期限届满前（\zd{空档期}）。
                  \item 为了\zd{方便}执行，向\zd{执行法院}\footnote{一审法院 \hz 与之同级的被执行财产所在地法院。}申请。
                \end{enumerate}
          \item 需要提供担保而不提供的，裁定驳回申请。
        \end{enumerate}
  \item 共同问题。
        \begin{enumerate}
          \item 保管问题。
                \begin{enumerate}
                  \item 不宜长期保存的（当事人处理 \hz 法院变卖）\yjt 法院保存价款。
                  \item 对抵押物、质押物、留置物可以保全，\zd{不影响担保权的优先受偿权，不需要担保物权人同意}。
                  \item \zd{保全不影响担保物权}，实质上绝对不影响 + 形式上尽量不影响。
                \end{enumerate}
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
          \item 解除与变更。
                \begin{enumerate}
                  \item 保全错误。
                  \item 申请人撤回。
                  \item 申请起诉 \hz 诉讼请求被生效裁判驳回。
                  \item 诉前保全后 30 天内未申请起诉/仲裁。
                \end{enumerate}
        \end{enumerate}
  \item 先予执行。可怜的人申请可怜的钱。救命钱。
        \begin{enumerate}
          \item 权利人已经穷的揭不开锅了、情况紧急。\zd{山穷水尽}。
          \item 当事人权力关系明确；依申请；被申请人有履行能力；担保不是必须的；裁定做出后马上执行。
          \item 对裁定不服可以申请复议，\zd{不停止}原裁定的执行。
        \end{enumerate}
  \item 妨碍诉讼的强制措施。了解一下就好了。
        \begin{enumerate}
          \item 拘传：
                \begin{enumerate}
                  \item 仅适用于必须到庭的当事人，具有赠养抚养抚育义务的人。
                  \item 由院长签发拘传票。
                  \item 必须经过 2 次合法传票传唤不到的。
                \end{enumerate}
          \item 罚款、拘留（15 天以下）。
                \begin{enumerate}
                  \item 妨碍诉讼 \yjt 毁灭伪造证据、扰乱法庭秩序、打击报复司法工作人员/证人。
                  \item 妨碍执行 \yjt 转移隐匿变卖毁损已经查封、扣押、冻结的财产；拒不履行；拒不协助。
                  \item 决定书 + 院长批准。
                  \item 向上级法院复议，复议不停止原决定的执行。
                  \item 罚款个人 10W 以下，单位 5W 以上 100W 以下，
                  \item 单位拒不协助的，对单位负责人罚 \yjt 不履行 \yjt 可以拘留。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
