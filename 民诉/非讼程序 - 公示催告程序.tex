  \item 适用于\zd{可以背书转让的票据}遗失、灭失、被盗、其他事项（新的交易工具，兜底规定）。
  \item 由票据最后持有人向票据\zd{付款地法院}申请。
  \item 受理。360。
        \begin{enumerate}
          \item 发出止付通知。支付人收到通知后应当停止支付，直至公示催告程序结束。

          \item 公示催告期间 \dydy \zd{60} 日（法院决定）。期间转让票据行为无效。
          \item 申报权利最迟到除权判决做出前。
        \end{enumerate}

          \item 一致 \yjt \zd{裁定终结}公示催告程序。
        \end{enumerate}

        \begin{enumerate}

        \end{enumerate}
\end{enumerate}
