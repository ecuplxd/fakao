\section{非讼程序 - 公示催告程序}
\begin{enumerate}
  \item 适用于可以背书转让的票据遗失、灭失、被盗、其他事项（新的交易工具，兜底规定）。
  \item 由票据最后持有人向票据付款地法院申请。
  \item 受理。
        \begin{enumerate}
          \item 发出止付通知。支付人收到通知后应当停止支付，直至公示催告程序结束。
          \item 3 日内公告。
          \item 公示催告期间 \dydy 60 日（法院决定）。期间转让票据行为无效。
        \end{enumerate}
  \item 利害关系人申报权利的 \yjt 法院进行形式审查 \yjt 通知申请人到场查验票据。
        \begin{enumerate}
          \item 形式审查。
                \begin{enumerate}
                  \item \al{实质审查、应当开庭审理 \cuo}。
                  \item \al{责令提供证明其对出示的汇票享有所有权的\xhx{证据} \cuo}。
                \end{enumerate}
          \item 处理结果。\yi 不一致 \yjt 驳回申报人的申请。\er 一致 \yjt 裁定终结公示催告程序。
        \end{enumerate}
  \item 超期的处理。申报权利最迟到除权判决作出前。
        \begin{enumerate}
          \item 公告期满后才来 \yjt 通知申请人到场查验票据 \yjt 驳回 \hz 进入除权判决。
          \item 除权判决才刀下留人 \yjt 不一致，驳回；一致，终结 \yjt 结论就是，都走到最后一步了，只能终结。
        \end{enumerate}
  \item 程序。2 个阶段。\yi 公示催告阶段 \yjt 独任制。\er 除权判决阶段 \yjt 合议制。
  \item 除权判决 3 必须。
        \begin{enumerate}
          \item 必须依申请、 必须搞合议制、 必须宣告之前的票据无效。
          \item 救济。自主观知道判决公告之日起的 1 年内向作出除权判决的法院起诉。
        \end{enumerate}
\end{enumerate}
