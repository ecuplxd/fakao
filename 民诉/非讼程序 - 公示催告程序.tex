\section{非讼程序 - 公示催告程序}
\begin{enumerate}
  \item 适用于\zd{可以背书转让}的票据遗失灭失 \hz 被盗；其他事项（新的交易工具，兜底）。
  \item 由票据最后持有人向票据支付地法院申请。
  \item 受理。
        \begin{enumerate}
          \item 应当通知支付人停止支付。
          \item 3 天内公告；
          \item 公示催告期间由法院决定不得少于 60 天。
        \end{enumerate}
  \item 效力。支付人收到通知后应当停止支付。
  \item 程序。两个阶段。\zd{公示催告阶段独任制，除权判决阶段合议制}。
  \item \zd{除权判决}。必须依申请，必须搞合议制，必须宣告之前票据无效。
  \item 救济。自知道 \hz 应当知道判决公告之日起的 1 年内向\zd{作出除权判决的法院}提起诉讼。
\end{enumerate}
