\section{非讼程序 - 公示催告程序}
\begin{enumerate}
  \item \zd{牢记特别程序是非诉程序，不解决权利义务纠纷}。
  \item 适用于\zd{可以背书转让}的票据遗失灭失 \hz 被盗；其他事项（新的交易工具，兜底）。
  \item 由票据最后持有人向票据\zd{付款地法院}申请。
  \item 受理。
        \begin{enumerate}
          \item 应当通知支付人停止支付。
          \item 3 天内公告。
          \item 公示催告期间由法院决定不得，少于 60 天。
          \item 申报权利最迟到除权判决做出前。
        \end{enumerate}
  \item 利害关系人申报权利的 \yjt 法院进行\zd{形式审查}而非实质审查（\al{组织辩论、调解、开庭、证据 ×}）\yjt 通知申请人到场查验票据。
        \begin{enumerate}
          \item 一致 \yjt 裁定终结公示催告程序。
          \item 不一致 \yjt 驳回申报人申请。
        \end{enumerate}
  \item 效力。
        \begin{enumerate}
          \item 支付人收到通知后应当停止支付，直至公示催告程序结束。
          \item 公示催告期间转让票据行为无效。
        \end{enumerate}
  \item 程序。两个阶段。\yi \zd{公示催告阶段 \yjt 独任制；\er 除权判决阶段 \yjt 合议制}。
  \item \zd{除权判决 3 必须}。必须\zd{依申请}，必须搞合议制，必须宣告之前票据无效。
  \item 救济。自知道 \hz 应当知道判决公告之日起的 \zd{1 年内向作出除权判决的法院}提起诉讼。
\end{enumerate}
