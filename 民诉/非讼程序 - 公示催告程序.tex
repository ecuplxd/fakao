\section{非讼程序 - 公示催告程序}
\begin{enumerate}
  \item 适用于\zd{可以背书转让的票据}遗失、灭失、被盗、其他事项（新的交易工具，兜底规定）。
  \item 由票据最后持有人向票据\zx{付款地法院}申请。
  \item 受理。\zx{360}。
        \begin{enumerate}
          \item 发出\zx{止付通知}。支付人收到通知后\zx{应当停止支付，直至公示催告程序结束}。
          \item \zd{3} 日内公告。
          \item 公示催告期间 \dydy \zd{60} 日（法院决定）。期间转让票据行为无效。
        \end{enumerate}
  \item 利害关系人申报权利的 \yjt 法院进行\bs{形式审查} \yjt 通知申请人到场查验票据。
        \begin{enumerate}
          \item 形式审查。
                \begin{enumerate}
                  \item \al{实质审查、应当开庭审理 \cuo}。
                  \item \al{责令提供证明其对出示的汇票享有所有权的\xhx{证据} \cuo}。
                \end{enumerate}
          \item 处理结果。\yi \zd{不一致 \yjt 驳回}申报人的申请。\er \zx{一致 \yjt 裁定终结}公示催告程序。
        \end{enumerate}
  \item 超期的处理。申报权利\zd{最迟到除权判决做出前}。
        \begin{enumerate}
          \item 公告期满后才来 \yjt 通知申请人到场查验票据 \yjt 驳回 \hz 进入除权判决。
          \item 除权判决才刀下留人 \yjt 不一致，驳回；一致，终结 \yjt 结论就是，都走到最后一步了，\zd{只能终结}。
        \end{enumerate}
  \item 程序。2 个阶段。\zx{\yi 公示催告阶段 \yjt 独任制。\er 除权判决阶段 \yjt 合议制}。
  \item 除权判决 3 必须。
        \begin{enumerate}
          \item \bs{必须依申请}、 必须搞合议制、 必须宣告之前的票据无效。
          \item 救济。自知道 \hz 应当知道判决公告之日起的 \zx{1 年内向作出除权判决的法院起诉}。
        \end{enumerate}
\end{enumerate}
