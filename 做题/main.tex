\begin{enumerate}
  \item 立场坚定、笃定、不动摇。
  \item 多选、不定项、题干过长，先瞄一眼选项，排除直接能确定错误的。
  \item 过于绝对的表述要谨慎。均、直接、只有、全部。
  \item 是在不确定，朴素的价值观很有用。
  \item 注意一些特别的表述。可以直接签订合同；有权直接要求。均、方。可直接移交。
  \item 单选选最优。
  \item 读题注意不要遗漏关键词。
  \item 碰到你不熟悉的，但其实背后肯定都是你学过的某个知识点，出题人变着法子考罢了。
  \item 不能看到某个关键词对了就选。\al{丙企业以甲国违反最惠国待遇为由起诉甲国}。
  \item 前对后错。
  \item 隐含的逻辑词。\zd{即 = 那么必然。不得 = 绝对不。应当 = 必须。须 = 必须}。
  \item 题感。要\scx{口头}征求意见；2 个工作人员\scx{自行}决定；是\scx{做决定的}根本依据。
  \item 考试关注扩号，这个括号一定是考点。
\end{enumerate}
