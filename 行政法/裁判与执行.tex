\section{裁判与执行}
\begin{enumerate}
  \item \zd{一个}行为\zd{一个}案件\zd{一种}判决。
  \item 合法。只有\zd{驳回原告诉讼请求}一种。题目信息要能明确行政行为合法、违法的信息，不然选项都是错的。
  \item 违法作为。\yi \zd{能撤就撤} \yjt \zd{不能确认}（赔偿 + 补救）。\er \zd{[行政处罚显失公正、其他行为款额有误]}可撤可变。
        \begin{enumerate}
          \item 不能。\zd{公共利益、诉讼中行为已被撤销 \hz 行政机关自己做出改变、不具有可撤销的内容}。
                \begin{enumerate}
                  \item \zd{限制人身自由已执行完毕、保护善意第三人、程序瑕疵}（不影响实体权利）\yjt \zd{确认违法}。
                  \item 无效 \yjt \zd{确认无效}。
                \end{enumerate}
          \item 撤销。
                \begin{enumerate}
                  \item 全部违法全部撤，部分违法违法撤。\al{征地 63 亩，出让 48 亩，38 亩非法}。
                  \item 需\zd{补充判决}（重做）。\zd{不履行生效判决}（一动不动）\yjt 告领导。
                  \item 和确认无效的转换（难点）。\al{甲起诉请求确认处罚无效，法院审查认为只是程序违法，可撤销，不属于无效情形，甲拒绝变更诉讼请求}。
                        \begin{enumerate}
                          \item 由低到高（升舱）。原告请求撤销，法院认为无效 \yjt 直接确认无效。
                          \item 由高到低（通知）。原告请求无效，法院认为撤销 \yjt 想变就变，不变就败（驳回诉讼请求）。
                          \item \zd{无效转来的撤销要遵守诉讼时效限制}。请求无效，认为撤销 + 过了起诉期（\zd{6} 个月）\yjt \zd{裁驳}。
                        \end{enumerate}
                  \item 和改变（\zd{全程都是复议机关}）。复议机关\zd{改变原行为}，法院\zd{判决撤销}的时候，应当\zd{责令重新做出 \hz 恢复原行为的效力}。
                  \item 和维持（难点，没考过）。诉两个、审两个、判两个（不能漏判）。
                        \begin{enumerate}
                          \item \al{原行为罚五百，复议维持}。撤销 + \zd{原机关}（干活的始终是下级）重做。
                          \item \al{原行为是不许可，复议维持}。撤销。
                          \item \al{原行为合法，复议违法}。合法部分驳回，轻微 \yjt 确认违法，不轻微 \yjt 撤销。
                          \item \al{原行为不符合复议/诉讼的受理条件，复议维持}。裁定驳回起诉。
                        \end{enumerate}
                \end{enumerate}
          \item 变更。\ydy 刑诉上诉不加刑。例外。\zd{检察院抗诉、自诉人上诉}。
        \end{enumerate}
  \item 违法不作为。\zd{履行（行为）判决、给付（给钱）判决、尚需被告调查裁量}（重新处理判决）。
        \zd{知道做啥，履行给付；不知做啥，重新处理；作无意义，确认违法}。\al{出生日期错误；苹果被抢完}。
  \item 二审判决同民诉。
  \item \zd{一审法院遗漏赔偿请求}，二审法院认为\zd{不应赔}（欺软），\zd{驳回赔偿请求}，认为\zd{要赔}（怕硬）；赔偿部分\zd{调解不了发回}。
        遗漏\zd{普通请求}同民诉\zd{（撤销原判，发回重审）}。
  \item 执行期限 \zd{2} 年。被告败诉 \yjt 从被告账上扣钱、罚款（\zd{负责人}）、公告、告状、司法拘留、追究刑事责任等。
\end{enumerate}
