\section{其他具体行政行为}
\begin{enumerate}
  \item 只要知道它是啥就得了，没有单行立法。\bs{指导、裁决、确认、给付、不作为、征收、奖励}。
  \item \zx{裁决。中立者身份}。
        \begin{enumerate}
          \item 行政机关在其行政职权范围内，对平等主体之间发生的民事纠纷进行审查并作出裁断。
          \item \zd{\ydy 判决}。\zd{2 方争议，3 方主体}。
          \item vs 确认。2 方主体，单方认定。\al{惩罚性赔偿}。
        \end{enumerate}
  \item \zx{确认。管理者身份}。对当事人的法律地位、法律关系、有关事实进行甄别，予以确定、认定、证明、宣告。
        \begin{enumerate}
          \item \bs{\ydy 公证、鉴定}。既存事实 \hz 法律关系的一种加强（上 buff）。vs 许可。\zx{给予恩赐}。
          \item 常考的。\al{交通事故责任、火灾事故、劳动伤残等级、工伤、排污不合格\xhx{认定}}。
          \item 易混的。\al{结婚登记；\xhx{初始登记是许可}、变更登记是确认；\xhx{核准是许可}、\xhx{房屋合格证}是确认}。
        \end{enumerate}
  \item 给付。\zx{给弱势群体好处}。\al{最低生活保障\xhx{金}，残疾补助金，社会保险金、养老金}。
  \item 不作为。积极的不作为\zd{明确拒绝}（\al{许可、不予许可}），消极的不作为\zd{不理不踩}（\al{到期视为默示拒绝}）。
  \item \zx{征收/征用。所有权/使用权}。\al{隔离酒店、收回国有土地使用权}。
        \begin{enumerate}
          \item \bs{带税字、费字的叫征收。不是处罚}。\al{补缴税款}。
          \item 征用一定是会给钱的，叫补偿。征收有可能是有偿的（\al{拆迁补偿}），有可能是无偿的（\al{收税}）。
        \end{enumerate}
  \item 奖励。\zd{激励先进}。赋予权利。\al{如给钱}。\zd{减免义务}。\al{如不/少纳税}。
\end{enumerate}
