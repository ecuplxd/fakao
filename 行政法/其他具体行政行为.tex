\section{其他具体行政行为}
\begin{enumerate}
  \item 什么东西难，规定的内容多的，越啰嗪的当然越难。
  \item 这\qd{其他具体行政行为}，只要知道它是啥就得了，\qd{没有单行立法}。
  \item \zd{行政确认}：\qd{对公民、其他组织的法律地位、法律关系、有关事实进行甄别，予以确定、认定、证明，予以宣告的行为}。
        \begin{enumerate}
          \item \zd{\ydy 公证、鉴定}。既存事实 \hz 法律关系的一种\qd{加强（上 buff）}。许可是\zd{给予恩赐}。
          \item 常见的。\al{交通事故责任认定、火灾事故认定、劳动伤残等级认定、工伤认定、排污不合格认定}。
          \item \zd{考行为定性}。易混。\al{结婚登记、初始登记许可/变更登记确认、核准许可/房屋合格证确认}。
        \end{enumerate}
  \item 行政裁决 \zd{\ydy 判决}。\zd{两方争议，三方主体}。确认是单方的认定。
  \item 行政给付是\zd{给好处，扶助弱势群体}。\al{最低生活保障金，残疾补助金，社会保险金}。
  \item 行政奖励是\zd{激励先进}。赋予权利如给钱；\zd{减免义务减免义务减免义务}如\al{少纳税，不纳税}。
  \item 征收（所有权）和征用（使用权，\al{隔离酒店}）。
        \begin{enumerate}
          \item \zd{带税字、费字的叫征收。不是处罚}。\al{补缴税款}。
          \item 征用一定是会给钱的叫补偿；征收有可能是有偿（拆迁补偿），有可能无偿（收税）。
        \end{enumerate}
  \item 行政不作为。积极的不作为明确拒绝（许可不予许可），消极的不作为不理不踩（到时间拟定默示拒绝）。
\end{enumerate}
