\section{社会秩序犯罪 - 妨害司法罪}
\begin{enumerate}
  \item 伪证。刑事诉讼领域；证人鉴定认定。
  \item 妨害作证。\zd{言辞证据}。三大诉讼领域；\zd{暴力、胁迫或贿买}；阻止证人作证；指使他人做伪证。
  \item 辩护人妨害作证。基本同上。
  \item 帮助毁灭、伪造证据。\zd{实物证据}。3 个动词均要扩大解释。
        \begin{enumerate}
          \item 伪造包括变造；毁灭包括隐藏（立法漏掉了）；帮助包括狭义的帮助 + 实行行为 + 教唆行为。
        \end{enumerate}
  \item 虚假诉讼。较新。
        \begin{enumerate}
          \item 提起虚假的民事诉讼，包括执行程序（扩大解释），不包括仲裁。
          \item 既遂。妨害了司法秩序。造成两个后果：开庭审理 \hz 财产保全或行为保全。
          \item 罪数。想象竞合，择一重。
                \begin{enumerate}
                  \item \al{甲超市购物小票被乙捡到，乙说这是我的，不准走，甲说有种去告我}。
                  \item \al{乙和法官合谋判甲败诉}。3 个罪。
                \end{enumerate}
        \end{enumerate}
  \item 窝藏、包庇。
        \begin{enumerate}
          \item 帮助犯罪人逃匿。广义的帮助：狭义的帮助 + 实行行为 + 教唆行为。\al{给路费}。
          \item 包庇：做\zd{假证明}帮助犯罪人逃避刑事追究 \hz \zd{获得从宽处罚}。\al{案发当天乙和我在一起}。
          \item 知情不报。\al{甲目睹了乙杀丙，民警询问，甲说，案发当天我不在家}。
        \end{enumerate}
  \item 掩饰、隐瞒犯罪所得、犯罪所得收益。保护司法机关的追赃活动，司法秩序。
        \begin{enumerate}
          \item \zd{虚拟财产（计算机数据）也能成为赃物}，犯罪工具不是；窝藏、转移、代为销售、收购。
          \item 事后参与 \yjt 帮助犯；事前参与 \yjt 上游犯罪的共犯。
          \item \zd{犯罪数额}。新考点。\yi 上游犯罪没达定罪数额，你不构成；\er \zd{销赃不看数额}。
        \end{enumerate}
  \item 脱逃罪。
        \begin{enumerate}
          \item \zd{依法被关押}的犯罪嫌疑人、被告人（未决犯、已决犯），行政/治安拘留不在内；
          \item 既遂，\zd{摆脱实际监管控制}。
        \end{enumerate}
\end{enumerate}
