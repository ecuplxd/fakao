\section{共同犯罪 - 特别问题}
\begin{enumerate}
  \item 片面的共同犯罪。以为自己在单干。
        \begin{enumerate}
          \item 观点展示。
                \begin{enumerate}
                  \item 肯定说。可以是单方面的意思联络、参与意识。
                  \item 否定说。必须是相互的。
                \end{enumerate}
          \item 类型。
                \begin{enumerate}
                  \item 片面帮助 \yjt 肯定说。
                  \item 片面教唆 \yjt 肯定说。
                  \item 片面实行 \yjt 否定说。
                \end{enumerate}
        \end{enumerate}
  \item 共犯与身份。
        \begin{enumerate}
          \item \zd{分别分析 + 想象竞合}。\al{投保人和保险经理一起合谋骗钱}。
          \item 传统。两个人构成共同犯罪，一定要最终定同一个罪名。
        \end{enumerate}
        \input{draw/特别问题.tex}
  \item 共犯与不作为犯。
        \begin{enumerate}
          \item 步骤。
                \begin{enumerate}
                  \item 先把作为义务人找出来。\zd{有些作为义务人不好找}。考的先行行为（有没有陷入危险状态）。
                  \item 再找没有作为义务的人。
                  \item 再看他们的行为。实行行为、教唆 \hz 帮助。
                \end{enumerate}
          \item 案例。
                \begin{enumerate}
                  \item \al{甲高位截瘫多年，其妻乙不经困扰，让丙小推车丢到路边}。
                  \item \al{甲高位截瘫多年，丙对其不可言说，其妻乙站在门口视而不见}。
                  \item \al{甲乙一起打伤丙女，此时乙欲行苟且之事，甲不阻止}。
                \end{enumerate}
        \end{enumerate}
  \item 共同犯罪和实行过限。\al{甲和乙一起实行 A 罪，乙多实行了 B 罪}。判断。有没有\zd{超出共同故意}的范围。
        \begin{enumerate}
          \item \al{甲乙盗窃小芳，甲在客厅，乙在卧室偷，强奸了小芳}。
          \item \al{甲教唆乙盗窃小芳，乙不仅实施了盗窃还进行了强奸}。
          \item \al{甲雇乙去教训丙，嘱咐不要弄死，丙反抗，乙杀之}。甲 \yjt 故意伤害 + 过失致人死亡 \yjt 法律拟制。
          \item \al{乙要盗窃丙女，嘱咐甲帮忙望风，乙盗窃过程中还顺便强奸了丙女}。
        \end{enumerate}
  \item 共同犯罪和认知错误的结合。难度很大。但没有新的知识点。
        \begin{enumerate}
          \item \al{甲乙欲杀博物馆的丙，各开一枪，甲打中了花瓶，乙啥都没打中}。
          \item \al{甲教唆乙杀害丙，丙照片给乙，嘱咐不要杀错人了，结果还真杀错了}。
        \end{enumerate}
  \item 教唆犯和间接正犯之间产生认识错误。\zd{一律定教唆犯}。
        \begin{enumerate}
          \item \al{甲让乙去杀丙，不知乙是精神病患者，乙果杀之}。
        \end{enumerate}
  \item 共犯人成为被害人。
        \begin{enumerate}
          \item \al{甲想盗窃丙的渔网，让乙提供工具。甲到海边，没看到丙的渔网，把旁边乙的渔网拿走了}。
          \item \al{乙女教唆甲男强奸室友丙女，结果当天丙女不在，甲误把乙女当丙女进行了强奸}。
        \end{enumerate}
\end{enumerate}
