\section{分论概说}
\begin{enumerate}
  \item 侵害个人、财产、国家法益。\zd{人、财、公、经、社、贪、渎}。
        \begin{enumerate}
          \item \zd{财产}，6 大罪名。
          \item \zd{人身}。
          \item \zd{贪污贿赂} \sjt 一半分值，抓大放小。
          \item 危害公共安全、经济、社会秩序、渎职。
        \end{enumerate}
  \item 选择性罪名。
        \begin{enumerate}
          \item 打顿号的罪名。可以拆分使用，也可以整体使用。
          \item 选择性罪名的认识错误是同一犯罪构成内的错误。\al{非法制造、买卖、运输、邮寄、储存枪支、弹药、爆炸物。买的枪，寄的子弹}。
          \item 非选择性罪名的认识错误是不同犯罪构成间的错误。\al{生产、销售、提供假药/生产、销售、提供劣药。主观卖假药，客观卖劣药}。
        \end{enumerate}
  \item 罪状。
        \begin{enumerate}
          \item 简单罪状。
          \item 叙明罪状。描述的很详细。
          \item 引证罪状。引用前款。内部。
          \item 空白罪状。援引刑法\zd{外部}。
        \end{enumerate}
  \item 注意规定。正常办事，重复强调。携带挪用的公款潜逃定贪污。法官注意哦，看到这种情况要定贪污。
  \item 法律拟制。特事特办。常考。
        \begin{enumerate}
          \item \zd{拟制的抢劫}。\al{事后转化抢劫、携带凶器抢夺、聚众打砸抢过程中毁坏/抢夺财物}。
          \item \zd{拟制的故意杀人}。\al{非法拘禁、刑讯逼供、暴力取证、虐待被监管人、聚众斗殴、故意伤害}。
        \end{enumerate}
  \item 一些动、名词的解释。
        \begin{enumerate}
          \item 买卖 = 买 + 卖。\zd{2 个行为}。
                \begin{enumerate}
                  \item 有偿（物物、钱物交易均可）。
                  \item 买。为自己使用而买进、为卖出而买进。
                  \item 卖。单纯的卖出、先买进后卖出（转卖）。
                  \item 除了毒品、枪支弹药，原则只处罚销售者，不处罚购买者 \yjt 购买者不是销售者的帮助犯。
                  \item vs 贩卖。只有卖构成。
                \end{enumerate}
          \item 生产。销售目的（\zd{非自用}）。
          \item 销售。\zd{\bdy 捐赠}。
          \item 财物。有体、无体/虚拟、财产性利益、债权、股票、应收款、罚款等。要有\zd{经济价值}。
        \end{enumerate}
  \item 正犯化的含义。（定罪量刑时）不再适用总则关于从犯/预备犯的规定。
  \item 做题小技巧。\zd{找法益、找主体、找行为、找对象}。
        \begin{enumerate}
          \item 看到\zd{环境}丢给社会秩序犯罪 - 环境犯罪。
          \item 看到\zd{食品}丢给经济犯罪 - 食品犯罪。
          \item 问自己\zd{主体对不对、对象对不对}。\al{缉毒警察掩护、包庇走私毒品的犯罪分子，构成放纵走私罪}。
          \item \al{\scx{聚众锯断高速公路}隔离栏，\scx{成立聚众扰乱交通}秩序\scx{罪}}。
          \item \al{\scx{甲将纯净水掺入到}工业酒精\scx{中，冒充白酒销售。
                    甲的行为不属于“在生产、销售的食品中掺入有毒、有害的非食品原料”，
                    不成立生产、销售}有毒、有害\scx{食品罪}}。
          \item \al{\scx{甲从山林间拾得许多蘑菇，明知是}毒蘑菇\scx{还卖给别人，其行为构成销售}有毒、有害\scx{食品罪}}。
        \end{enumerate}
\end{enumerate}
