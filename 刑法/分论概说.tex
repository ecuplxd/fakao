\section{分论概说}
\begin{enumerate}
  \item 侵害个人、财产、国家法益。
        \begin{enumerate}
          \item \zd{财产}，6 大罪名。
          \item \zd{人身}。
          \item \zd{贪污贿赂} \sjt 一半分值，抓大放小。
          \item 危害公共安全、经济、社会秩序、渎职。
        \end{enumerate}
  \item 选择性罪名。打顿号的罪名。罪数问题；认识错误。
  \item 罪状：
        \begin{enumerate}
          \item 简单。
          \item 叙明。描述的很详细。
          \item 引证。引用前款。内部。
          \item 空白。援引刑法\zd{外部}。
        \end{enumerate}
  \item 注意规定。正常办事，重复强调。携带挪用的公款潜逃定贪污罪。法官注意哦，看到这种情况要定贪污罪。
  \item 法律拟制。特事特办。常考。
        \begin{enumerate}
          \item 拟制的抢劫罪。事后转化抢劫、携带凶器抢夺、聚众打砸抢过程中毁坏、抢夺财物。
          \item 拟制的故意杀人罪。非法拘禁、刑讯逼供、暴力取证、虐待被监管人、聚众斗殴的过失致人死亡。
        \end{enumerate}
\end{enumerate}
