\section{危害公共安全罪 - 恐怖型、枪支类犯罪}
\begin{enumerate}
  \item 恐怖型犯罪。和黑社会组织区分，理想是否远大（政治目的）。
        \begin{enumerate}
          \item 领导、组织、参加恐怖组织罪。
          \item 帮助恐怖活动。帮助行为单独处理，\zd{帮助行为正犯化}，加大打击力度。\al{谎称自己是中国军队里工程师}。
          \item 准备实施恐怖活动。\zd{准备行为正犯化}。
        \end{enumerate}
  \item 枪支类犯罪。掌握名词、动词即可。
        \begin{enumerate}
          \item 枪支的认定，标准很低，动能很低。每平方厘米 1.8 焦耳。主要是为了安全。
          \item 动词。\zd{买卖}可以拆开，包括买、卖，买卖一进一出俩行为。物物、钱物交易均可。\al{甲拿枪换乙的毒品}。
                \begin{enumerate}
                  \item 盗窃、抢夺枪支、弹药、爆炸物、危险物质。危险犯，不要求造成严重后果；既遂是取得。
                  \item 非法持有、私藏枪支、弹药。
                  \item 非法出租、出借枪支。单位和个人；永久性 \yjt 非法买卖枪支；出借扩大解释（赠予）。
                  \item 丢失枪支不报。公务用枪；非自愿失去；真正不作为犯；故意。
                  \item 非法制造、买卖、运输、邮寄、储存枪支、弹药、爆炸物。
                  \item 非法制造、买卖、运输、存储危险物质。
                \end{enumerate}
          \item 选择性罪名，对象认识错误，看客观，客观是啥定啥。\al{买的枪，寄的子弹}。
        \end{enumerate}
  \item 安全生产领域。
        \begin{enumerate}
          \item 重大责任事故 \yjt 操作、作业有问题；重大劳动安全事故 \yjt 设备、条件有问题。
          \item 危险作业。具体危险犯；故意犯罪。打击提前；实害结果 \yjt 重大责任事故。
          \item 强令、组织他人违章冒险作业。过失犯罪。
        \end{enumerate}
\end{enumerate}
