\section{危害公共安全罪 - 恐怖型、枪支类犯罪}
\begin{enumerate}
  \item 恐怖型犯罪。vs 黑社会组织。理想是否远大（政治目的）。
        \begin{enumerate}
          \item 领导、组织、参加恐怖组织。
          \item 帮助恐怖活动。\zd{帮助行为正犯化}，加大打击力度。\al{谎称自己是中国军队里工程师}。
          \item 准备实施恐怖活动。\zd{准备行为正犯化}。\al{准备凶器}。
        \end{enumerate}
  \item 枪支类犯罪。掌握名词、动词即可。
        \begin{enumerate}
          \item 枪支的认定。标准很低，1.8 J/cm²。主要是为了安全。
          \item 动词。\al{甲拿枪换乙的毒品}。
                \begin{enumerate}
                  \item 盗窃、抢夺枪支、弹药、爆炸物、危险物质。抽象危险犯、取得既遂。
                  \item 非法持有、私藏枪支、弹药。
                  \item 非法出租、出借枪支。单位和个人、出借扩大解释（\al{赠与}）、永久性出租/借 \yjt 非法买卖枪支。
                  \item 丢失枪支不报。真正身份犯、\zd{公务用枪}、非自愿失去、真正不作为、故意。
                  \item 非法制造、买卖、运输、邮寄、储存枪支、弹药、爆炸物。
                  \item 非法制造、买卖、运输、存储危险物质。
                \end{enumerate}
        \end{enumerate}
  \item 安全生产领域。\bs{凡是说发生事故，都是过失}。\zd{责任事故 vs 安全事故。危险 vs 冒险}。
        \begin{enumerate}
          \item 重大\zd{责任事故}。操作、作业有问题。\zd{人的问题}。
          \item 重大劳动\zd{安全事故}。设备、条件有问题。\zd{非人的问题}。
          \item 危险作业。具体危险、故意犯罪。vs 重大责任事故（打击提前、实害结果）。
          \item 不报、谎报安全事故。
          \item 危险物品肇事。违规使用危险品。
          \item 强令、组织他人违章冒险作业。过失犯罪。
          \item 组织违章\zd{冒险}作业。过失。
        \end{enumerate}
\end{enumerate}
