\section{刑罚的体系}
\begin{enumerate}
  \item 刑事责任的承担方式。
        \begin{enumerate}
          \item 刑罚措施。
                \begin{enumerate}
                  \item 主刑。只能独立适用，不能附加适用。一个罪只有一个主刑。管、拘、有、无、死。
                        \begin{enumerate}
                          \item 管制 \yjt 限制自由刑（不关押）。[3 月, 2 + 1]。
                          \item 拘役 \yjt 短期自由刑。[1 月, 6 月 + 1]。
                          \item 有期、无期 \yjt 长期自由刑。
                          \item 死刑（死立执 + 死缓） \yjt 生命刑。不适用于未成年/\zx{孕妇}、75 岁。\zd{犯罪时/审判时（扩大解释）}。
                        \end{enumerate}
                  \item 附加刑罚。
                        \begin{enumerate}
                          \item 罚金。
                          \item 没收财产。个人 + 合法 + 所有；和罚金不是一个性质的。
                          \item 剥夺政治权力。一般 1 - 5 年。
                          \item 驱逐出境。
                        \end{enumerate}
                \end{enumerate}
          \item 非刑罚处罚措施。
                \begin{enumerate}
                  \item 禁止令。仅适用管制和缓刑（不关押）、不能影响日常基本生活、执行之日起算。
                  \item 职业禁止。刑罚执行完毕 \hz 假释之日起算、期限不定、可能构成拒不执行判决/裁定罪。
                  \item 追缴违法所得/责令退赔。财务本身及孳息、没收犯罪工具（属本人）。
                \end{enumerate}
          \item 单纯宣告有罪。
        \end{enumerate}
\end{enumerate}
