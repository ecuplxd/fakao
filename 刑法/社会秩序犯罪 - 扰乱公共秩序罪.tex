\section{社会秩序犯罪 - 扰乱公共秩序罪}
\begin{enumerate}
  \item 罪名特别多，知识点杂乱，某些罪名的某些要点。
  \item 妨害公务。
        \begin{enumerate}
          \item 主观故意；\zd{依法 + 正在}执行的公务；\al{袭击上班的警察}。
          \item 认识错误。
                \begin{enumerate}
                  \item \al{甲看到朋友乙和丙在打架，上前帮忙将丙打成轻伤，丙其实是便衣警察}。故意伤害罪。
                  \item \al{甲误以为丙在追杀乙，重伤乙，丙其实是便衣警察}。甲假想防卫，过失致人重伤。
                \end{enumerate}
          \item 罪数。原则结合犯。前罪 + 此罪 = 数罪并罚。
                \begin{enumerate}
                  \item 例外,走私、贩卖、运输、制造毒品，组织、运送偷越国（边）境。前罪 + 此罪 = 此罪加重处罚。
                \end{enumerate}
        \end{enumerate}
  \item 袭警。
        \begin{enumerate}
          \item 行为方式\zd{只包括暴力袭击，不包括暴力相威胁}。\al{拿把菜刀威胁民警，吓跑了}。
          \item \zd{警察本人，警犬不算}。
        \end{enumerate}
  \item 公文、证件、印章犯罪。
        \begin{enumerate}
          \item \zd{伪造}、变造、\zd{买卖}国家机关公文、证件、印章。
                \begin{enumerate}
                  \item 伪造。有形\blh \yjt \zd{无制作权限的人制作}；无形\blh \yjt 有权限的人。\al{收买警察办户口}。
                  \item 买卖 \yjt 买 + 卖 都构成；贩卖 \yjt 只有卖构成。
                \end{enumerate}
          \item 伪造公司、企业、事业单位、人民团体印章。只有伪造，弱保护。\al{伪造大学毕业证}，毕业证要盖大学印章，伪造了印章图案，
          \item 伪造、变造、买卖身份证件。特殊的国家证件，独立出来；\zd{身份证、护照、驾驶证、社会保障卡}。
          \item 盗窃、抢夺、毁灭国家机关公文、证件、印章。
          \item 冒名顶替。新罪。\zd{上大学的资格，罗彩霞；公务员录用；就业安置的待遇}。
        \end{enumerate}
  \item “小混混”型犯罪。
        \begin{enumerate}
          \item 招摇撞骗。
                \begin{enumerate}
                  \item \zd{冒充的必须是国家机关工作人员}，一般人相信。
                  \item 骗啥都可以，感情、名誉、钱财（\zd{和诈骗想象竞合择一重}）、色。
                \end{enumerate}
          \item 聚众斗殴。\zd{（过失）致人重伤死亡拟制为故意杀人}；首要分子不分阵营。
          \item 寻衅滋事。\zd{和若干罪不是排斥对立关系，可以想象竞合，择一重}；不是结果加重犯。
          \item 聚众扰乱社会秩序。
          \item \zd{高空抛物罪}。新罪。
                \begin{enumerate}
                  \item 高度要求，\zd{2 层楼，3m 左右}；井里有人扔也算，空对地，垂直位移。
                  \item \zd{故意，高空坠物是过失}。
                \end{enumerate}
        \end{enumerate}
  \item “大哥型”犯罪。
        \begin{enumerate}
          \item 组织、领导、参加黑社会性质组织。
                \begin{enumerate}
                  \item 有组织；要有一定的经济实力；进行违法犯罪活动；形成非法控制（这地方我说了算）。
                  \item 参加。进去后\zd{得干点违法犯罪活动}。
                  \item 责任划分。“主营业务” \yjt 组织罪行；“主营业务外” \yjt 个人罪行。
                \end{enumerate}
          \item 赌博。
          \item 开设赌场。\zd{赌博要求有输有赢}；微信抢红包具体情况分析。
          \item 虚假物质、信息罪。
        \end{enumerate}
  \item 考试作弊类犯罪。
        \begin{enumerate}
          \item 组织考试作弊。有档次的考试。
          \item 非法出售、提供试题、答题。
          \item 代替考试。
        \end{enumerate}
  \item 计算机犯罪。
        \begin{enumerate}
          \item 非法\zd{侵入}计算机信息系统。\zd{国家事务、国防建设}；登录访问；强保护。
          \item 非法获取计算机信息系统数据。
          \item \zd{破坏}计算机系统。除了国家、国防的，也包括民营公司的。弱保护。
          \item 非法控制计算机系统。
          \item 非法利用信息网络。可以和 n 多罪想象竞合，\al{在网上发贩毒信息}。
          \item 帮助信息网络犯罪活动。帮信罪。
                \begin{enumerate}
                  \item 可以和 n 多罪想象竞合，\al{甲明知乙实施网络诈骗，仍为其提供网络接入服务}。
                  \item 虽然是独立罪名，成立还是要严格遵循共犯从属性。\al{实际乙并未去诈骗}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
