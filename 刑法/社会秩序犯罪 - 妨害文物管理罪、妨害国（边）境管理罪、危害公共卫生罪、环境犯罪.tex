\section{社会秩序犯罪 - 妨害文物管理罪、妨害国（边）境管理罪、危害公共卫生罪、环境犯罪}
\begin{enumerate}
  \item 妨害文物管理罪。
        \begin{enumerate}
          \item 倒\zd{卖}文物。不要求是二道分子，买进 + 卖出，偷来 + 卖出，只看卖出去了。
                \begin{enumerate}
                  \item 数罪并罚。买入或者偷来，侵犯旧法益，卖出侵犯新法益。
                  \item \zd{没有盗窃文物罪 \yjt 定盗窃}。
                \end{enumerate}
          \item 盗掘古墓葬。法定刑升格 \yjt 盗窃所掘起的文物、损毁文物。
        \end{enumerate}
  \item 组织、运送他人偷越国（边）境。
        \begin{enumerate}
          \item \zd{越过边境线既遂}。
          \item 结合犯。本罪 + 非法拘禁、本罪 + 妨害公务 = 本罪加重处罚。其他数罪并罚。
        \end{enumerate}
  \item 危害公共卫生罪。第 2 轮 20 - 30 小时，第 3 轮 6 - 10 小时。
        \begin{enumerate}
          \item 医疗事故。过失犯罪。
          \item 非法行医。
                \begin{enumerate}
                  \item \zd{不是在职执业医师}。
                  \item 职业犯。反复、持续实施。
                  \item 医疗活动，\zd{保健活动不算}。
                  \item 结果加重犯。过失致人死亡。
                \end{enumerate}
          \item 妨害传染病防治。故意犯罪。\al{我得知道我是阳性}。
        \end{enumerate}
  \item 环境犯罪。
        \begin{enumerate}
          \item 针对林木的犯罪。
                \begin{enumerate}
                  \item 盗伐林木。A + B。
                        \begin{enumerate}
                          \item \zd{财产 + 还破坏了生态环境}。\al{枯死的树}。2 立方，100+。
                          \item 扩大解释。手段不限于砍伐。
                          \item 采种、剥树皮等行为 + 树木死亡 \yjt 盗伐林木。
                        \end{enumerate}
                  \item 滥伐林木。B。只\zd{破坏了生态环境}，\zd{滥伐自己的林木的也算}。10 - 20，幼树 500+
                \end{enumerate}
          \item 危害珍贵、濒危野生动物。不要求在野外；猎捕、杀害、收购、运输；武松打虎，无罪，紧急避险。
          \item 污染环境。故意犯罪、实害犯、和投放危险物质想象竞合。\al{向土地大量排放危险废物}。
        \end{enumerate}
\end{enumerate}
