\section{客观要件 - 因果关系}
\begin{enumerate}
  \item 解决实害结果的归属问题。先因后果！因 \yjt 介入因素 \yjt 果 \yjt 无法查明。考的最多的。
  \item 分类。
        \begin{enumerate}
          \item \bs{条件说}。\zx{“无 A 则无 B”的条件关系}。\al{放火与死亡}。
          \item \bs{相当因果说}。\zx{行为与结果之间具有相当性} \yjt
                看介入因素发生是否异常 \yjt
                异常 \yjt
                不具有相当性，没有因果关系（过于绝对）。
                \al{大阪南港案 \yjt 二因一果}。
          \item \zd{危险的现实化原理}。\bs{2 步走}。
                \begin{enumerate}
                  \item 不异常 \yjt 有引发关系则有因果关系。
                  \item 介入因素异常（独立关系） \yjt 谁的作用更大（先前、介入、都大）。
                \end{enumerate}
        \end{enumerate}
  \item 因。即判断是不是一个危害行为。很喜欢考\zx{追捕行为}。
        \begin{enumerate}
          \item \zx{没有对法益制造危险}。\al{小偷跑主人追 \dui。主人跑小偷追 \cuo}。
          \item 对法益制造了危险，但“危害”行为并非法律所禁止的。\al{警察追小偷、开车上路 \dui}。
          \item \zd{介入被害人的过失行为，仅有条件关系}。
        \end{enumerate}
  \item 介入因素。
        \begin{enumerate}
          \item 被害人自身行为。被害人自杀。常考。
                \begin{enumerate}
                  \item \al{甲为讨债拘禁乙，乙深感无力还债自杀}。
                  \item 没有因果关系，但有条件关系，算造成其他严重后果加重处罚。\al{强奸后，羞愤自杀}。
                  \item 2 个例外。暴力干涉婚姻自由致人死亡、虐待致人死亡包括被害人自杀。
                \end{enumerate}
          \item \zx{被害人特殊体质}。结论。先行行为对疾病的发作\zx{有引发关系}则有因果关系。\al{街上推人}。
          \item 第三人行为。
                \begin{enumerate}
                  \item \zx{阻断救助行为}。结论。如果救助行为有救活可能性，结果就算到阻断行为上。
                        \begin{enumerate}
                          \item \al{甲推乙入水，丙扔救生圈，被\xhx{丁捞走}}。
                          \item \al{乙驾车撞伤丙，\xhx{甲谎称自己留下}打电话叫救护车，让乙赶紧将车开走}。
                          \item \al{宗教迷信，\xhx{拒绝}输血}。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 果。实害结果 = 事实判断 + \bs{价值评价（一定得是坏结果）}。
        \begin{enumerate}
          \item 不讨论假设的结果。要现实发生的。\al{沙漠钻孔案}。
          \item 管辖范围内的结果。\al{德国交警尾灯案}。
          \item 是刑法规范保护范围内的结果。
                \begin{enumerate}
                  \item 罪名规范范围。实害结果不应超出该罪名所能保护的法益范围。\al{甲杀乙后逃走，丙路过取财}。
                  \item （过失犯罪的）注意义务规范范围。不应超出该罪名所要注意的义务范围。
                        \al{车进隧道超速撞到人 \yjt 注意义务是不要和前车追尾，被害人自陷风险}。
                \end{enumerate}
          \item 重叠的因果关系。A + B \yjt C。
          \item 择一的因果关系。A \hz B \yjt C。
        \end{enumerate}
  \item 无法查明。共犯部分实行，全部负责。时间无法查明，死的越早越好（存疑时有利于被告）。
\end{enumerate}
