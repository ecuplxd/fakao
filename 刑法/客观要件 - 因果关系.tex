\section{客观要件 - 因果关系}
\begin{enumerate}
  \item 考的最多的。解决实害结果的归属问题。
  \item 因。即判断是不是危害行为。
  \item 果。实害结果 = 事实判断 + 价值评价（坏的）。
        \begin{enumerate}
          \item 现实发生的，\zd{不讨论假设的结果}。\al{沙漠钻孔案}。
          \item 重叠的因果关系。A + B \yjt C
          \item 双重择一的因果关系。A \hz\, B \yjt C
          \item \zd{规范保护范围}。实害结果不超出该罪名所能保护的法益范围。\al{甲杀乙后逃走，丙路过取财}。
          \item 管辖范围内。\al{德国交警尾灯案}。
        \end{enumerate}
  \item 关系分类。
        \begin{enumerate}
          \item 条件说：行为与结果即使有必要条件关系，也不意味着有因果关系。
          \item 相当因果说：看介入因素发生是否异常。\al{大阪南港案}（\zd{二因一果}）。
          \item 危险的现实化原理。介入因素异常 \yjt 独立关系 \yjt 谁的作用更大。
        \end{enumerate}
  \item 介入因素种类：
        \begin{enumerate}
          \item 被害人自身行为。
                \begin{enumerate}
                  \item 被害人自杀（常考）。
                        \begin{enumerate}
                          \item \al{甲为讨债拘禁乙，乙深感无力还债自杀}。
                          \item \al{强奸后，羞愤自杀}，虽然没有因果关系，但有条件关系，算其他严重后果，加重处罚。
                        \end{enumerate}
                  \item 例外：暴力干涉婚姻自由致人死亡、虐待致人死亡包括被害人自身。
                \end{enumerate}
          \item 第三人行为。
                \begin{enumerate}
                  \item \zd{阻断救助行为}。如果救助行为有救活可能性，结果就算到阻断行为上。
                        \begin{enumerate}
                          \item \al{甲推乙入水丙扔救生圈被丁捞走}。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{被害人特殊体质}。有\zd{引发关系}则有因果关系。
        \end{enumerate}
  \item 无法查明。
        \begin{enumerate}
          \item 一个人/无法查明死亡时间。存疑时有利于被告，\zd{死的越早越好}。
          \item 两个人。\al{甲乙枪杀丙，无法查明哪颗子弹打中}。
                \begin{enumerate}
                  \item 构成共同犯罪的。\zd{部分实行全部负责}。
                  \item 不构成。单独处理。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
