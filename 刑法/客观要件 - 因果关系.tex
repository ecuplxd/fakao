\section{客观要件 - 因果关系}
\begin{enumerate}
  \item 解决实害结果的归属问题。考的最多的。
  \item 分类。
        \begin{enumerate}
          \item 条件说。行为与结果即使有必要条件关系，也不意味着有因果关系。
          \item 相当因果说。看介入因素发生是否异常。\al{大阪南港案 \yjt 二因一果}。
          \item \zd{危险的现实化原理}。介入因素异常 \yjt 独立关系 \yjt 谁的作用更大。
        \end{enumerate}
  \item \zd{\blx{先因后果}}。
  \item 因。即判断是不是一个危害行为。\zd{追捕行为很喜欢考}。
        \begin{enumerate}
          \item 没有对法益制造危险。\al{小偷跑主人追 \dui，主人跑小偷追 \cuo}。
          \item 对法益制造了危险，但“危害”行为并非法律所禁止的。\al{警察追小偷、开车上路 \dui}。
        \end{enumerate}
  \item \kd{介入因素}。
        \begin{enumerate}
          \item 被害人自身行为。\zd{被害人自杀}。常考。
                \begin{enumerate}
                  \item \al{甲为讨债拘禁乙，乙深感无力还债自杀}。
                  \item 没有因果关系，但有条件关系，算其他严重后果进行加重处罚。\al{强奸后，羞愤自杀}。
                  \item 例外。\al{暴力干涉婚姻自由致人死亡、虐待致人死亡包括被害人自杀}。
                \end{enumerate}
          \item 第三人行为。
                \begin{enumerate}
                  \item \zd{阻断救助行为}。结论。\zd{如果救助行为有救活可能性，结果就算到阻断行为上}。
                        \begin{enumerate}
                          \item \al{甲推乙入水，丙扔救生圈，被\xhx{丁}捞走}。
                          \item \al{乙驾车撞伤丙，甲谎称自己留下打电话叫救护车，让乙赶紧将车开走}。
                          \item \al{拒绝输血}。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{被害人特殊体质}。结论。\zd{先行行为对疾病的发作有引发关系则有因果关系}。\al{砸人一圈}。
        \end{enumerate}
  \item 果。实害结果 = 事实判断 + 价值评价（坏的）。
        \begin{enumerate}
          \item \zd{不讨论假设的结果}。要现实发生的。\al{沙漠钻孔案}。
          \item \zd{是规范保护范围内的结果}。
                \begin{enumerate}
                  \item 罪名规范范围。实害结果\zd{不应超出该罪名所能保护的法益范围}。\al{甲杀乙后逃走，丙路过取财}。
                  \item （过失犯罪的）注意义务规范范围。\zd{不应超出该罪名所要注意的义务范围}。
                        \al{车进隧道超速撞到人 \yjt 注意义务是不要和前车追尾，被害人自陷风险}。
                \end{enumerate}
          \item 管辖范围内的结果。\al{德国交警尾灯案}。
          \item 重叠的因果关系。A + B \yjt\, C。
          \item 双重择一的因果关系。A \hz\, B \yjt\, C。
        \end{enumerate}
  \item 无法查明。除了\zd{共犯部分实行全部负责，其余死的越早越好}（存疑时有利于被告）。
\end{enumerate}
