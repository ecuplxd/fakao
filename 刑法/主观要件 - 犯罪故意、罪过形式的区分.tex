\section{主观要件 - 犯罪故意、罪过形式的区分}
\begin{enumerate}
  \item 犯罪故意。明知故犯，\zd{希望或者放任}。
        \begin{enumerate}
          \item vs 生活中的故意、行政上的故意。
                \begin{enumerate}
                  \item \al{甲夜里为了盗窃仓库的物品，火柴照明}。
                  \item \al{闯红灯}。
                \end{enumerate}
          \item 主客观相一致。主观认识和实际发生要相一致。
                \begin{enumerate}
                  \item 行为对象相一致。
                        \begin{enumerate}
                          \item \al{不识字狗蛋卖书籍，不知里面是淫秽色情}。
                          \item \al{窝藏包庇罪}。
                        \end{enumerate}
                  \item 派生 \yjt \zd{客观决定主观原则}。一个要素如果不是客观构成要件要素，则不要求主观认识到。
                        \begin{enumerate}
                          \item \al{以为自己卖的是鸦片（实例），实际卖的是海洛因（实例）} \yjt
                                主观认识到是毒品（\zd{上位概念}，类型性 \yjt 客观要素）即可，而不需要具体认识到是何种类毒品（鸦片还是海洛因 \yjt 实例）。
                          \item \al{甲以为树下的人是乙（实例），误杀之} \yjt 对于故意杀人，在人的范围内主客观相一致。
                        \end{enumerate}
                \end{enumerate}
          \item 理论分类。
                \begin{enumerate}
                  \item 概括故意。范围、数量不确定。
                  \item 择一故意。两个结果发生哪个不确定。\al{一杯毒药一杯饮料}。
                \end{enumerate}
        \end{enumerate}
  \item 罪过形式区分。
        \begin{enumerate}
          \item \zd{直接故意} \yjt 明知 + 希望。\al{叶文洁，丈夫，政委。解开绳子，丈夫必死无疑} \yjt 仅一种可能性。
          \item \zd{间接故意} \yjt 明知 + 放任。发生、不发生都可以，\zd{两种可能性}。
          \item 各类过失。预见的可能性大小。认识能力 + 客观认识条件。
                \begin{enumerate}
                  \item 已经预见 \yjt \zd{过于自信}。不想让结果发生，\zd{客观上有采取避免措施}。\al{高速开斗气车}。
                  \item 应当预见，有条件预见 \yjt \zd{疏忽大意}。\al{医生忘取纱布；马路边推人}。
                  \item 无从预见 \yjt \zd{意外事件}。\al{天黑车停路边下车掉井盖}。
                \end{enumerate}
        \end{enumerate}
  \item 步骤。
        \begin{enumerate}
          \item 有认识到会发生危害结果 \yjt 对结果的态度 \yjt 希望/放任/反对 \yjt 结果避免可能性 \yjt 不可抗力。
          \item 没有 \yjt 预见可能性。
        \end{enumerate}
\end{enumerate}
