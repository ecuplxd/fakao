\section{人身犯罪 - 侵犯名誉权、人身权、婚姻家庭的犯罪、普通罪名}
\begin{enumerate}
  \item 侵犯名誉权、人身权。
        \begin{enumerate}
          \item 侮辱 vs 诽谤。
                \begin{enumerate}
                  \item 使用的事实，\zd{诽谤必须是虚假的}，\zd{不能假的太离谱，要能使一般人相信}。
                  \item 都要求\zd{公然性}。体现：\al{移动客服案（一对一）}。
                \end{enumerate}
          \item 诬告陷害 vs 诽谤。
                \begin{enumerate}
                  \item 诬告陷害罪（要坐牢）\yjt 人身自由；诽谤罪 \yjt 外部名誉。\zd{被害人都可以承诺放弃}。
                  \item 诬告陷害罪 \yjt \zd{虚假的犯罪事实}；诽谤罪 \yjt 虚假的事实。
                \end{enumerate}
          \item 刑讯逼供。
                \begin{enumerate}
                  \item 肉刑或变相肉刑（酷刑）。\al{审讯室单曲循环一首歌；精神折磨崩溃}。
                \end{enumerate}
          \item 虐待被监管人、暴力取证、刑讯逼供、聚众斗殴（非本章罪名）。\zd{（过失）致人死亡要拟制为故意杀人}。
        \end{enumerate}
  \item 婚姻家庭的犯罪。
        \begin{enumerate}
          \item 重婚。同时维持两份婚姻。
                \begin{enumerate}
                  \item 法律婚 + 法律 \hz 法律 + 事实。
                  \item 事实 + 事实、同居不算。
                \end{enumerate}
          \item 破坏军婚。
                \begin{enumerate}
                  \item 明知军人的配偶 + [(结婚 \hz \zd{同居/包二奶})，No(不包括通奸)]
                  \item \zd{一夜情} + 一方有配偶 = \zd{通奸} + 共同生活 = \zd{同居} + 公开 + 对外夫妻相称 = \zd{事实婚姻} + 登记 = 法律婚姻。
                \end{enumerate}
          \item 通奸不是犯罪了，取证困难。
          \item 暴力干涉婚姻自由罪、虐待罪。结果加重：致人死亡（包括被害人自杀）。
          \item 虐待罪。要求是家庭成员；虐待被监护、看护人罪。幼儿园。\zd{不是对立互斥，可能法条、想象竞合}。
        \end{enumerate}
  \item 普通罪名。
        \begin{enumerate}
          \item 侵犯公民个人信息。
          \item 强迫劳动。
          \item 非法侵入住宅。
        \end{enumerate}
\end{enumerate}
