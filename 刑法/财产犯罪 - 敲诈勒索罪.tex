\section{财产犯罪 - 敲诈勒索罪}
\begin{enumerate}
  \item 没有法律上的财产请求权。
  \item \bs{\yi 非法占有目的 \yjt \er 恐吓行为 \yjt \san 恐惧心理 \yjt \si 交付财物（既遂） \yjt 取得}。基本同抢劫。
        \begin{enumerate}
          \item \er\san 要有因果关系。\san\si 因果。
        \end{enumerate}
  \item vs 抢劫。被害人\zx{意志自由被剥夺的程度}不同。抢劫没得选只能给，敲诈有得选但最好给。\al{收保护费}。
  \item vs 行使权力。根据行为是否符合要件去判断。
        \begin{enumerate}
          \item 明确有请求权。怎样都不构成。
                \begin{enumerate}
                  \item \al{吃饭吃出头发，要求赔 10W}。
                  \item \al{吴秀波第三者，青春损失费}。
                \end{enumerate}
          \item \zx{请求权有争议。行为人如果用恐吓手段而非法律手段 \yjt 定敲诈勒索}。\al{华为李洪元}。
        \end{enumerate}
  \item vs 诈骗。\bs{可以想象竞合。诈骗虚构的事实可以有暴力内容，敲诈勒索的恶害可以既虚假又让人恐惧}。
        \begin{enumerate}
          \item \al{甲杀死乙后，心生一计给乙妻打电话不给钱就撕票。故意杀人、敲诈勒索、诈骗想象竞合}。
          \item \al{甲缺钱，给其父打电话，不给钱就卸你一条胳膊}。
        \end{enumerate}
  \item \al{碰瓷}。有可能诈骗、敲诈勒索……
\end{enumerate}
