\section{社会秩序犯罪 - 卖淫类犯罪、关于淫秽物品的犯罪}
\begin{enumerate}
  \item 一个名词，一个动词。
  \item 卖淫。
        \begin{enumerate}
          \item 行为主体。\zd{不能包括动物，男女随便排列组合}。\al{充气娃娃}。
          \item 内容。要求发生关键的那一步。
          \item 支付方式。嫖资可以是金钱货币也可以是物，不包括办事。\al{甲乙完事后，甲请求乙辅导作业}。
        \end{enumerate}
  \item \kd{组织卖淫}、强迫卖淫、协助组织卖淫。\al{乙帮助组织卖淫的王某招募、运送卖淫女}。
        \begin{enumerate}
          \item 组织。管理性、控制性。不要求有实体，固定地点。
          \item 强迫。逼良为娼、不给上岸、竞业禁止。
          \item 协助组织。不能扩大打击面，招募人员、运送、保镖（保安，看工资待遇）、财物。\zd{帮助行为正犯化}。
        \end{enumerate}
  \item 引诱、容留、\kd{介绍卖淫}。
        \begin{enumerate}
          \item 引诱 \yjt 勾引。
          \item 容留同容留吸毒。\al{航班上空姐提供性服务，机长知道却放任}。
          \item 介绍 \yjt 拉皮条的/中介。vs 介绍嫖娼。介绍工作，为嫖客服务，站在嫖客立场。\al{发小卡片}。
        \end{enumerate}
  \item 引诱幼女卖淫。
  \item 传播性病。性病患者卖淫嫖娼。\zd{扩大解释，包括艾滋病}，可能构成故意伤害罪，想象竞合择一重。
  \item \kd{淫秽物品的犯罪}。淫秽物品扩大解释。\al{淫秽表演网络直播}。
        \begin{enumerate}
          \item 制作、复制、组织、出版、\zd{贩卖、传播}淫秽物品/\zd{牟利}。牟利目的。\zd{是否能实现，在所不问}。
          \item 传播淫秽物品。有传播（社会公众）目的即可。\al{下了小黄片，给哥几个一起传阅 ×}。
          \item 传播淫秽物品牟利。传播 + 牟利。
          \item 走私淫秽物品。传播、牟利至少有一个。
        \end{enumerate}
\end{enumerate}
