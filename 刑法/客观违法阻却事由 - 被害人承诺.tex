\section{客观违法阻却事由 - 被害人承诺}
\begin{enumerate}
  \item 一般的被害人承诺。
        \begin{enumerate}
          \item 权限和范围。名誉、人身自由、轻伤 √；重伤、生命 ×。
          \item 时间。\zd{事前}承诺。
                \begin{enumerate}
                  \item 时间连续型的分阶段讨论。
                  \item 被害人承诺是客观存在的，\zd{不要求行为人主观意识到}。
                \end{enumerate}
          \item 承诺能力。对承诺的事项有正确的理解能力。\al{骗小孩/精神病人的钱} \yjt 盗窃罪。
          \item \kd{承诺的意思表示}。\zd{真实}。考试喜欢考欺骗。\zd{也适用于认定诈骗中}。
                \begin{enumerate}
                  \item 甲欺骗乙导致乙产生认识错误。
                        \begin{enumerate}
                          \item 事实性欺骗。即\zd{如果我知道则不会}。\al{尹志平小龙女 \yjt 事实性错误，承诺无效 \yjt 强奸}。
                          \item 动机性欺骗。\zd{动机错误不影响被害人承诺有效性}。包括卑劣的动机，不要带入道德审判。
                                \al{导演骗女演员 \yjt 动机错误，承诺有效 \yjt 不构成强奸；甲汽修店老板为了让司机们前来补胎，高速路口撒钉子 \yjt 本身不构成欺骗}。
                        \end{enumerate}
                  \item 乙自己产生认识错误。
                        \begin{enumerate}
                          \item 甲不知道 \yjt 有效。
                          \item 甲知道且\zd{继续实施欺骗行为}（维持、强化）\yjt 无效。\al{司机来补轮胎}。
                                \begin{itemize}
                                  \item 有告知义务，实施不作为欺骗。\al{乙以为自己的马绝症了请求兽医安乐死}。
                                  \item 没有告知义务，实施作为欺骗。\zd{犹疑不定 \yjt 内心确信}。\al{乙以为自家着火请求甲灭火，甲说火势很大}。
                                \end{itemize}
                          \item 甲知道，但仅单纯利用 \yjt 有效。其实就是\zd{看你笑话}的意思。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 推定的被害人承诺。
        \begin{enumerate}
          \item 一般人的标准。\zd{不一定以被害人为标准}。\al{落水救人} \yjt 即便被害人本身是想自杀。
          \item 可能和紧急避险竞合。\al{坚决要求顺产结果双双死亡；疫情期间送医}。
        \end{enumerate}
\end{enumerate}
