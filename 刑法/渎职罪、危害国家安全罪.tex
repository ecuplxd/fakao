\section{渎职罪、危害国家安全罪}
\begin{enumerate}
  \item 不重要。考前稍微看一下。
  \item 渎职罪。
        \begin{enumerate}
          \item 滥用职权。故意犯罪。
          \item 玩忽职守。过失。
          \item 徇私枉法。刑事诉讼领域；公检法。
          \item 民事、行政枉法裁判。
          \item 私放在押人员和失职致使在押人员脱逃。
          \item 徇私舞弊不移交刑事案件。
          \item 帮助犯罪分子逃避处罚。
          \item 食品、药品监管渎职。增加了药品；\zd{故意、过失共享同一个法定刑}。
        \end{enumerate}
  \item 危害国家安全罪。
        \begin{enumerate}
          \item 间谍。
          \item 为境外窃取、刺探、收买、非法提供国家秘密、情报。
          \item 叛逃。
        \end{enumerate}
\end{enumerate}
