\section{渎职罪、危害国家安全罪}
\begin{enumerate}
  \item 不重要。考前稍微看一下。
  \item 渎职。
        \begin{enumerate}
          \item 滥用职权。故意作为、故意不作为均可构成。
          \item 玩忽职守。过失、一般法。
          \item \zx{徇私枉法}。刑事诉讼领域 + 公检法。
                \begin{enumerate}
                  \item \al{刑事附带民事 \dui。\xhx{分管公安}工作的副\xhx{县长} \cuo}。
                  \item \al{不立案}。
                \end{enumerate}
          \item \zd{民事、行政枉法裁判}。
          \item 执行判决、裁定失职。
          \item 执行判决、裁定滥用职权。
          \item 私放在押人员。故意。
          \item 失职致使在押人员脱逃。过失。
          \item 国家机关工作人员签订、履行合同失职被骗。主体是国有企事业单位直接负责的主管人员。
          \item 徇私舞弊不移交刑事案件。新增。行政执法人员。不看身份，看事情性质定性。
                \begin{enumerate}
                  \item \al{警察\xhx{抓卖淫嫖娼}发现传播性病}。
                  \item \al{警察\xhx{侦查}卖淫嫖娼时发现传播性病}。
                \end{enumerate}
          \item 徇私舞弊不征、少征税款。税务机关工作人员、故意。
          \item 招收学生徇私舞弊。
          \item 帮助犯罪分子逃避处罚。\al{\xhx{协警}甲向犯罪分子乙通风报信助其逃避处罚 \dui}。
          \item 食品、药品监管渎职。新增了药品。故意、过失共享同一个法定刑。
          \item 环境监管失职。
          \item 放纵走私。海关工作人员。
        \end{enumerate}
  \item 危害国家安全。
        \begin{enumerate}
          \item 间谍。行为人知道对方的间谍身份。
          \item 为境外窃取、刺探、收买、非法提供国家秘密、情报。
          \item 非法获取国家秘密。
          \item 故意泄露国家秘密。只要求故意泄露就行。
          \item 叛逃。
                \begin{enumerate}
                  \item 国家工作机关人员在履行公务期间，擅离岗位，叛逃境外 \hz 在境外叛逃。
                  \item 又实施其他犯罪的，应当数罪并罚。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
