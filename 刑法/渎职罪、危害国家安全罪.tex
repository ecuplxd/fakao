\section{渎职罪、危害国家安全罪}
\begin{enumerate}
  \item 不重要。考前稍微看一下。
  \item 渎职。
        \begin{enumerate}
          \item 滥用职权。故意犯罪。
          \item 玩忽职守。过失。
          \item 徇私枉法。刑事诉讼领域。公检法。
          \item 民事、行政枉法裁判。
          \item 私放在押人员和失职致使在押人员脱逃。一个故意一个过失。
          \item 徇私舞弊不移交刑事案件。
          \item 帮助犯罪分子逃避处罚。\al{公安人员甲向犯罪分子乙通风报信助其逃避处罚}。
          \item 食品、药品监管渎职。增加了药品。\zd{故意、过失共享同一个法定刑}。
          \item 放纵走私。\zd{海关工作人员}。
        \end{enumerate}
  \item 危害国家安全。
        \begin{enumerate}
          \item 间谍。行为人知道对方的间谍身份。
          \item \zd{为境外}窃取、刺探、收买、非法提供国家秘密、情报。
          \item 非法获取国家秘密。
          \item 故意泄露国家秘密。泄露\zd{给境内}人员。
          \item 叛逃。
                \begin{enumerate}
                  \item 国家工作机关人员在履行公务期间，擅离岗位，叛逃境外 \hz 在境外叛逃。
                  \item 又实施其他犯罪的，应当数罪并罚。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
