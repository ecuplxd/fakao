\section{行为 - 不作为犯的分类}
\begin{enumerate}
  \item 作为：违反\zd{禁止性}规定。飞车抢劫。
  \item 不作为：违反\zd{义务性}规定。母亲不喂养婴儿。不作为内部：
        \begin{enumerate}
          \item 真正\blh：只能由不作为构成。立法者\zd{设立了作为义务}；不履行方式 = 积极的举动 \hz 消极的禁止。
                \begin{enumerate}
                  \item 丢失枪支不报（报告义务）罪。
                  \item 拒不支付报酬。转移资产 \yjt 积极举动；
                  \item 遗弃罪、拒绝提供间谍犯罪证据、拒不执行判决裁定。
                \end{enumerate}
          \item 不真正\blh：作为不作为都能构成。\al{拿刀把人捅死} \yjt 作为的故意杀人，\al{母亲不喂养婴儿} \yjt 不作为的\blh。
        \end{enumerate}
  \item 区分：
        \begin{enumerate}
          \item \zd{积极制造危险}达到通常性程度 \yjt 作为。
          \item \zd{有义务消除危险}不消除 \yjt 不作为。
        \end{enumerate}
  \item \zd{持有型犯罪都是作为犯罪}。持有毒品、枪支。
        \begin{enumerate}
          \item 维持持有这个状态，不是消极的无为，是有一个\zd{积极的举动}。
          \item 知情情况下，\blh \zd{本身}就构成了犯罪。
          \item \al{老爸临死前把枪留给了狗蛋}。
        \end{enumerate}
  \item 作为、不作为和过失、故意关系：没有必然的对应关系，\zd{可相互组合}。
        \begin{enumerate}
          \item 滥用职权 \yjt 故意犯罪（故意的作为，瞎作为 \hz 故意的不作为，懒政）\yjt 导致国有资产流失。
          \item 玩忽职守。
        \end{enumerate}
\end{enumerate}
