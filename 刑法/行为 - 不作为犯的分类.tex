\section{行为 - 不作为犯的分类}
\begin{enumerate}
  \item 作为。违反\zd{禁止性}规定。\al{飞车抢劫}。
  \item 不作为。违反\zd{义务性}规定。\al{母亲不喂养婴儿}。
        \begin{enumerate}
          \item 真正不作为。只能由不作为构成。\zd{立法设立了作为义务}。
                \begin{enumerate}
                  \item 积极的不作为。\al{丢失枪支不报（报告义务）、拒不支付报酬、转移资产}。
                  \item 消极的不作为。\al{遗弃、拒绝提供间谍犯罪证据、拒不执行判决裁定}。
                \end{enumerate}
          \item 不真正不作为。作为、不作为都能构成。\al{拿刀把人捅死/母亲不喂养婴儿 \yjt 作为/不作为的故意杀人}。
        \end{enumerate}
  \item 区分。
        \begin{enumerate}
          \item \zd{积极制造危险}达到通常性程度 \yjt 作为。
          \item \zd{有义务消除危险}不消除 \yjt 不作为。
        \end{enumerate}
  \item \bs{持有型犯罪都是作为犯罪}。\zd{持有毒品、枪支}。
        \begin{enumerate}
          \item \zd{维持“持有”}这个状态，必然要求一个积极的举动。
          \item 知情情况下，\zd{持有本身}就构成了犯罪。\al{老爸临死前把枪留给了狗蛋}。
        \end{enumerate}
  \item \bs{作为、不作为和过失、故意没有必然的对应关系}，可排列组合。
        \begin{enumerate}
          \item \al{滥用职权} \yjt 故意犯罪 \yjt 故意的作为（\al{瞎作为}）\hz 故意的不作为（\al{懒政}）\yjt 都能导致国有资产流失。
          \item \al{玩忽职守}。同上。
        \end{enumerate}
\end{enumerate}
