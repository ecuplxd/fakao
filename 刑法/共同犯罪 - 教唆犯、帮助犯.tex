\section{共同犯罪 - 教唆犯、帮助犯}
\begin{enumerate}
  \item 教唆犯。\zd{故意引起}他人制造（\zd{故意 \hz 过失}）违法事实（违法行为 + 违法结果）。
        \begin{enumerate}
          \item 客观。
                \begin{enumerate}
                  \item 引起正犯制造违法行为。
                        \begin{enumerate}
                          \item \al{甲让乙杀丙，乙说我早就想杀了他}。
                          \item \al{乙想实施诈骗，甲说不如去抢劫}。
                          \item \al{乙想抢劫，甲说带把枪啊}。情节加重。行为方式改变了。
                          \item \al{乙想抢 100，甲说抢 5W 啊}。数额加重。行为方式没改变。没考过。
                          \item \al{乙想抢劫，甲说不如去诈骗}。降低危险（两罪性质相同，程度不同）。
                          \item \al{乙想抢劫，甲说不如去猥亵}。降低危险但\zd{引起新犯意}。
                        \end{enumerate}
                  \item 引起正犯制造违法结果。早期一人既遂，全部既遂。\al{甲让乙杀丙，引起门卫怀疑，乙杀了门卫后逃走}。
                \end{enumerate}
          \item 主观。故意引起。
                \begin{enumerate}
                  \item 说者无意听者有心。\al{甲问乙在外面靠啥发财，贩毒。乙也去贩毒}。
                  \item \zd{故意教唆他人实施不能犯不构成教唆犯}。
                \end{enumerate}
          \item 处罚。稍微了解。
        \end{enumerate}
  \item 帮助犯。\zd{故意促进}他人制造（\zd{故意 \hz 过失}）违法事实。\zd{帮助行为未遂\, \bdy 就是帮助犯}。
        \begin{enumerate}
          \item 客观。
                \begin{enumerate}
                  \item 促进正犯制造违法行为。起正面作用。\al{乙要盗窃丙家，让甲给把钥匙}。
                        \begin{enumerate}
                          \item \al{给了假钥匙，乙另行他法}。
                          \item \al{甲送钥匙途中钥匙被偷。帮助行为未建立连接关系}。
                          \item \al{乙盗窃途中钥匙被偷}。
                          \item \al{门其实开着}。
                          \item \al{钥匙锁孔里被乙弄断}。
                          \item \al{一切顺利}。
                        \end{enumerate}
                  \item 心理性帮助犯。\al{台湾现场助威罪}。
                  \item 促进正犯制造违法结果。对于既遂，帮助行为要发挥\zd{实际贡献}。
                \end{enumerate}
          \item 主观。故意。\al{甲想乙借猎枪打猎，其实是拿枪杀丙}。
          \item 中立的帮助行为。\al{赌场卖茶叶蛋；出租车司机拉凶手到被害人跟前（实质紧迫）}。
        \end{enumerate}
  \item \zd{也有犯罪形态问题，容易忽视}。\al{甲盗窃丙，乙提供户型图，甲未使用图纸就找到 10W 珠宝}。乙帮助犯，未遂。
  \item 共犯对正犯的要求。原理同共同正犯。
        \begin{enumerate}
          \item 教唆犯 + 正犯。
                \begin{enumerate}
                  \item \yi \al{医生怂恿护士} \er \al{医生欺骗护士} \yjt 支配力 \yjt 间接正犯。
                  \item \al{护士将有毒针听成正常针}。医生无欺骗行为 \yjt 无支配力。护士 \yjt 故意杀人罪客观阶段的“正犯”
                  \item \zd{故意 + 过失还没考}。非常重要。
                \end{enumerate}
          \item 帮助犯 + 正犯。
          \item 对正犯责任年龄不做要求。\al{甲虚报儿子乙年龄考取警察，唆使乙刑讯逼供犯人丙}。
          \item 对正犯责任能力不做要求。\al{甲教唆乙去伤害丙，乙是精神病患者但甲不知}。
        \end{enumerate}
  \item 要得出一个符合正义感的结论是相对容易的，但是要给予充分论证是很难的。
\end{enumerate}
