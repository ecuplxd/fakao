\section{共同犯罪 - 共同犯罪的参与时间、处罚规定}
\begin{enumerate}
  \item 承继的共犯。实施了部分犯罪，中途参与进来。\al{路过、经过}。
        \begin{enumerate}
          \item 中途参与。
                \begin{enumerate}
                  \item \zd{共同实行} \yjt 承继的共同正犯 \yjt 整罪负责。\al{甲抢劫丙时乙路过，和甲一起重伤乙，夺得财物}。
                  \item \zd{进行帮助} \yjt 承继的帮助犯 \yjt 帮助部分负责。\al{甲抢劫丙重伤倒地，乙路过把丙的东西给甲}。
                  \item \zd{承继前行为而非己行为}。\al{甲成立抢劫，乙成立抢夺，两者重合地方成立共犯 ×}。
                \end{enumerate}
          \item \zd{事前共谋，临时迟到}。不是承继的，因为一开始就是共同犯罪。
          \item 事后参与（已既遂）。\al{甲完成对乙的抢劫，丙路过对甲说我带你走。丙均不构成抢劫、故意伤害}。
                \begin{enumerate}
                  \item 对人 \yjt 窝藏。
                  \item 对证据 \yjt 毁灭证据。
                  \item 对财物 \yjt 隐藏犯罪所得。
                \end{enumerate}
          \item 中途退出。共犯关系的脱离。\zd{先要确定处于哪个犯罪形态}。
                \begin{enumerate}
                  \item 构成犯罪中止要件。穷尽所有可能\zd{消除自己的物理、心理贡献}。\zd{命题陷阱，打时间差}。
                        \begin{enumerate}
                          \item \al{甲知道乙要偷车，将盗车钥匙给乙，后在乙盗车前要回钥匙。乙通过其他方法盗窃了轿车}。
                          \item 预备阶段 \yjt 自动放弃。实行阶段 \yjt 物理 + 心理。其实就是实行终了、未实行终了？
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 处罚规定。不是难点重点，记忆性东西。
\end{enumerate}
