\section{共同犯罪 - 共同犯罪的参与时间、处罚规定}
\begin{enumerate}
  \item 承继的共同犯罪。实施了部分犯罪，中途参与。
        \begin{enumerate}
          \item 中途参与。
                \begin{enumerate}
                  \item 共同实行 \yjt 承继的共同正犯 \yjt 整罪负责。\al{甲抢劫丙时乙路过，和甲一起重伤乙，夺得财物}。
                  \item 进行帮助 \yjt 承继的帮助犯 \yjt 帮助部分负责。\al{甲抢劫丙重伤倒地，乙路过把丙的东西给甲}。
                \end{enumerate}
          \item 事前共谋，临时迟到。不是承继的，因为一开始就是共同犯罪。
          \item 事后参与（已既遂）。\al{甲完成对乙的抢劫，丙骑车路过对甲说我带你走。丙均不构成抢劫罪、故意伤害罪}。
                \begin{enumerate}
                  \item 对人 \yjt 窝藏。
                  \item 对证据 \yjt 毁灭证据。
                  \item 对财物 \yjt 隐藏犯罪所得。
                \end{enumerate}
          \item 中途退出。共犯关系的脱离。
                \begin{enumerate}
                  \item 构成犯罪中止要件。穷尽所有可能消除自己的贡献（物理 + 心理）。
                \end{enumerate}
        \end{enumerate}
  \item 处罚规定。不是难点重点，记忆性东西。
\end{enumerate}
