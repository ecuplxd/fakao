\section{法与社会}
\begin{enumerate}
  \item 常识应对。
  \item 法与道德。
        \begin{enumerate}
          \item 生成方式。\bs{建构、非建构性}（\zd{自发产生}）。自然演进、不是自觉制定、程序选择的产物。
          \item \zd{道德也具有强制性}（内心强制）。道德不可诉。
        \end{enumerate}
  \item 人权。本质上是一种道德权利。
        \begin{enumerate}
          \item 分为应有/应然权利、\zd{法律权利（法律化）}、实有/现实权利。
          \item 历史性。物质生活条件决定。我国反对人权的普适性、超验性（\al{造物主、神}）、不证自明性。
          \item 紧密关联性。权利和义务之间。
        \end{enumerate}
\end{enumerate}
