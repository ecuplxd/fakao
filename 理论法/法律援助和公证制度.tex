\section{法律援助和公证制度}
\begin{enumerate}
  \item 出题 2 选 1。
  \item 3 年可以当审理人，开所，单干再 + 2 年。
  \item 法律援助。更重要。
        \begin{enumerate}
          \item 援助责任主体是政府。县以上。
          \item 4 个统一。受理、审查、指派、监督。
          \item \zd{完全无偿}；形式丰富；主体多样。调动一切力量。
          \item 对象。弱势、困难。
                \begin{enumerate}
                  \item 申请 + 经济困难，证明文件。
                  \item 智力残疾；共犯中其他人委托了，他没；检察院抗诉；影响大。
                  \item 公益、道义。蒙冤、家暴、英烈；老幼残、低保户、农民工。新增。
                  \item 强制指定辩护。刑诉。
                  \item 申诉。
                \end{enumerate}
          \item 诉讼，办案机关所在地；非诉，争议机关 \hz 事由所在地。
          \item 实施形式。法律咨询、代理、刑辩、值班律师。
          \item 7 日审查，3 日指派，书面拒绝，补充材料一次告知。
          \item 先予援助。\zd{保}全、\zd{先}予执行、诉讼时效\zd{不足一星期}。新增。
          \item \zd{无期死刑有经验（3 年），未成年人懂特点}。新增。
          \item 救济。司法行政提异议，处理时间是 5 天。
        \end{enumerate}
  \item 公证制度。证明活动。\zd{不是诉讼活动}。没怎么考过。
        \begin{enumerate}
          \item 范围。\zd{没有争议}的民事法律行为和有法律意义的\zd{事实和文书}。\zd{真实性、合法性}。
          \item 2 方主体。公证处，民间组织。市场化程度非常高。
          \item 管辖。
          \item 公证员条件。处罚最高到吊证。
                \begin{enumerate}
                  \item 25 - 65岁；实习 2 年；有其他 3 经验 \yjt\, 1 年。
                  \item 犯过职务过失不能。
                  \item 机构推荐，省级审核，司法部任命，省级发证。
                  \item 义务。禁止自证、私证、公证回避。动摇公信力。
                \end{enumerate}
          \item 公证机构。处罚最高到停业整顿。
                \begin{enumerate}
                  \item 不是按照行政区划设立。最低到县。
                  \item 地级市以上有字号，省内不雷同。
                \end{enumerate}
          \item 不予办理公证。不合法、不真实、不给钱。
          \item 应当终止。超期了、撤回了、挂掉了、阻挠了。
          \item 救济。
                \begin{enumerate}
                  \item 复查。无问题 \yjt 维持；有问题 \yjt 更正、补正 \hz 撤销。
                  \item 诉讼。\zd{否认效力，裁定不予执行。不能撤公证书}。
                \end{enumerate}
          \item 公正代理。遗嘱、生存、收养。人身性；现场监督 2 人。
        \end{enumerate}
\end{enumerate}
