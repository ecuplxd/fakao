\section{检察制度和检察官职业道德}
\begin{enumerate}
  \item 检察制度。刑事、民事、行政、公益诉讼检察。
        \begin{enumerate}
          \item 检察权统一行使（\zd{检察一体}）。
                \begin{enumerate}
                  \item \zd{检察长负责和检委会集体领导相结合}。
                  \item 冲突时候。在办案件上一级，其他重大上一级 \hz 同级人常。
                \end{enumerate}
        \end{enumerate}
  \item 检察官职业道德。同法官。
  \item 免除职务。丧失国籍、调出、职务变动不需要保留、考核不称职、健康原因、退休、辞职辞退、违法违纪。
  \item \kd{惩戒委员会}。只在最高和省级。
        \begin{enumerate}
          \item 给意见的权利，无处分权（原单位）。半官方组织。
          \item \zd{不接受来自社会的举报材料}。来自内部移送。
          \item 故意、重大过失。
          \item \zd{一上一下自己人遴选 1/3、惩戒最少一半、通过 2/3}。
          \item 异议还是找惩戒委员会。
          \item 原单位处分、原单位复议、上级机关申诉。
        \end{enumerate}
\end{enumerate}
