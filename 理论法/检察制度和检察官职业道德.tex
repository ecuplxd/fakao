\section{检察制度和检察官职业道德}
\begin{enumerate}
  \item 检察制度。刑事、民事、行政、公益诉讼检察。
        \begin{enumerate}
          \item 检察权统一行使（\zd{检察一体}）。
                \begin{enumerate}
                  \item \zd{检察长负责和检委会集体领导相结合}。
                  \item 冲突。在办案件上一级，其他重大上一级 \hz 同级人常。
                \end{enumerate}
        \end{enumerate}
  \item 检察官职业道德。同法官。
  \item \zd{惩戒委员会}。只在最高和省级。
        \begin{enumerate}
          \item 给意见的权利，无处分权（原单位）。半官方组织。
          \item \bs{不接受来自社会的举报材料}。来自内部移送。
          \item 故意、重大过失。
          \item 异议还是找惩戒委员会。
          \item 原单位处分、原单位复议、上级机关申诉。
        \end{enumerate}
\end{enumerate}
