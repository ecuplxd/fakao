\section{其他国际货物运输法律制度}
\begin{enumerate}
  \item 国际航空货物运输法。责任限制，存在最高赔偿限额。
        \begin{enumerate}
          \item 考的很少很少。只考过一回。
          \item 《华沙公约》不完全过失责任。《蒙特利尔公约》完全过失责任。
          \item 接到交期间。
        \end{enumerate}
  \item 铁路运输法律制度。一带一路。
        \begin{enumerate}
          \item 运单效力。\zd{不是物权凭证}。有单货分离的事实需求，但没有法律基础。要穿越多国，必须随单穿行。
          \item 联运\zd{完全过失连带责任}。无过失才可以免责。
          \item 管货期间为\zd{接到交}。
          \item 足额赔偿责任。更安全，安全的事业不需要特殊的制度去鼓励。
        \end{enumerate}
\end{enumerate}
