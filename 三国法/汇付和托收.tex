\section{汇付和托收}
\begin{enumerate}
  \item 汇付所占的份额是非常少。一般用于尾款的支付。从来没有考过汇付。
  \item 支付方式的信用性质判断：商业信用还是银行信用，\zd{银行要不要垫付资金}。
  \item 托收。考的少。考过三回。委托代理关系。
        \begin{enumerate}
          \item 跟单托收。凭提单委托收款。
          \item 四方当事人。两个委托代理关系，一个相对人。
          \item 免责。三不管三免责。管一不管三。
                \begin{enumerate}
                  \item 一不管单二不管货三不管票据追索。管收钱。
                  \item \zd{托收行对代收行的行为免责}。托收它便宜。
                \end{enumerate}
          \item 付款交单的托收，承兑交单的托收。
        \end{enumerate}
\end{enumerate}
