\section{汇付和托收}
\begin{enumerate}
  \item 汇付/汇款。所占的份额是非常少。一般用于尾款的支付。从来没有考过汇付。
  \item 托收。考的少，考过 3 回。委托代理关系。
        \begin{enumerate}
          \item 法律关系。\input{draw/托收.tex}
          \item 支付方式的信用性质判断。商业信用 vs 银行信用，\zd{银行要不要垫付资金}。
          \item 跟单托收。凭提单委托收款。
          \item 4 方当事人。2 个委托代理关系，1 个相对人。
          \item 免责。三不管三免责。管一不管三。
                \begin{enumerate}
                  \item 不管单不管货不管票据追索，\zx{只管收钱}。
                  \item \zx{托收行对代收行的行为免责}。托收它便宜。
                \end{enumerate}
          \item 根据嘱咐银行交单的条件分。付款交单（D/P），承兑交单（D/A） \yjt 卖方风险更大。
          \item 代收行过失，卖方的救济。\zx{只能根据合同追究买方违约责任}。
        \end{enumerate}
\end{enumerate}
