\section{海上货物运输保险}
\begin{enumerate}
  \item 海运保险法。
  \item 保险人责任。\zd{货损责任}。险别。学险别就是学分类。
  \item 2 大要素决定。运输中的风险（致损原因），运输中的损失（结果）。
  \item 风险分类。2 大类 5 小类。
        \begin{enumerate}
          \item 海上风险。海上相对固有的风险。
                \begin{enumerate}
                  \item 自然灾害。人力意志不可转移。\zd{因 xx 被雨淋}、恶劣气候、台风、雷电、海啸、地震、洪水、火山。
                  \item 意外事故。克尽可以避免。\zd{整件落海}、搁浅、触礁、沉没、碰撞、火灾、爆炸、失踪、倾覆、投弃、船长/船员恶意行为。
                \end{enumerate}
          \item 外来风险。
                \begin{enumerate}
                  \item 特殊。战争、罢工。
                  \item 特别。政治、行政等因素。进口国\zd{拒收}、进口\zd{关税}等。
                  \item 一般。战争、罢工、政治、行政以外。\zd{钩损、被雨淋}、渗漏、受潮受热、串味等。
                \end{enumerate}
        \end{enumerate}
  \item 损失分类。全部么 \yjt 部分么 \yjt 共同么 \yjt 单独。
        \begin{enumerate}
          \item 全部损失。读题就能判断。\al{完全灭失、被火烧为灰烬、完全丧失使用价值}。
                \begin{enumerate}
                  \item 实际全损。物理性。赔偿方式由保险人选择。\al{被火烧成灰}。
                  \item 推定全损。所有损失费用 \dy 货物价值。
                        \begin{kk}{推定全损索赔}
                          \begin{enumerate}
                            \item 必须向保险人发出\zd{委付通知}。我不要了给你。\zd{单方意思表示}。
                            \item 保险公司在\zd{合理的时间}内将\zd{决定通知}被保险人是否接受。
                            \item \zd{合同看标的看标的看标的}。委付通知针对\zd{标的物残值所有权}，和怎么赔赔多少没关系。
                            \item \hz 按部分损失进行索赔。
                          \end{enumerate}
                        \end{kk}
                \end{enumerate}
          \item 部分损失。
                \begin{enumerate}
                  \item \zd{共同海损}。危险\zd{危及到了船}、\zd{有意采取措施}（只看主观）导致的、措施相对合理。\al{搁浅抛货}。
                        \begin{enumerate}
                          \item \zd{有共损必有分摊}。由受益方（\zd{承运人也有可能是受益方}，不要漏了）按各自获救\zd{比例} 分摊。
                          \item 共同海损的分摊叫\zd{共同海损理算，适用理算地法}。
                        \end{enumerate}
                  \item 单独海损。个案推定。非“有意”有意采取措施导致。
                \end{enumerate}
        \end{enumerate}
  \item 险别。
        \begin{enumerate}
          \item \zd{基本险别}。
                \begin{enumerate}
                  \item 平安险/海运最低险。只管海上风险，\bs{不赔自然灾害导致的单独海损}。
                  \item 水渍险。不赔外来风险。
                  \item 一切险。不赔特别、特殊外来风险。
                  \item \sjt \zd{意外事故导致的任何损失都赔}。
                \end{enumerate}
          \item 附加险别。一般/特别/特殊附加险分别对应。不能单独投保。
        \end{enumerate}
  \item 保险责任期间。仓至仓确定。
  \item 除外责任（法定免责）。
        \begin{enumerate}
          \item 被保险人\zd{故意 \hz 过失}造成的损失。
          \item \zd{发货人责任}造成的损失。
          \item 在保险\zd{责任开始前，已经存在的品质不良，数量短差}。
          \item \zd{间接性损失不赔}。自然损耗、本质缺陷、特性以及市价跌落、\zd{运输迟延}引起的损失和费用。
        \end{enumerate}
\end{enumerate}
