\section{海上货物运输保险}
\begin{enumerate}
  \item 海运保险法。
  \item 保险人责任。\zd{货损责任}。险别。学险别就是学分类。
  \item 2 大要素决定。运输中的风险（致损原因），运输中的损失（结果）。
  \item 风险分类。2 大类 5 小类。
        \begin{enumerate}
          \item 海上风险。海上相对固有的风险。
                \begin{enumerate}
                  \item 自然灾害。恶劣气候、台风、雷电、海啸、地震、洪水、火山爆发。
                  \item 意外事故。搁浅、触礁、沉没、碰撞、火灾、爆炸、失踪、倾覆、投弃、船长和船员的恶意行为。
                \end{enumerate}
          \item 外来风险。
                \begin{enumerate}
                  \item 一般\blh。与政治行政战争罢工无关。装卸过程中的钩损、一般雨、渗漏、受潮受热、串味。
                  \item 特别\blh。战争和罢工以外的人为因素。
                  \item 特殊\blh。战争和罢工。
                \end{enumerate}
          \item 按人力意志是否可转移分。自然灾害 \yjt 灾害级的雨；意外事故 \yjt 装卸过程中整件落海。
        \end{enumerate}
  \item 险别。
        \begin{enumerate}
          \item \zd{基本险别}。平安、水渍、一切险。
                \begin{enumerate}
                  \item 平安。海运最低险。海上风险 √。不赔部分海损。
                  \item 水渍。海上风险 + 自然灾害导致的部分损失。
                  \item 一切险。特别 \hz 特殊外来风险不赔。
                \end{enumerate}
          \item 附加险别。不能单独投保。交强险/玻璃险。
        \end{enumerate}
  \item 损失分类。全部么 \yjt 部分么 \yjt 共同么 \yjt 单独。
        \begin{enumerate}
          \item 全部损失。完全灭失、被火烧为灰烬、完全丧失使用价值。读题就能判断。
                \begin{enumerate}
                  \item 实际全损。物理性。赔偿方式由保险人选择。
                  \item 推定全损。所有损失费用 > 货物价值。
                        \begin{kk}{推定全损索赔}
                          \begin{enumerate}
                            \item 必须向保险人发出\zd{委付通知}。我不要了给你。\zd{单方意思表示}。
                            \item 保险公司在\zd{合理的时间}内将\zd{决定通知}被保险人是否接受。
                            \item \zd{合同看标的看标的看标的}。委付通知针对\zd{标的物残值所有权}，和怎么赔赔多少没关系。
                            \item \hz 按部分损失进行索赔。
                          \end{enumerate}
                        \end{kk}
                \end{enumerate}
          \item 部分损失。
                \begin{enumerate}
                  \item \zd{共同海损}。危险危及到了船；\zd{有意采取措施}（看主观）导致的，如搁浅抛货；相对合理性。
                        \begin{enumerate}
                          \item 由受益方分摊。\zd{有共损必有分摊}。
                          \item 共同海损的分摊叫共同海损理算。适用理算地法。
                        \end{enumerate}
                  \item 单独海损。个案推定。
                \end{enumerate}
        \end{enumerate}
  \item 保险责任期间。仓至仓确定。
  \item 除外责任（法定免责）。
        \begin{enumerate}
          \item 被保险人\zd{故意 \hz 过失}造成的损失。
          \item \zd{发货人责任}造成的损失。
          \item 在保险责任开始前，\zd{已经存在的品质不良，数量短差}。
          \item 自然损耗、本质缺陷、特性以及市价跌落、\zd{运输延迟}引起的损失和费用。\zd{间接性损失不赔}。
        \end{enumerate}
\end{enumerate}
