\section{银行信用证}
\begin{enumerate}
  \item 主要难在操作流程上，本质是一种银行保证。
  \item 四方 \hz 五方当事人。开证申请人（买方）、受益人（卖方）、开证行、通知行/议付行（帮忙的小伙伴）（可以是同一个）。
  \item 法律关系。
        \begin{enumerate}
          \item 买方和开证行 \yjt 委托合同关系。
          \item 信用证开立 \yjt 付款保证责任。（有条件付款保证）。
          \item 开证行和通知行 \yjt 委托代理关系。
          \item 通知行通知卖方 \yjt 代理人和代理行为相对人。
          \item 卖方单据、汇票给到议付行 \yjt 第一次买卖关系。
        \end{enumerate}
  \item 跟单信用证统一惯例，国际商会第六百号出版物，UCP600。
  \item 开证行。\zd{单证一致单单一致。表面一致}。
        \begin{enumerate}
          \item 有义务收卖方单给卖方钱。
          \item 诉买方、银行、凭提单去取货、履行押金项下的权利。
          \item 审单期仅限 5 个工作日。
          \item 两个可以赋予银行的权利。单证不符，\zd{可以自行联系}开证申请人，开证申请人放弃\zd{不符点通知}，银行\zd{可以释放单据}。
                选项可能换个说法，\scx{应当付款}。
          \item 免责。
                \begin{enumerate}
                  \item \zd{对单据的实质免责}。最重要的免责条款。
                  \item 对传递延误 \hz 遗失免责。
                  \item 不可抗力免责。
                  \item \zd{对买卖合同的实际履行状况免责}。\zd{信用证独立原则}，效力独立于买卖合同。
                \end{enumerate}
        \end{enumerate}
  \item 信用证欺诈。
        \begin{enumerate}
          \item 开立假信用证欺诈。银行业务员。信用证诈骗罪。\zd{没有真实交易基础}。
          \item 软条款信用证欺诈。买方诈卖方货。\al{规定一些银行付款的\xhx{限制性条款}；暂不生效条款；清关后支付等。加列各种限制性条件}。
          \item 伪造单据 \hz 以假货充真货。卖方诈买方钱。国际经济法调整。
        \end{enumerate}
        \begin{kk}{止付令}
          信用证欺诈例外原则。非常苛刻的条件限制。
          \begin{enumerate}
            \item 只能由\zd{有管辖权的法院}发出。司法干预。
            \item 有欺诈的\zd{确凿证据}。有可靠充分的\zd{担保}。
            \item 时间限制。要早于任何一家关联银行已经善意的付款 \hz 承兑信用证项下的票据。
            \item \zd{48 小时做出裁定}。
          \end{enumerate}
        \end{kk}

        \begin{kk}{单证 \hz 单单表面不符和止付令不用付钱，其他都要都要都要！！！}
          可以解决信用证一多半的法律题目。
        \end{kk}
  \item 保兑信用证。
        \begin{enumerate}
          \item 一家银行开出的信用证，被另一家银行加以保证兑付。\zd{连带责任}。
          \item 保兑信用证就是一个\zd{加持}的信用证。
        \end{enumerate}
\end{enumerate}
