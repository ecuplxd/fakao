\section{货物销售合同公约}
\begin{enumerate}
  \item 适用范围。
        \begin{enumerate}
          \item 原则买卖双方的营业地要在不同的国家。
                \begin{kk}{客体不适用}
                  \begin{enumerate}
                    \item 消费者合同。购买目的供自用、家人使用、私人使用。
                    \item 特殊的交易方式（\al{拍卖}）、依法律令状进行的销售。
                    \item 特殊标的物。电力、飞机、船舶。
                    \item 有价证券 \hz 货币。\al{企业债券、货币的买卖}。
                  \end{enumerate}
                \end{kk}

                \begin{kk}{内容不涉及}
                  这么记。担保成立。
                  \begin{enumerate}
                    \item 不调整合同的效力，但调整了合同的成立。
                    \item 不调整所有权转移（物权），但规定了所有权担保（债权）。
                    \item 不调整产品责任问题（侵权），但要求卖方承担对买方的质量担保责任（合同）。
                  \end{enumerate}
                \end{kk}

                \begin{kk}{效力任意性}
                  当事人意思自治优先。合同 \dy 公约规定，但约定内容不一样，对公约的排除效力不一样。
                  \begin{enumerate}
                    \item 准据法的选择 \dy 公约适用。在我国，合同中若明确选择准据法，将完全排除公约适用。
                    \item 可以通过合同条款约定部分排除 \hz 改变公约规定。\al{可自行选择贸易术语及版本 \dui}。
                  \end{enumerate}
                \end{kk}
        \end{enumerate}
  \item 卖方义务的特殊要求。交货、交单、知识产权。
        \begin{enumerate}
          \item 交货义务。
                \begin{enumerate}
                  \item 一切以合同记载的规格为准。样品不构成产品的质量标准。
                  \item 分批交货。哪批违约哪批解除/无效。有关联才可扩大到后续批次。
                  \item 宣告无效 = 解除合同。要根本违约！
                \end{enumerate}
          \item 交单义务。
                \begin{enumerate}
                  \item 若提前交单享有在交单时间届满前纠正单据错误的权利，但应赔偿买方损失。
                  \item 其他权利无中生有。\al{可以改变移交单据的地点和方式 \cuo{思路 2，我咋知道合同有没有}}。
                \end{enumerate}
          \item 知识产权担保义务。第三方不能根据知识产权主张任何权利或要求（大白话，不侵犯他人的知识产权）。
                \begin{enumerate}
                  \item 地点。买方营业地、合同预期的货物转售 \hz 使用地。
                  \item 免责。
                        \begin{enumerate}
                          \item 买卖双方知假买假，知假卖假。
                          \item 卖方无过错。\yi 按买方指示供货。\er 买方知情，合理期限内未通知卖方。
                        \end{enumerate}
                \end{enumerate}
          \item 如果有义务归还价款，必须同时从支付价款之日起支付价款利息。
        \end{enumerate}
  \item 买方义务的特殊要求。接收、拒收、验货。
        \begin{enumerate}
          \item 接收义务。
                \begin{enumerate}
                  \item 采取一切理应采取的辅助性工作，以期卖方能交付货物。
                  \item 好不好都得收，不收导致的损失买方承担。
                \end{enumerate}
          \item 拒收权。卖方提前交货、多交（只能拒收多交部分）。
          \item 验货。承担 2 个时间 2 个地点的限制。
                \begin{enumerate}
                  \item 实际可行的最短时间内验货。\al{依自己习惯的时间安排检验 \cuo}。有问题，声明不符的时间为收货后 2 年内。
                  \item 运输目的地就是验货点，卖方已知 + 同意可以延伸到转运目的地。
                \end{enumerate}
        \end{enumerate}
  \item 买卖中间的风险转移。\yi 有约从约 \yjt 交货时。\er 若买卖的是在途货物，买卖合同成立时风险转移。
\end{enumerate}
