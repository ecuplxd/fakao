\section{货物销售合同公约}
\begin{enumerate}
  \item 适用范围。
        \begin{enumerate}
          \item 买卖双方的\zd{营业地}要在不同的国家。
          \item 客体适用范围。
                \begin{kk}{几个不调整}
                  \begin{enumerate}
                    \item 购买目的供\zd{自用、家人使用、私人使用}。
                    \item 特殊的交易方式，依法律令状进行的销售。
                    \item \zd{船舶、飞机、电力}。
                    \item 不是货物的买卖，如企业债券等等以及货币的买卖。
                    \item 不调整合同的效力，但调整了合同的成立。
                    \item 不解决所有权转移，但规定了所有权担保。所有权转移是物权问题，所有权担保是债权问题。
                    \item 不调整产品责任问题，但有质量担保。产品责任是侵权问题，质量担保是合同问题。
                    \item 销售合同公约，自然只能去调整债的关系。
                  \end{enumerate}
                \end{kk}
        \end{enumerate}
  \item 任意性公约。当事人意思自治优先。合同优先于公约规定，但\zd{约定内容不一样，对公约的排除效力不一样}。
        \begin{enumerate}
          \item \qd{准据法的选择优先于公约适用}。合同中若明确选择\zd{准据法}，将\zd{完全排除}公约适用。
          \item 可以通过合同条款约定包括选择\zd{贸易术语，部分排除 \hz 改变公约}。
        \end{enumerate}
  \item 卖方义务的特殊要求。
        \begin{enumerate}
          \item 交单义务。
                \begin{enumerate}
                  \item 若\zd{提前交单}享有在交单时间届满前\zd{纠正单据}错误的权利，但应\zd{赔偿买方损失}。
                  \item 其他权利无中生有。\al{可以改变移交单据的地点和方式}。
                \end{enumerate}
          \item \zd{知识产权担保义务}。第三方不能根据知识产权主张任何权利或要求（不侵犯他人的知识产权）。
                \begin{enumerate}
                  \item 地点。买方营业地，合同预期的转售 \hz 使用地。
                  \item 免责。
                        \begin{enumerate}
                          \item 买卖双方知假买假。
                          \item 按买方的指示供货。
                          \item 卖方有证据证明卖方不知道权利有瑕疵，买方知道。
                        \end{enumerate}
                \end{enumerate}
          \item 如果有义务归还价款，必须同时从支付价款之日起支付价款利息。
          \item 持续交付，只要某一次交付构成根本违约，则整体无效/违约。
          \item 样品不构成产品的质量标准，一切\zd{以合同记载的规格为准}。
        \end{enumerate}
  \item 买方义务的特殊要求。
        \begin{enumerate}
          \item 接收义务。采取一切理应采取的行动，以期卖方能交付货物。拒收权。卖方提前交，卖方多交。
          \item 接受义务。\zd{好不好都得收}，不收导致的\zd{损失买方承担}。
          \item 检验货物。承担 2 个时间 2 个地点的限制。
                \begin{enumerate}
                  \item \zd{最短时间}内要验；有问题，\zd{声明不符}的时间为\zd{收货后 2 年}内。
                  \item 运输目的地就是验货点，\zd{卖方已知 + 同意转运}可以延伸到转运目的地。
                \end{enumerate}
        \end{enumerate}
  \item 买卖中间的风险转移。\yi 一般规则\zd{交货时}。\er 若买卖的是在途货物，买卖\zd{合同成立时}转移。
\end{enumerate}
