\section{公司的董事、监事、高级管理人员}
\begin{enumerate}
  \item \zd{高管。董事长、经理、副经理、财务负责人、董秘、其他（CEO 之类）}。
  \item 消极任职资格。聘任 \yjt 无效，任职期间出现 \yjt 解聘。\zd{政钱 5，破关 33 巨不还钱}。
        \begin{enumerate}
          \item 剥夺政治权利 \hz 因钱获刑 \yjt\, 5 年。
          \item 破产的\zd{董监高、经理、董事、厂长} \yjt\, 3 年。
          \item 违法被关停的法定代理人 \yjt\, 3 年。
          \item 个人欠钱太多还不起。
        \end{enumerate}
  \item 忠实、勤勉义务。常识判断。
  \item 资格丧失同消极任职条件。
\end{enumerate}
