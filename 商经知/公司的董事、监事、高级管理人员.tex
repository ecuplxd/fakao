\section{公司的董事、监事、高级管理人员}
\begin{enumerate}
  \item 高管。经理、副经理、财务负责人、董秘、其他（CEO 之类）。
  \item 消极任职资格。聘任 \yjt 无效，任职期间出现 \yjt 解聘。
        \begin{enumerate}
          \item 因钱获刑 \hz 剥夺政治权利，5 年。
          \item 破产的董监高、经理、董事、厂长，3 年。
          \item 违法被关停的法代，3 年。
          \item 个人欠钱太多。
        \end{enumerate}
  \item 义务。常识判断。
\end{enumerate}
