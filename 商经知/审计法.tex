\section{审计法}
\begin{enumerate}
  \item 不重要，可放弃。
  \item 流程。启动 \yjt 调查 \yjt 报告 \yjt 决定。
  \item \zd{国家审计}、内部审计、外部独立审计。
  \item 审计机关\zd{双重领导}制度 \yjt 审计管辖看隶属关系。\zd{有争议不得协商管辖，直接找上级}。
  \item 审计职责。
        \begin{enumerate}
          \item \zd{范围}。花国家钱的；预算决算；外国援助、贷款项目的财物收支；事关重大（\al{河南村镇银行}）。
          \item 履行。全面审计、专项审计。
          \item 风险隐患通报制度。\zd{报告}本级政府 \hz \zd{通报}有关主管机关。
        \end{enumerate}
  \item \zd{查银行账户。上一级负责人批准}。
\end{enumerate}
