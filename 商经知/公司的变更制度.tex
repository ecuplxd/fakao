\section{公司的变更制度}
\begin{enumerate}
  \item 办理变更登记。重大事项 2/3。
  \item 资本方面。股东会
        \begin{enumerate}
          \item 增加。
                \begin{enumerate}
                  \item 增发股份购买资产。
                  \item 投资者增资处理。平价、溢价。
                \end{enumerate}
          \item 减少。
                \begin{enumerate}
                  \item 资金闲置；亏损严重，名实不符。
                  \item 编制资产负债表，财产清单。盘点。
                  \item 债权人保护制度。10 天内通知（对抗），公告。还钱 \hz 提供担保。
                \end{enumerate}
        \end{enumerate}
  \item 组织结构。
        \begin{enumerate}
          \item 合并。
                \begin{enumerate}
                  \item 吸收、新设合并。
                  \item 保护债权人同减资。
                \end{enumerate}
          \item 分立。
          \item \sjt 不需要清算。概括承继。
        \end{enumerate}
  \item 变更形式。配合上市股改。\zd{有限变股份，折合的实收股本总额不得高于公司的净资产额}。
\end{enumerate}
