\section{公司的变更制度}
\begin{enumerate}
  \item 重大事项 2/3，办理变更登记。
  \item 资本方面。股东会。
        \begin{enumerate}
          \item 增加。\yi 增发股份购买资产。\er 投资者增资。平价、溢价。
          \item 减少。资金闲置；亏损严重，名实不符。盘点。编制资产负债表，财产清单。
                \begin{enumerate}
                  \item 债权人保护制度。仅减资和合并有。要么通知，要么公告 \yjt 还钱 \hz 提供担保。
                        \begin{enumerate}
                          \item 10 日内通知（对抗） \yjt 收到 30 日内 \yjt 要求还钱 \hz 提供担保。
                          \item 30 日内报纸上公告 \yjt 公告之日起 45 日内 \yjt 要求还钱 \hz 提供担保。\al{提异议 \cuo{无权插手}}。
                        \end{enumerate}
                  \item 未经法定程序减资 \ydy 抽逃出资。
                \end{enumerate}
        \end{enumerate}
  \item 组织结构。都不需要清算 \yjt 债权人利益不会受到影响。
        \begin{enumerate}
          \item 合并。
                \begin{enumerate}
                  \item 吸收合并。A + B = A。1 个公司吸收其他公司。
                  \item 新设合并。A + B = C。2 个以上公司合并设立 1 个新公司。
                \end{enumerate}
          \item 分立。权利、义务有约从约 \yjt 概括承继。\al{分立为乙丙，约定乙承担债务，丙承担债权}。
        \end{enumerate}
  \item 变更形式。有限变股份，折合的实收股本总额 \xydy 净资产额（= 时不用另行募集资本）。\al{上市股改}。
\end{enumerate}
