\section{公司的变更制度}
\begin{enumerate}
  \item \zd{重大事项 2/3}，办理变更登记。
  \item 资本方面。股东会。
        \begin{enumerate}
          \item 增加。\yi 增发股份购买资产。\er 投资者增资。平价、溢价。
          \item 减少。资金闲置；亏损严重，名实不符。盘点。编制资产负债表，财产清单。
                \begin{enumerate}
                  \item 债权人保护制度。\zd{未经法定程序减资 \ydy 抽逃出资}。
                        \begin{enumerate}
                          \item 10 天内通知（对抗）\yjt 收到 30 日起。
                          \item 30 日内报纸上公告 \yjt 公告之日起 45 日内。
                          \item \sjt \zd{要求还钱 \hz 提供担保 \dui，提异议 \cuo}。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 组织结构。\xjt 都\zd{不需要清算}。债权人利益不会受到影响。
        \begin{enumerate}
          \item 合并。\zd{有债权人保护制度}。
                \begin{enumerate}
                  \item 吸收合并。A + B = A。一个公司吸收其他公司。
                  \item 新设合并。A + B = C。两个以上公司合并设立一个新公司。
                \end{enumerate}
          \item 分立（无债权人保护制度）。权利、义务有约从约 \yjt 概括承继。\al{分立为乙丙，约定乙/丙承担债务/债权}。
        \end{enumerate}
  \item 变更形式。\zd{有限变股份，折合的实收股本总额 <= 净资产额}（= 时不用另行募集资本）。\al{配合上市股改}。
\end{enumerate}
