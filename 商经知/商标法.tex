\section{商标法}
\begin{enumerate}
  \item 3 分左右。最简单。
  \item 注册商标。能区别。文字、图像、声音（\al{QQ 来消息声音}）、数字、符号。
  \item 分类。
        \begin{enumerate}
          \item 商品、服务商标。
          \item 集体（内部用）、证明（外部用）商标。\al{沙县小吃；绿色食品}。都是组织控制。
        \end{enumerate}
  \item 根本不得使用。
        \begin{enumerate}
          \item 国家、官方、红十字、民族歧视相关。
          \item 欺骗 + 误认。\al{百消灵}。
          \item 品格不高，不良影响。\al{老榴芒}。
          \item 县级以上地名。
                \begin{enumerate}
                  \item 地名还有其他含义，且印象高于地名。\al{长安汽车}。
                  \item 作为集体、证明商标的一部分。\al{烟台苹果；山西陈醋}。
                  \item 已使用的继续有效。\al{青岛啤酒}。
                \end{enumerate}
        \end{enumerate}
  \item 不能注册，可以默默用。
        \begin{enumerate}
          \item 通用名称。\al{水牌矿泉水}。
          \item 仅仅表示商品物理属性特点。\al{发光牌灯泡，光明牌灯泡}。
          \item 其他缺乏显著特征。例外：经过使用后获得显著特征。\al{两面针牙膏}。
        \end{enumerate}
  \item 含有虚假地理标志。作为集体商标、证明商标存在。
  \item 申请。
        \begin{enumerate}
          \item 自愿。强制注册，烟。
          \item 申请在先，使用在先补充。
          \item 不以使用为目的的\zd{恶意}注册。蹭热点，抢热度。防御商标。\al{老干爹}。\zd{商标体系架构}。
          \item 抢注。识人之肥，搭便车。提异议 \hz 5 年申请无效。
          \item 外国人必须委托。
          \item 代理机构的义务。告知、不能助纣为虐、只能帮别人。
          \item 分类填报。同一商标归属不同主体，在不同类别存在。\zd{全品类注册}。一标多类。
        \end{enumerate}
  \item 优先权。6 个月。
  \item 不予注册绝对理由，谁都可以提异议；相对理由，被损害的主体。
  \item 10 年，核准之日起算。
  \item 转让要一并转让。xx 碳酸饮料，xx 果汁。公告之日发生效力。
  \item 许可。备案对抗。
  \item 无效宣告。\zd{注册后}发现不符合。绝对，相对。和商标异议差不多。
        \begin{enumerate}
          \item \zd{注册日 5 年内}申请。\al{乔丹案}。驰名商标 + 恶意除外。
          \item 同专利。自始无效，溯及既往。已执行、履行除外。
        \end{enumerate}
  \item 使用管理。
        \begin{enumerate}
          \item 撤销。自行改变相关信息 \yjt 责令限期改正 \yjt 撤销。
          \item 丧失显著性 \hz 连续 3 年不用。\al{阿司匹林}。冷静期 1 年。
        \end{enumerate}
  \item 侵权。考点集中在这里。
        \begin{enumerate}
          \item 专用权以核准注册的商标和核定使用的商品为限。
          \item 假冒。\al{茅台酒}。
          \item 仿冒。很像，但不完全一样。\al{周住洗衣粉、雷碧}。善意侵权不赔钱。
          \item 造假商标、卖假商标。
          \item 反向假冒。换掉商标 + 再次销售。
          \item 帮助侵权。明知。
          \item 其他。当字号用；类似商品；突出使用。
        \end{enumerate}
  \item 驰名商标。为相关公众所熟知（动态过程）。不能写入判决主文。
        \begin{enumerate}
          \item 不得将字样用于包装、装潢、宣传。\bdy 商品质量。
          \item 没注册的。\ydy 一般的注册商标。没有赔偿一说。
          \item 注册的。
                \begin{enumerate}
                  \item 跨类别保护。他人注册，权利人申请无效不受 5 年限制。
                  \item 把别人商标当字号用，相同类别商品，突出。用字多的侵犯商标权，字少的适用反不正当竞争。
                \end{enumerate}
        \end{enumerate}
  \item 不构成侵权。
        \begin{enumerate}
          \item 描述性使用。\al{下列公司都在用飞书}。
          \item 说明商品 \hz 服务用途。\al{本墨水适用惠普打印机}。
          \item 商标用尽。购买之后。
          \item 通用元素的正常使用。\al{农夫山泉，恒大冰泉}。
          \item 先使用。
        \end{enumerate}
  \item 赔偿。损失 \hz 获利 \yjt 使用费 \yjt 裁量，500W 以下。
\end{enumerate}
