\section{人身保险合同}
\begin{enumerate}
  \item 人身、伤害、健康保险。
  \item 保险金的定额支付。
  \item 不得要求投保人承担违约责任，不得以诉讼方式要求支付保费。
  \item 不适用代位求偿。
  \item 中止与复效。
        \begin{enumerate}
          \item 宽限期。应当缴纳保费之日 60 天 \hz 催告之日 30 天 \yjt 中止期 \yjt\, 2 年，解除合同。
          \item 除非重大变化，否则补交就复效，不得拒绝。
          \item 谎报年龄。大谎解除，退还保单现金价值；小谎不解除，多退少补。
        \end{enumerate}
  \item \zd{死亡险}。
        \begin{enumerate}
          \item 适用宣告死亡，下落之日不明得在期限内。
          \item 无民不得投，不得承。例外：父母给未成年子女。赔付有限额。
          \item 要征得同意（很宽松）+ 认可保险金额。要主动审查。
          \item 未经书面同意不得转让 \hz 质押。
          \item 解除。通知投保人、保险人。双重通知。
        \end{enumerate}
  \item 健康险。
        \begin{enumerate}
          \item 公费医疗赔偿金的扣除。一开始保费就要扣减才行。
          \item 超过医保目录范围。该赔还得赔；超了标准部分可拒赔。\al{10 块青霉素在医保，100 块是进口，赔 10}。
          \item 非约定医疗机构。不支持。例外：急诊，要立即就医的。
        \end{enumerate}
  \item 受益人。被保险人最终决定权，无需征得受益人同意。
        \begin{enumerate}
          \item 为具有劳动关系的只能指定劳动者本人、近亲属。
          \item 变更。通知。
          \item 争议。受益人法定。配偶。
                \begin{enumerate}
                  \item 投保人与被保险人同一。事故发生时关系认定。\al{甲为自己投保，约定妻子受益人后离婚，再婚}。
                  \item 异主体订立。合同成立时。\al{甲为妻投保，约定其配偶为受益人，后其妻离婚改嫁，不日死亡}。
                  \item 约定了姓名和身份，视为没有指定。
                \end{enumerate}
          \item 权利丧失。同民法继承。
        \end{enumerate}
  \item 理赔规则。
        \begin{enumerate}
          \item 无法查明。比例。
          \item 悬空份额。先按顺序再按比例。
          \item 事故发生后可转让。
          \item 没有受益人，作为被保险人遗产处理。
          \item 同时死亡，推定受益人死亡在先。优于民法继承规则。
          \item 保险人不能向第三人代位追偿、追偿。性质不同。\al{甲为其妻投保，被乙撞死}。
        \end{enumerate}
  \item \zd{特殊的人身保险事故}。
        \begin{enumerate}
          \item 不赔。交足 2 年应退。\al{天津杀妻骗保}。
          \item 故意犯罪。同上。
          \item 自杀。非无民 2 年内不赔，退现金价值。
        \end{enumerate}
\end{enumerate}
