\section{人身保险合同}
\begin{enumerate}
  \item 人身、伤害、健康保险。父母、配偶、子女、有抚养关系的近亲属、劳动关系、经过第三人同意。
  \item 谁被保，谁最大 \yjt 事事以他为准，经他同意。
  \item 保险金的定额支付。多买多赔原则。
  \item 不存在重复投保的限制（人身无价）。分别赔偿，互不干扰。
  \item 中止与复效。
        \begin{enumerate}
          \item 宽限期。应当缴费之日 60 日 \hz 催告之日 30 日 \yjt 效力中止期 \yjt 2 年，解除合同。
          \item 除非重大变化，补交就复效，不得拒绝。
          \item 谎报年龄。大谎解除 + 退还保单现金价值。小谎不解除，多退少补 \yjt 真实年龄在要求的范围内。
        \end{enumerate}
  \item 受益人。劳动及近亲；指意变加通；有受受先死；无受变遗产。
        \begin{enumerate}
          \item 为具有劳动关系的投保，只能指定劳动者本人及其近亲属。
          \item 投保人指定受益人时，必须经被保险人同意（拥有最终决定权）。\al{需征得受益人同意 \cuo}。
          \item 变更受益人要经过通知 + 同意。
          \item 权利丧失。同民法继承人资格的丧失。
          \item 同时死亡。推定受益人死亡在先（可以理解成视为没有受益人）。优于民法继承规则。
          \item 没有受益人的，作为被保险人遗产处理。
          \item 受益人不明确。投保时受益人写着法定、配偶之类含糊其辞的表述……以交保费的人为参考系。
                \begin{enumerate}
                  \item 投保人 = 被保险人。事故发生时进行认定。\al{甲为自己投保，约定妻子为受益人，后甲离婚又再婚}。
                  \item 异主体订立。合同成立时。\al{甲为妻乙投保，约定\xhx{其配偶}为受益人，后乙离婚改嫁，不久乙死亡}。
                  \item 约定了姓名和身份，视为没有指定。
                \end{enumerate}
        \end{enumerate}
  \item 死亡险。须同意、认金额、主动审；转书同；未成年、宣告死；除双通。
        \begin{enumerate}
          \item 要征得被保险人同意（方式很宽松）+ 认可保险金额。保险人要主动审查。
          \item 转让 \hz 质押须经书面同意。
          \item 无民仅限父母给未成年子女、赔付有限额。
          \item 宣告死亡适用，但下落之日不明得在保险期内。\al{[2000, 2009.9.1 失踪, 2010 | 2014.4 宣告死亡]}。
          \item 被保险人书面解除，双重通知。投保人、保险人。
        \end{enumerate}
  \item 健康险。扣减公、赔不超。
        \begin{enumerate}
          \item 公费医疗赔偿金的扣除。一开始保费就要扣减这部分的金额。
          \item 超过医保目录范围该赔还得赔，仅超过部分可拒赔。\al{5 块青霉素在医保，进口是 9 块，赔 5}。
          \item 不支持非约定医疗机构。例外。急诊、要立即就医的。
        \end{enumerate}
  \item 理赔规则。无按比；悬先顺、再比例；可转让；无代位。
        \begin{enumerate}
          \item 无法查明。比例。
          \item 悬空份额。顺序 \dy 比例。
          \item 事故发生后可转让。
          \item 保险人不能向第三人代位追偿 \yjt 人身依附性。\al{甲为其妻投保，被乙撞死}。
        \end{enumerate}
  \item 特殊的人身保险事故。小二骗保应退，大二自杀应赔。
        \begin{enumerate}
          \item 故意犯罪、故意杀害被保险人的不赔（丧失受益权）。交足 2 年应退。\al{天津杀妻骗保}。
          \item 自杀。非无民 2 年内不赔，退还保单现金价值。
        \end{enumerate}
\end{enumerate}
