\section{银行业监督管理法}
\begin{enumerate}
  \item 强制信息披露。不要求上市。
  \item 违反审慎经营，限期改正 \yjt  \zd{强制整改}。强监管。
  \item 范围。银行、信托、金融资产管理、财务、金融租赁。
  \item 接管。可能发生信用危机，挤兑。\al{包商银行}。
        \begin{enumerate}
          \item 银监会。重组也是找（最上面的）银监会。
          \item 债权债务关系不消灭。
          \item 接管期 1 + 1。
          \item 针对直接利益关系人限制出境、财产转让等。
          \item 冻结需要申请司法机关。\al{通知 xx 停止 xx \cuo}。
          \item 接管期限届满、破产、恢复能力、合并，应终止接管。
        \end{enumerate}
  \item 破产清算。破产费用 \yjt 共益债务 \yjt 职工债权 \yjt 个人储蓄的存款本金、利息 \yjt 其他社保和税款 \yjt 普通债权。
  \item \zd{做题区分是啥类型的清算}。
\end{enumerate}
