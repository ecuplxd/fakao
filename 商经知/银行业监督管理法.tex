\section{银行业监督管理法}
\begin{enumerate}
  \item 不论是否上市，强制信息披露。
  \item 强监管。违反审慎经营，限期改正 \yjt 强制整改。
  \item 范围。\zx{银行、信托、财务、金融租赁、金融资产管理}。
  \item 接管。\zx{可能}发生信用危机，挤兑。\al{包商银行}。
        \begin{enumerate}
          \item \zx{银监会}。重整也是找（最上面的）银监会。
          \item 债权债务关系不消灭。
          \item 接管期 1 + 1。
          \item 针对直接利益关系人限制出境、财产转让等。
          \item \zx{冻结需要申请司法机关}。\al{通知 xx 停止 xx \cuo}。
          \item \zd{应当终止接管}。接管期限届满、恢复能力、合并、破产。
        \end{enumerate}
  \item 破产清算。破产费用 \dy 共益债务 \dy 职工债权 \dy \zx{个人储蓄的存款本金、利息 \dy 其他社保和税款} \dy 普通债权。
  \item \bs{做题区分是啥类型的清算}。
\end{enumerate}
