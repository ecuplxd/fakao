\section{银行业监督管理法}
\begin{enumerate}
  \item 强制信息披露。不要求上市。
  \item 违反审慎经营，限期改正 \yjt  \zd{强制整改}。强监管。
  \item 接管。信用危机，挤兑。\al{包商银行}。
        \begin{enumerate}
          \item 债权债务关系不消灭。
          \item 不超过 2 年。
          \item 限制出境、财产转让。直接利益关系。
          \item 冻结需要申请司法机关。
        \end{enumerate}
\end{enumerate}
