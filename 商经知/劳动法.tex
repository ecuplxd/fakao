\section{劳动法}
\begin{enumerate}
  \item 劳动者主张加班费的，就加班的事实存在承担举证责任；证据在单位那可以要求单位提供。
  \item 最低工资标准。
  \item 女职工
        \begin{enumerate}
          \item 矿山、井下。第 4 级劳动强度。劳动时间率达到 77\%。
          \item 经期 \yjt 高处低温冷水；孕期、产期；第 3 级。
          \item 怀孕 7 月，不得安排加班、夜班，延长工作时间。
          \item 哺乳不满 1 周岁，不得安排 3 级。
        \end{enumerate}
  \item 未成年工（16 - 18）。
        \begin{enumerate}
          \item 矿山、井下、\zd{有毒有害}、第 4 级。
          \item 上岗前培训。
          \item 定期健康检查。
        \end{enumerate}
\end{enumerate}
