\section{财产保险合同}
\begin{enumerate}
  \item 财产损失、责任保险、保证保险。
  \item 损害填补原则。保险责任以保险金额为限。超出部分无效。
  \item 费用。
        \begin{enumerate}
          \item 施救费用。不超过保险金额、不以产生效果为前提、按比例出。
          \item 勘察/鉴定等费用保险人全额出（因为你本来就有义务去查清）。例外。\zd{骗保、虚报}等投保人导致的。
        \end{enumerate}
  \item 保险标的的转让。23 可能会考。\bs{概括继受、交付获权；不知免责；要么加钱、要么解退}。
        \begin{enumerate}
          \item \zd{受让人概括继受}。\al{甲为私家车投保，免责签字，后卖给乙但未告知免责事项}。
          \item \zd{交付即获权}。交付但未登记，受让人行使权利。同民法风险转移，
          \item 拒赔 = 没通知保险人 + 转让导致的增量风险引发了事故。
          \item 危险增加的处理。2 选 1。危险是否增加，感性认知。\al{甲为私家车投保，后转行去开网约车，发生事故}。
                \begin{enumerate}
                  \item 增加保费。
                  \item \zd{解除 + 退还}保单现金价值。投保人有安全保护义务，构成根本违约。
                \end{enumerate}
        \end{enumerate}
  \item 理赔。\bs{转多少免多少，代位禁止家、组；重复不超总额}。
        \begin{enumerate}
          \item 在保险人赔付之前，被保险人放弃对第三人追偿的，保险人不承担赔偿保险金的责任。
          \item \zd{代位求偿权}（债权的让与）。不得对被保险人的\bs{家庭成员 \hz 其组成人员}行使代位权。\al{保姆}。
          \item 重复保险。通知、共同赔偿不超过总额。
        \end{enumerate}
  \item 责任保险。标的是赔偿责任。\al{第三者责任险、电梯责任险}。
        \begin{enumerate}
          \item 责任确定方式 \yjt 判决、裁决、协商。费用保险公司出。
          \item 第三人代位请求权。被保险人怠于（仅限或诉或裁）找保险公司。
          \item 不及于被保险人的损失、责任确定之日起算诉讼时效。
          \item 常见险种。
                \begin{enumerate}
                  \item 交强险。造成\zd{本车人员、被保险人以外的受害人}的人身伤亡、财产损失。
                  \item 第三者责任险/商业三者险。\bs{标的是车，不看人}。致使第三者遭受人身伤亡 \hz 财产直接损失。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
