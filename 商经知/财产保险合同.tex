\section{财产保险合同}
\begin{enumerate}
  \item 财产损失、责任保险、保证保险。
  \item 损害填补原则。
  \item 限定。保险责任以保险金额为限。超出部分无效。
  \item 施救费用。不超过保险金额。不以产生效果为前提。按比例出。
  \item 勘察/鉴定等费用保险人全额出（因为你本来就有义务去查清事实真相）。例外：\zd{骗保；虚报}等投保人导致的。
  \item \zd{保险标的的转让}。23 可能会考。
        \begin{enumerate}
          \item \zd{受让人概括继受}。\al{甲为私家车投保，免责签字，后卖给乙但未告知免责事项}。
          \item 拒赔 = 没通知保险人 + 转让导致的增量风险引发事故。
          \item 交付但未登记，受让人行使权利。同民法风险转移，\zd{交付即获得权利}。
          \item 危险增加的处理（感性认知）。2 选 1。\al{甲为私家车投保，后转行去开网约车，发生事故}。
                \begin{enumerate}
                  \item 增加保费。
                  \item 解除合同（投保人安全保护义务根本违约，所以很苛刻）。退还保单现金价值。
                \end{enumerate}
        \end{enumerate}
  \item 理赔。
        \begin{enumerate}
          \item 在保险人赔付之前，放弃对第三人追偿的保险人不承担赔偿保险金的责任。
          \item \zd{代位求偿权}（债权的让与）。不得对被保险人的家庭成员 \hz 其组成人员行使代位权。
          \item 重复保险。通知。共同赔偿不超过总额。
        \end{enumerate}
  \item \zd{责任保险}。标的是赔偿责任。\al{第三者责任险；电梯责任险}。
        \begin{enumerate}
          \item 责任确定方式 \yjt 判决、裁决、协商。费用保险公司出。
          \item 第三人代位请求权。被保险人怠于（第三人起诉时）找保险公司。
          \item 不及于被保险人的损失。
          \item 责任确定之日起算诉讼时效。
          \item 常见险种。
                \begin{enumerate}
                  \item 交强险。造成本车人员、被保险人以外的受害人的人身伤亡、财产损失。
                  \item 第三者责任险/商业三者险。\zd{标的是车，不看人}。致使第三者遭受人身伤亡 \hz 财产直接损失。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
