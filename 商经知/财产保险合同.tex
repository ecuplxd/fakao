\section{财产保险合同}
\begin{enumerate}
  \item 财产损失、责任保险、保证保险。
  \item 损害填补原则。
  \item 限定。保险责任以保险金额为限。超出部分无效。
  \item 受损标的的代位权。
  \item 施救费用。不超过保险金额。不以产生效果为前提。比例出。
  \item 勘察/鉴定费用保险人全额出。
  \item \zd{保险标的的转让}。23 可能会考。
        \begin{enumerate}
          \item 拒赔 = 没通知 + 转让导致的增量风险发生的事故。
          \item 受让人概括继受。
          \item 交付但未登记，受让人行使权利。同民法风险转移，交付即获得权利。
          \item 危险增加的处理（感性认知）。增加保费 \hz 解除合同。退还现金价值。可预见的危险除外。
        \end{enumerate}
  \item 重复保险。通知。共同赔偿不超过总额。
  \item 财产损失。\zd{代位求偿权}。债权的让与。相对性。保险人、投保人的求偿权同根同源。
  \item 责任保险。标的是赔偿责任。\al{第三者责任险；电梯责任险}。
        \begin{enumerate}
          \item 责任确定，判决、裁决、协商。费用保险公司出。
          \item 第三人代位请求权。被保险人怠于（第三人起诉时）找保险公司。
          \item 不及于被保险人的损失。
          \item 责任确定之日起算诉讼时效。
        \end{enumerate}
\end{enumerate}
