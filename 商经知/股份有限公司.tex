\section{股份有限公司}
\begin{enumerate}
  \item 不重要。
  \item 设立。
        \begin{enumerate}
          \item 发起。2 - 200 人，半数以上境内有住所。
          \item 募集。\zd{实缴 + 验资}。发起人不得少于 35\%。不能分期。
        \end{enumerate}
  \item 创立大会 \ydy 临时股东。
        \begin{enumerate}
          \item 参会。发起人、认股人。
          \item 表决是否成立；选举董事会成员、监事会成员；审核设立费用；筹办情况；通过章程。
        \end{enumerate}
  \item 股东大会。
        \begin{enumerate}
          \item 不得临时加事项；同股同权；按出席会议人数算。
          \item 累积投票制。选人才有。目的是给小股东放大投票权，集中兵力选自己的人。
        \end{enumerate}
  \item 董事会。必须设立。
        \begin{enumerate}
          \item 董事长。提名 + 过半数董事。
          \item 免责。反对 + 有记载记录。
          \item 全体董事过半数出席，全体董事过半数决议。人数确定的就全体，不确定就出席来算人数。
          \item 决议效力不成立 \yjt 出席的 \hz 同意的人数不够。
        \end{enumerate}
  \item 监事会。必须，不能简化。
  \item 股份转让。不区分对内对外，没有优先购买权。
        \begin{enumerate}
          \item 发起人 1 年内不得转让；上市 1 年内原始股不得转让。
          \item 董监高不得超过自己数量的 25\%；离职半年内。例外：持有太少，1000 股。
          \item 董监高 5\% 不能做短线。
        \end{enumerate}
  \item 股份回购。原则公司不能回购。和有限公司股权回购有些许区别？例外。
        \begin{enumerate}
          \item 减资。10 日内注销。
          \item 合并、分立；因合并、分立异议（反对票）的股东。6 个月内转让 \hz 注销。
          \item 3 小类 3 要求。员工持股激励、可转债、为维护公司价值及股东权益（自己做庄）。
                \begin{enumerate}
                  \item 合计不能超过 10\%；3 年内转让 \hz 注销。
                  \item 可授权董事会（2/3 出席即可）做决议。\al{该回购事项需要通过股东大会决议 \cuo}。
                  \item 不得用任意公积金购买；信息披露 + 公开集中交易。
                \end{enumerate}
          \item 公司持有的本公司股票不得分配利润。
        \end{enumerate}
  \item 上市公司。增加 3 个股东大会的特别决议事项。
        \begin{enumerate}
          \item 独立董事。不能有管理人身份，不能是大股东；占 1/3；1 名会计；最多 5 家；独立性、公正性。
          \item 关联董事回避制度。
          \item 董事会\zd{秘书}。题干出现秘书，隐含为上市公司。
        \end{enumerate}
\end{enumerate}
