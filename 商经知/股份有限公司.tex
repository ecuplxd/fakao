\section{股份有限公司}
\begin{enumerate}
  \item 不重要。
  \item 设立。发起、募集。
  \item 发起。2 - 200 人，半数以上境内有住所。
  \item 实缴 + 验资。发起人不得少于 35\%。
  \item 创立大会。具有临时股东的性质。
        \begin{enumerate}
          \item 参会。发起人、认股人。
          \item 表决。只有人古人。
        \end{enumerate}
  \item 股东大会。
        \begin{enumerate}
          \item 不得临时加事项。
          \item 同股同权。
          \item 累积投票制。放大投票权，集中兵力。选人才有。推荐规则。
          \item 按出席会议人数算。
        \end{enumerate}
  \item 董事会。必须设立。
        \begin{enumerate}
          \item 董事长。提名 + 过半数董事。
          \item 免责。反对 + 有记载记录。
          \item 全体董事过半数出席，全体董事过半数决议。人数确定的就全体，不确定就出席来算人数。
          \item 决议效力的不成立。出席的人数 \hz 同意的人数不够。
        \end{enumerate}
  \item 监事会。必须，不能简化。
  \item 股份转让。不区分对内对外，没有优先购买权。
        \begin{enumerate}
          \item 发起人 1 年内不得转让；原始股上市 1 年内不得转让。
          \item 董监高不得超过自己数量的 25\%；离职半年内。例外：持有太少，1000。
          \item 董监高 5\% 不能做短线。
        \end{enumerate}
  \item 回购。
        \begin{enumerate}
          \item 注销。原则公司不能回购，例外减资。10 天内。
          \item 转让。6 个月。
          \item 3 小类。员工持股激励、可转债、自己做庄。
                \begin{enumerate}
                  \item 合计不能超过 10\%。
                  \item 3 年内转让 \hz 注销。
                  \item 可授权董事会做决议，2/3 出席即可。
                \end{enumerate}
          \item 异议股东回购。只留下合并、分立。
          \item 变相回购。
        \end{enumerate}
  \item 上市公司。
        \begin{enumerate}
          \item 增加 3 个股东大会的特别决议事项。
          \item 独立董事。不能有管理人身份，不能是大股东。占 1/3。独立性、公正性。
          \item 关联董事回避制度。
          \item 董事会秘书。
        \end{enumerate}
\end{enumerate}
