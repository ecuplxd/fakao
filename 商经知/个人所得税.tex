\section{个人所得税}
\begin{enumerate}
  \item 1 道多选题。
  \item 居民个人和非居民个人。住所地 + 该年度累计居住时间（183 日）。
  \item 分类。
        \begin{enumerate}
          \item 综合所得。\zd{累进税率}。劳务报酬（800）、稿酬（800）、特许权使用费、工资/薪金（5000）。
          \item 经营所得。
          \item 利息、股息、红利所得。
          \item 财产租赁、财产转让。
          \item 偶然所得。20\%。\al{中彩票}。
        \end{enumerate}
  \item 免税收入。\bs{国、省、军、外、补助}。
        \begin{enumerate}
          \item \zx{国债、高级别公益奖金}。军以上单位、外国/国际组织。
          \item 补贴、补助、救助。
        \end{enumerate}
  \item 可以减征。省政府报同级人常备案。
  \item 避税 vs 偷、逃、漏、骗。既不违法也不非法/违法。\al{涉嫌 \dui，直接认定构成 \cuo。除非条件很充分}。
\end{enumerate}
