\section{证券法}
\begin{enumerate}
  \item 股票、公司债券、存托凭证。
  \item 证券发行。不得随便改变资金用途。
        \begin{enumerate}
          \item 公开。必须证监会注册。招股说明书。
          \item 非公开。不得公开劝诱。
          \item 平价、溢价 \yjt 计入资本公积、折价 \yjt 禁止。
          \item 注册制。IPO 堰塞湖。交易所审核 \yjt 报证监会注册。
        \end{enumerate}
  \item 公开 + 承销 \yjt 保荐人。
        \begin{enumerate}
          \item 核查；不得预留。
          \item 代销未达 70\% 失败。
        \end{enumerate}
  \item 证券交易。禁止内部人员短线交易。5\% 以上 + 董监高，6 月内倒买倒卖。
  \item 退市。交易所决定。
  \item 禁止行为。内幕交易、利用未公开信息、操纵市场、虚假陈述。
  \item 信息披露。定期报告、临时报告。
  \item \zd{收购}。要约、协议收购。
        \begin{enumerate}
          \item 信息披露。
                \begin{enumerate}
                  \item 达 5\% 时候通知交易所 + 公司 + 公告，3 日内。成为重要股东。举牌。
                  \item 每增减 5\%，报告 + 公告，公告后 3 日内冷静期。
                  \item 5\%后，每增减 1\%，报告。
                  \item 违规买入 36 月没有表决权。
                \end{enumerate}
          \item 要约收购。30\% + 继续收购触发。
        \end{enumerate}
  \item 投资者保护。
  \item 征集股东权利。
  \item 代表人诉讼。\al{康美药业}。
        \begin{enumerate}
          \item 一般的代表人诉讼。主动登记，登记参加。
          \item 特别的。默认参加，除非明确反对。主体特定化为投资者保护机构。50 名委托。
        \end{enumerate}
  \item 证券服务机构。
        \begin{enumerate}
          \item 证券交易所。技术性停牌、临时停市。
          \item 证券公司。经纪、咨询、财务顾问、承销保荐、融资融券、做市、自营。
        \end{enumerate}
\end{enumerate}
