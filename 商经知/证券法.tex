\section{证券法}
\begin{enumerate}
  \item 股票、公司债券、存托凭证。
  \item 证券发行。不得随便改变资金用途（主要用于运营）。
        \begin{enumerate}
          \item 公开。必须在证监会进行注册。招股说明书。
          \item 非公开。不得公开劝诱。
          \item 平价、溢价 \yjt 计入资本公积。\zd{禁止折价发行}。
          \item 注册制。IPO 堰塞湖。交易所审核 \yjt 报证监会注册。
        \end{enumerate}
  \item 公开 + 承销 \yjt 保荐人。核查；不得预留；代销未达 70\% 失败。
  \item 证券交易。禁止内部人员（5\% 以上 + 董监高）短线交易（6 月内倒买倒卖）。
  \item 禁止行为。谁实施处罚谁，与所在公司无关。
        \begin{enumerate}
          \item 内幕交易。
          \item 利用未公开信息。
          \item 操纵市场。
          \item 虚假陈述。
        \end{enumerate}
  \item 信息披露。（定期）报告、临时报告。罚款。个人 50 - 500W，公司 100 - 1000W。
  \item 债券发行。公司均可。
  \item \zd{收购}。目的是为了获得控制权。要约收购、协议收购（单独谈） 2 选 1。
        \begin{enumerate}
          \item 信息披露。记住 \zd{5\%} 这个数。
                \begin{enumerate}
                  \item 首次达 5\% 时候（成为了重要股东） 3 日内报告证监会、交易所 + 通知公司 + 公告 + 禁止交易。
                  \item 每增减 5\%，报告 + 公告 + \zd{6 日冷静期}。
                  \item 5\%后，每增减 1\%，次日内通知 + 公告 + 临时报告。
                  \item 违规买入 2 年没有表决权。
                \end{enumerate}
          \item 协议收购达 30\%，继续收购 \yjt\, \yi 信息披露；\er 变为强制要约收购（不可撤销，但能变更收购条件）。
        \end{enumerate}
  \item 投资者保护。
        \begin{enumerate}
          \item 征集股东权利。
          \item 代表人诉讼。\al{康美药业；獐子岛}。
                \begin{enumerate}
                  \item 一般的代表人诉讼。主动登记，登记参加，判决对登记发生效力。
                  \item 特别的代表人诉讼。
                        \begin{enumerate}
                          \item 50 名委托。
                          \item 被动登记，默认参加，除非明确反对。
                          \item 原告主体特定化为中证中小投资者服务中心（投资者保护机构）。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 证券服务机构。
        \begin{enumerate}
          \item 证券交易所。
                \begin{enumerate}
                  \item 决定退市、技术性停牌、临时停市。
                  \item 国务院批准设立和解散，其他事项证监会批准。
                \end{enumerate}
          \item 证券公司。
                \begin{enumerate}
                  \item 经纪、咨询、财务顾问、承销保荐、融资融券、做市、自营。
                  \item \zd{不得为股东 \hz 股东关联人提供融资 \hz 担保} \yjt 罚款 \yjt 关停。
                  \item 普通投资者要求调解的，不得拒绝。
                  \item 不得对风险承受能力最低类别的投资者销售高于其风险承受能力的产品。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
