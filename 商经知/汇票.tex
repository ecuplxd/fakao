\section{汇票}
\begin{enumerate}
  \item 时出票人签发，委托付款人在见票时 \hz 在指定日期无条件支付确定的金额给收款人 \hz 持票人的票据。
  \item 分为银行汇票、商业汇票。
  \item 绝对记载事项。金额、出票日期、出票人签章。
  \item 出票
        \begin{enumerate}
          \item 附条件无效；一经签发不得撤回（无权要求银行停止付款）。
          \item 出票人\zd{限制背书}（不得转让字样）。
        \end{enumerate}
  \item 背书。上方出让人，下方受让人。应当连续。从上到下，从左到右，前后相续。
        \begin{enumerate}
          \item 转让背书。无需债务人同意；背书人不退出法律关系；背书人有权限制背书。
                \begin{enumerate}
                  \item 回头\blh。A \yjt B \yjt C \yjt A \yjt 对前手没有追索权；A \yjt B \yjt C \yjt D \yjt B \yjt 对后手。
                  \item 部分\blh。将票据金额的一部分转让的背书。无效。
                  \item 期后\blh。被拒绝付款后再背书。违法行为。
                  \item 附条件\blh。所附条件无效，背书行为有效。\al{\scx{7 月 30 号之前}不得转让} \yjt 进行了限制背书。
                \end{enumerate}
          \item 非转让背书。一次性付清；不得再转让。
                \begin{enumerate}
                  \item 质押\blh。生效 = \zd{质押字样} + 签章。
                  \item 委托收款\blh。
                \end{enumerate}
          \item 伪造签章。
        \end{enumerate}
  \item 承兑。远期汇票。
        \begin{enumerate}
          \item 清洁性。否则视为没有承兑。
          \item 保证人。
                \begin{enumerate}
                  \item 连带责任。仅欠缺绝对记载事项（形式审查）免责。代位权（含向前追索）。
                  \item \zd{保证人字样 + 签章}（\al{甲出具一份担保函 \cuo}），否则不构成票据法的保证，只构成民法的保证。
                  \item 附条件。条件无效保证有效。
                  \item 选项什么没约定/写明保证人名称就不承担保证责任，统统错。
                \end{enumerate}
        \end{enumerate}
  \item 付款。恶意 \hz 重大过失 \hz 远期汇票提前付款 \yjt 自行承担责任。
  \item 票据行为的代理。无权代理，签章人承担责任（\zd{无章无责}，但可拒绝追认），无权代理人民事责任。
\end{enumerate}
