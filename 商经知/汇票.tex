\section{汇票}
\begin{enumerate}
  \item 出票人签发，委托付款人在见票时 \hz 在指定日期、无条件支付、确定的金额给收款人 \hz 持票人的票据。
        \yjt 绝对记载事项。金日出票。金额、出票日期、出票人签章。
  \item 分为银行汇票、商业汇票。
  \item 出票。
        \begin{enumerate}
          \item 附条件，条件无效。
          \item 一经签发不得撤回。无权要求银行停止付款。
          \item \zd{出票人限制背书。“不得转让”字样}。\bs{后手无论何种方式取得，不得主张票据权利}。
        \end{enumerate}
  \item 背书。背书应当连续。上方出让人，下方受让人。从上到下，从左到右，前后相续。
        \begin{enumerate}
          \item 转让背书。无需债务人同意、背书人不退出法律关系、背书人限制背书。
                \begin{enumerate}
                  \item 回头背书。A \yjt B \yjt C \yjt A（对前手没有追索权）。A \yjt B \yjt C \yjt D \yjt B（仅对后手有）。
                  \item 部分背书。将票据金额的一部分转让的背书 \yjt 附条件 \yjt 无效。
                  \item 期后背书。被拒绝付款后再背书。违法行为。
                  \item 附条件背书。所附条件无效，背书行为有效。\al{\scx{7 月 30 号之前}\xhx{不得转让} \yjt 进行了限制背书}。
                \end{enumerate}
          \item \zx{非转让背书}。一次性付清、不得再转让。
                \begin{enumerate}
                  \item 质押背书。生效 = “质押”字样 + 签章。\zd{构成民法上的质押合同}。
                  \item 委托收款背书。生效 = “委托收款”字样 + 签章。
                \end{enumerate}
          \item 伪造签章。
        \end{enumerate}
  \item 承兑。远期汇票。
        \begin{enumerate}
          \item 清洁性。否则视为没有承兑。
          \item 保证人。
                \begin{enumerate}
                  \item 连带责任。仅欠缺绝对记载事项（形式审查）免责。代位权（含向前追索）。
                  \item \zd{“保证人”字样 + 签章。否则不构成票据法的保证，只构成民法的保证}。\al{甲出具一份\xhx{担保函} \cuo}。
                  \item 选项什么没约定/写明被保证人名称、保证时间就不承担保证责任，统统错。
                  \item 附条件。条件无效，保证有效。部分保证 = 附条件。
                \end{enumerate}
        \end{enumerate}
  \item 付款。恶意 \hz 重大过失 \hz 远期汇票提前付款 \yjt 自行承担责任。
  \item 票据行为的代理。
        \begin{enumerate}
          \item 无权代理 \yjt 效力待定 \yjt 签章人承担责任，除非拒绝追认。
          \item 无章无责 \yjt 无权代理人仅承担民事责任。
        \end{enumerate}
\end{enumerate}
