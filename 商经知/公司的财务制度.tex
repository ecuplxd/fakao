\section{公司的财务制度}
\begin{enumerate}
  \item 不是重点。
  \item 外部审计。\al{自行审计 \cuo}。
  \item 收益分配制度。\al{甲公司 5000W 资本，亏损 3000W，法定公积金剩余 5W，年底利润 7000W}。
        \begin{enumerate}
          \item 以利润存在为前提。\zd{虚增利润构成抽逃出资}。
          \item 弥补亏损。法定公积金不足 \yjt 用当年利润弥补。\al{弥补 3000W 亏损剩 4000W}。
          \item 先 \zd{25\%} 企业所得税 \yjt \zd{10\%} 法定公积金。\al{提 400W 法定公积金剩 3600W \yjt Opt(任意公积金)}。
          \item 分错了退回。
        \end{enumerate}
  \item 公积金制度。
        \begin{enumerate}
          \item 法定公积金达 \zd{50\%} 后可提可不提。\al{最高 2500W}。
          \item 法定公积金转增注册资本。留存 \dydy 注册资本 \zd{25\%}。\al{最低 1250W}。
          \item 资本公积金 = 实缴出资 - 注册资本。
                \begin{enumerate}
                  \item 平衡新老股东利益。溢价增资。
                  \item \zd{不能用于弥补亏损}。不是赚来的，无法反映生产经营状况。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
