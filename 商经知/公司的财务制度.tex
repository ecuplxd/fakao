\section{公司的财务制度}
\begin{enumerate}
  \item 不是重点。
  \item \zx{外部审计}。\al{自行审计 \cuo}。
  \item 收益分配制度。\al{甲公司 5000W 资本，亏损 3000W，法定公积金剩余 5W，年底税后利润 7000W}。
        \begin{enumerate}
          \item 以利润存在为前提。\zx{虚增利润构成抽逃出资}。
          \item 弥补亏损。法定公积金不足以弥补 \yjt 用当年利润弥补。\al{弥补 3000 亏损剩 4000}。
          \item 先 \zx{25\%} 企业所得税 \yjt \zx{10\%} 法定公积金。\al{提 400 法定公积金剩 3600 \yjt Opt(任意公积金)}。
          \item 任意公积金。股东会 \hz 股东大会决定。
          \item 可分配利润。\al{7000 - (3000 - 5) - 400 = 3605}。分错了退回。
        \end{enumerate}
  \item 公积金制度。\bs{一半一半}。
        \begin{enumerate}
          \item 法定公积金达 \zd{50\%} 后可提可不提。\al{5000 * 0.5 = Max(2500)}。
          \item 法定公积金转增注册资本。\zx{留存 \dydy 注册资本 25\%}。\al{5000 * 0.25 = Min(1250)}。
          \item \zx{资本公积金 = 实缴出资 - 注册资本}。
                \begin{enumerate}
                  \item 平衡新老股东利益。溢价增资。
                  \item \zx{不能用于弥补亏损}。不是赚来的，无法反映生产经营状况。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
