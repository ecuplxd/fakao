\section{公司的财务制度}
\begin{enumerate}
  \item 不是重点。
  \item 外部审计。
  \item 收益分配制度。
        \begin{enumerate}
          \item 利润存在为前提。虚增利润构成抽逃出资。
          \item 亏损。法定公积金 \yjt 利润。
          \item 25\% 企业所得税 \yjt\, 10\% 法定公积金。\al{1000W - 250W = 750W - 75W = 675W \yjt\, Opt(任意公积金)}。
          \item 法定公积金达 50\% 后可提可不提。
          \item 分错了退回。
        \end{enumerate}
  \item 公积金制度。
        \begin{enumerate}
          \item 转增注册资本。留存不得少于注册资本 25\%。
          \item 资本公积金。实际缴付的出资超过注册资本的差额。
                \begin{enumerate}
                  \item 平衡新老股东利益。溢价增资。
                  \item 不能用于弥补亏损（不是赚来的，无法反映生产经营状况）。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
