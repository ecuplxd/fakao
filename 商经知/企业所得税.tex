\section{企业所得税}
\begin{enumerate}
  \item 个人独资、合伙不在内。和国籍没有必然联系。
  \item 居民企业。依我国法律在我国境内设立 \hz 主要经营管理机构在境内；非居民企业（境内收入、有联系收入）。
  \item 营业地办（180 日）理税务登记手续。\al{甲 A 省成立，18 年 2 月到 10 月临时将营业设备人员派往 B 省}。
  \item \zd{不征税收入}。财政拨款、行政事业性收费、政府性基金（\al{电影专项基金}）、国务院规定的其他。
  \item 优惠。
        \begin{enumerate}
          \item \zd{公}益性捐赠支出，年度利润总额 12\% 当年扣，超过 12\%以后 \zd{3} 年内。
          \item \zd{亏}损年度，向以后年度结转，不超过 \zd{5} 年。
          \item \zd{免税收入/免税项目}。\zd{国}债利息、\zd{权}益性投资收益、\zd{公}益。
          \item 可以减征、免征。\zd{农}业类、\zd{基}建类、\zd{产}业政策类。
          \item 加计扣除。研发费用；\zd{安置工资}。
        \end{enumerate}
  \item \zd{不征税收入和免税收入是两个不同的概念。做题注意严格区分}。
  \item 代为记账。取消“经税务机关认可”程序。
\end{enumerate}
