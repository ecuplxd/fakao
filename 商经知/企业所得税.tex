\section{企业所得税}
\begin{enumerate}
  \item \bs{个人独资、合伙不在内}。
  \item 对象。和国籍没有必然联系。
        \begin{enumerate}
          \item 居民企业。依我国法律在我国\zd{境内设立} \hz 主要经营管理机构\zd{在境内}。
          \item 非居民企业。有境内收入、有联系收入。
          \item \zx{\dydy 180 日}，营业地办理税务登记手续。\al{甲 A 省成立，18 年 1 月到 9 月临时将营业设备、人员派往 B 省}。
        \end{enumerate}
  \item \bs{不征税收入。拨款、收费、基金}。
        \begin{enumerate}
          \item 财政拨款。
          \item 行政事业性收费。
          \item 政府性基金。\al{电影专项基金}。
          \item 国务院规定的其他。
        \end{enumerate}
  \item 优惠措施。\bs{公 123 亏 5；免税国、权、公；免征农、基、政；加计扣研、安}。
        \begin{enumerate}
          \item 公益性捐赠支出。年度利润总额 12\% 当年扣，超过 12\%以后 3 年内。
          \item 亏损年度。向以后年度结转，不超过 5 年。
          \item \zd{免税}收入/免税项目。国债利息、权益性投资收益、公益。
          \item 可以\zd{减征、免征}。农业类、基建类、产业政策类。
          \item \zd{加计扣除}。研发费用、\bs{安置工资}。
        \end{enumerate}
  \item \bs{不征税、免税、免征是 3 个不同的概念。做题注意严格区分}。
  \item 代为记账。取消“经税务机关认可”程序。
\end{enumerate}
