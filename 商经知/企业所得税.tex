\section{企业所得税}
\begin{enumerate}
  \item 个人独资企业、合伙企业不在内。和国籍没有必要联系。
  \item 居民企业；非居民企业。
  \item \zd{不征税收入}。财政拨款、 行政事业性收费、政府性基金（电影专项基金）、国务院规定的其他。
  \item 优惠。
        \begin{enumerate}
          \item 公益性捐赠支出，年度利润总额 12\% 当年扣，超过结转以后 3 年内。
          \item 亏损年度，向以后年度结转，不超过 5 年。
          \item \zd{免收收入}。国债利息、权益性投资收益、扶持公益所得收入。
          \item 可以减征、免征。涉及农业、基建类、产业政策类。
          \item 加计扣除。研发费用；安置费。
        \end{enumerate}
\end{enumerate}
