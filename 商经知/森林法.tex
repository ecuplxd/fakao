\section{森林法}
\begin{enumerate}
  \item 森林资源所有权。国家、集体。
  \item 林木所有权。符合常识。
  \item 确权。同土地权属纠纷。
  \item 森林保护。县以上林业主管部门。
        \begin{enumerate}
          \item 林地保护。
                \begin{enumerate}
                  \item 占用林地控制总量。
                  \item 建设工程占用林地 = 县以上林业主管部门审核同意 + 建设用地审批手续。
                  \item 公益林。国务院 + 省政府划定，调整找原划定机关。
                        \begin{enumerate}
                          \item 涉及非国有林地 \yjt 补偿。
                          \item 林分改造，森林抚育 \yjt 提高质量和保护功能。
                          \item 适度开展林下经济、森林旅游。
                        \end{enumerate}
                  \item 商品林。不重要。
                \end{enumerate}
          \item 林地使用。林业配套工程设施不需要审批。
          \item 林木采伐。
                \begin{enumerate}
                  \item 控制年采伐量、伐育同步。
                  \item 采伐许可证。县以上林业主管部门核发。发放遵循年采伐限额。
                        \begin{enumerate}
                          \item 自留山、个人承包 \yjt 一大片 \yjt 县以上政府 \hz 委托乡镇政府。
                          \item 房前屋后、自留地 + 零星 \yjt 一小片 \yjt 不需要。
                        \end{enumerate}
                  \item 移植林木按照采伐林木进行管理。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
