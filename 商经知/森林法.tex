\section{森林法}
\begin{enumerate}
  \item 森林资源所有权。国家、集体。
  \item 林木所有权。符合常识。
  \item 权属争议解决。结合行政法，复议前置。
        \begin{enumerate}
          \item 单位之间 \yjt 县以上政府。
          \item 个人之间，个人单位 \yjt（乡镇 \hz 县以上）\yjt 行政诉讼。同土地权属纠纷。
        \end{enumerate}
  \item 森林保护。
        \begin{enumerate}
          \item 林地保护。
                \begin{enumerate}
                  \item 占用林地控制总量。
                  \item \zd{建设工程占用林地 = 县以上林业主管部门审核同意 + 建设用地审批手续}。
                  \item 公益林。
                        \begin{enumerate}
                          \item 国务院 + 省政府划定，调整找原划定机关。
                          \item 涉及非国有林地，补偿。
                          \item 林分改造，森林抚育 \yjt 提高质量和保护功能。
                          \item \zd{适度}开展林下经济，森林旅游。
                        \end{enumerate}
                  \item 商品林。不重要。
                \end{enumerate}
          \item 林地使用。直接为\zd{林业生产经营服务的工程设施}不需要审批。
          \item 林木采伐。\zd{严格控制森林的年采伐量}；伐育同步。
          \item 采伐许可证。
                \begin{enumerate}
                  \item 房前屋后，自留地 + 零星不需要；移植林木按照采伐林木进行管理。
                  \item 县以上林业主管部门核发。
                  \item 自留山 \hz 个人承包 \yjt 县以上\blh\, \hz 委托乡镇政府
                  \item 发放遵循年采伐限额。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
