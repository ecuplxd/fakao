\begin{enumerate}
  \item 不重要。
  \item 集合投资、分散风险、专业管理。
  \item 分类。
        \begin{enumerate}
          \item 公募。不特定 \hz 特定 200 人；打款成立，证监会备案生效。
          \item 私募。合格投资者。

  \item 主体。
        \begin{enumerate}
          \item 管理人。基金管理公司。最低注册资本 1 亿，实缴。证监会核准。私募向基金业协会备案。
        \end{enumerate}
  \item 老鼠仓。
\end{enumerate}
