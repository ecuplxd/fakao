\section{证券投资基金法}
\begin{enumerate}
  \item 不重要。
  \item 集合投资、分散风险、专业管理。
  \item 分类。
        \begin{enumerate}
          \item 公募。不特定 \hz 特定 200 人、打款成立、证监会备案生效。
          \item 私募。合格投资者 \xydy 200、向基金业协会备案。
        \end{enumerate}
  \item 主体。管理人。基金管理公司。最低注册资本 1 亿，实缴。证监会核准。
  \item 老鼠仓。
  \item 开放式基金应当保持足够的现金 \hz 政府债权，以备支付赎回款项。
\end{enumerate}
