\section{公司的能力}
\begin{enumerate}
  \item 权利能力、行为能力、对外投资。
  \item 经营范围是登记事项。
  \item \bs{担保能力}。民商结合。决议前置，保护中小股东利益。
        \begin{enumerate}
          \item \zx{为关联方（股东 \hz 实际控制人）。股决议}、过半数（一般事项）、利害关系人\zd{表决权回避}。
          \item \zx{为非关联方。董股决议}。
          \item \zx{越权担保}。大概率考表见代表。
                \begin{enumerate}
                  \item \zd{善意相对人}（对签章、决议类型等\zd{形式审查}）则有效。
                        \al{甲公司在西安创立分公司，委托乙运营业务，乙伪造同意担保的股东决议提供给银行}。
                  \item 双方\zd{都有过错，不超过 1/2}。\al{不担责 \cuo}。
                \end{enumerate}
          \item \zx{决议豁免}。未经决策，担保有效的情形。一事一授权。
                \begin{enumerate}
                  \item 金融机构开立保函 \hz 担保公司提供担保。
                  \item \zx{公司为全资子公司提供担保}。提供担保时的公司承担责任。\xjt 不适用于上市公司对外提供担保。
                  \item 担保合同由[单独 \hz 共同]持有 \bs{2/3} 以上，对担保事项有\bs{表决权}的股东签字同意。
                \end{enumerate}
          \item 答题逻辑。\bs{哪种类型的担保 \yjt 不存在决议豁免的情形}。
        \end{enumerate}
\end{enumerate}
