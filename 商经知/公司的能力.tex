\section{公司的能力}
\begin{enumerate}
  \item 权利能力。
  \item 行为能力。
  \item 对外投资。
  \item 经营范围是登记事项。
  \item 担保能力。民商结合。
        \begin{enumerate}
          \item 为非关联方。董事会、股东会决定。
          \item \zd{为关联方}。为（股东 \hz 实际控制人）（回避，无表决权）提供担保 \yjt 股东会，半数。
          \item \zd{越权担保}。善意（合理形式审查）相对人则有效。双方都有过错，不超过 1/2。
          \item 未经决策，担保有效的情形。
                \begin{enumerate}
                  \item 金融机构保函 \hz 担保公司提供担保。
                  \item 公司为全资子公司提供担保。
                  \item 单独 \hz 共同持有 2/3 以上，对担保事项有表决权的股东签字同意。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
