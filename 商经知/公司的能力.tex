\section{公司的能力}
\begin{enumerate}
  \item 权利能力、行为能力、对外投资。
  \item 经营范围是登记事项。
  \item \bs{担保能力}。民商结合。\al{甲公司在西安创立分公司，委托乙运营业务，乙伪造同意担保的股东决议提供给银行}。
        \begin{enumerate}
          \item \zd{为关联方}（股东 \hz \zd{实际控制人}）。股东会、利害关系人\zd{回避；半数}通过（一般事项）。
          \item 为非关联方（为他人）。决定主体 + 董事会。
          \item \zd{越权担保}。善意相对人（\zd{对签章、决议类型形式审查}）则有效。\zd{双方都有过错，不超过 1/2}。\al{不担责 \cuo}。
          \item 未经决策，担保有效的情形。
                \begin{enumerate}
                  \item 金融机构开立\zd{保函 \hz 担保公司}提供担保。
                  \item 公司\zd{为全资子公司提供担保}。\xjt 不适用于上市公司对外提供担保。
                  \item 担保合同由单独 \hz 共同持有 \zd{2/3} 以上，对担保事项有\zd{表决权的股东签字}同意。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
