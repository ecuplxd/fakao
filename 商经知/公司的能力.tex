\section{公司的能力}
\begin{enumerate}
  \item 权利能力、行为能力、对外投资。
  \item 经营范围是登记事项。
  \item \bs{担保能力}。民商结合。决议前置，保护中小股东利益。
        \begin{enumerate}
          \item \zx{为关联方}（股东 \hz \zd{实际控制人}）。\zx{股决议、过半数}（一般事项）、利害关系人\zx{表决权回避}。
          \item \zd{为非关联方。董股决议}。
          \item \zx{越权担保}。表见代表。
                \begin{enumerate}
                  \item 善意相对人（对签章、决议类型等\bs{形式审查}）则有效。
                        \al{甲公司在西安创立分公司，委托乙运营业务，乙伪造同意担保的股东决议提供给银行}。
                  \item \zx{双方都有过错，不超过 1/2}。\al{不担责 \cuo}。
                \end{enumerate}
          \item 决议豁免。未经决策，担保有效的情形。一事一授权。
                \begin{enumerate}
                  \item 金融机构开立\zx{保函 \hz 担保公司}提供担保。
                  \item 公司\zx{为全资子公司提供担保}。\zd{提供担保时}的公司承担责任。\xjt 不适用于上市公司对外提供担保。
                  \item 担保合同由单独 \hz 共同持有 \zx{2/3} 以上，对担保事项有\zx{表决权的股东签字}同意。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
