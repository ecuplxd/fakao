\section{普通合伙企业}
\begin{enumerate}
  \item 4 分左右。不考主观题。
  \item 4 个共同。共同出资、共同经营、共享收益、共担风险（无限责任）。
  \item 适合小规模小风险的领域，追求成本可控。
  \item 设立。
        \begin{enumerate}
          \item 2 人以上。排除\zd{国有、上市、公益性、社会团体}（因为是无限责任）。
          \item 书面合伙协议，签名生效。补充、修改一致同意。
          \item 可以劳务出资。协商。
          \item 非货币出资，协商 + 评估。
          \item 标明普通合伙字样。
        \end{enumerate}
  \item 财产的管理与便用。共同共有。
        \begin{enumerate}
          \item 请求分割。清算之前。
          \item 生产经营所得，合伙人分别缴纳所得税。
          \item 财产份额 \ydy 股权。是权益概念，有身份属性。
          \item 转让。
                \begin{enumerate}
                  \item 对内通知即可，没有优先购买权。
                  \item 对外，\zd{一致同意}，优先权。
                \end{enumerate}
          \item 财产份额的出质质押。\zd{未一致同意，一律无效}，该合伙人承担赔偿责任。登记生效。
        \end{enumerate}
  \item 决议。
        \begin{enumerate}
          \item 一般事项。原则 1 人 1 票，不看出资，全体过半数。
          \item 特别事项。一致同意。破坏人合性、风险大的。内外有别。
                \begin{enumerate}
                  \item 改名、经营范围、营业地点、协议。
                  \item 处分（出售、抵押）不动产、知识产权、财产份额。
                  \item 聘任管理人、吸收新合伙人。
                  \item 提供担保。自我交易。
                \end{enumerate}
        \end{enumerate}
  \item 执行。灵活。同等权利。
        \begin{enumerate}
          \item 异议权。事前监督，会导致暂停。
          \item 监督权。事后监督，不执行的主体。
          \item 委托权的撤销。
          \item 外聘经营管理人。授权范围内。
        \end{enumerate}
  \item 合伙人义务。竞业禁止 \yjt 绝对禁止；自我交易 \yjt 相对禁止。
  \item 利润分配，亏损分担。约定（都得分，否则无效）\yjt 协议 \yjt 协商 \yjt 实缴出资比例 \yjt 平均。
        \begin{enumerate}
          \item 合伙债务。先合伙，再个人无限。有先后。
          \item 个人债务禁止抵销，禁止代位。\al{甲欠乙 10W，乙欠甲合伙 10W}。
                \begin{enumerate}
                  \item 个人财产 \yjt 所获收益清偿 \yjt 份额。
                  \item 法院强制执行。通知全体。不买，不同意，退伙结算。
                  \item 优先还个人。
                \end{enumerate}
        \end{enumerate}
  \item 入伙和
        \begin{enumerate}
          \item 如实告知义务。对之前的债务无限责任。
          \item 约定陷阱。前后划定，内外有别。
          \item 继承。走新入伙规则。
        \end{enumerate}
  \item 退伙。
        \begin{enumerate}
          \item 自愿。约定期限说走就走，没约定提前 30 天。
          \item 法定。死亡；丧失偿债能力；宣告破产；许可资格丧失；全部份额强制执行。\zd{主体资格出问题}。
          \item 除名。犯错误。
          \item \zd{退伙前原因导致的债务退伙后依然无限连带责任}。
        \end{enumerate}
  \item 特殊普通合伙企业。
        \begin{enumerate}
          \item 特殊的债务承担。故意，重大过失。捣乱的无限连带，无辜的有限责任。
          \item 特殊的行业限制。专业知识、专业技能。律师、会计、资产评估。
        \end{enumerate}
\end{enumerate}
