\section{公司法的基础理论}
\begin{enumerate}
  \item 理解为主。实践法，不创造规则，是对商事规则加以确认。
  \item 股东的有限责任。以认缴的出资额为限。取消了最低注册资本的要求（1 元都行！！）。
  \item 公司的独立法人地位。名义、财产、责任独立 \yjt 法人人格否认制度。权利滥用、谁决策谁连带、举证倒置。
        \begin{enumerate}
          \item 人格、财产混同导致的。正向（横向、纵向）、逆向（起诉一人有限公司的股东）混同。
          \item 过度支配、控制地位。
                \begin{enumerate}
                  \item \al{甲乙设立丙，丁系甲子公司，甲让丙以高于市场的价格从丁进货}。
                  \item 子公司为母公司提供担保。
                \end{enumerate}
          \item 资本显著不足。投入的资本数额与经营所隐含的风险明显不匹配。
          \item 法人人格否认之诉。
                \begin{enumerate}
                  \item 债权已经由生效裁判确认，另行提。股东为被告，公司为第三人。
                  \item 提债权诉讼时，一并提。股东、公司共同被告。
                  \item 债权尚未经生效裁判确认，直接提。释明 \yjt 不追加 \yjt 裁定驳回起诉。
                \end{enumerate}
        \end{enumerate}
  \item 诉讼地位总结。好像确实可以从民诉原理推。
        \begin{enumerate}
          \item 股东资格确认之诉。公司为被告，其他利害关系人为第三人。
          \item 分红权之诉。公司为被告。
          \item 查账权之诉。
          \item 直接诉讼。
          \item 代表诉讼。股东是原告，侵权人是被告，公司为第三人，相同诉讼请求的其他股东列为共同原告。
          \item 决议效力之诉。公司为被告，决议涉及的其他利害关系人为第三人。
        \end{enumerate}
  \item 公司的所有权和经营权。
        \begin{enumerate}
          \item 合一。效率高、专业度低。
          \item 分离。授权。11 个董事 \yjt 董事会，日常经营决策|执行权 \yjt 高级管理人员 ← 监事。
        \end{enumerate}
\end{enumerate}
