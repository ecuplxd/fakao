\section{公司法的基础理论}
\begin{enumerate}
  \item 理解为主。实践法，不创造规则，是对商事规则加以确认。
  \item 股东的有限责任。以认缴的数额为限。
  \item 独立法人地位。名义、财产、责任独立。
  \item \zd{法人人格否认制度}。哪个股东滥用权利，逃避债务，哪个连带责任，个案适用。
        \begin{enumerate}
          \item 人格混同。财产混同导致的。举证倒置。
          \item 过度的支配和控制。大股东的工具。
          \item 资本显著不足。
          \item 横向否定。控制子公司，子公司连带。
        \end{enumerate}
  \item 所有权和经营权。
        \begin{enumerate}
          \item 合一。效率高，专业度低。
          \item 分离。授权，11 个董事 \yjt 董事会，日常经营决策|执行权 \yjt 高级管理人员 ← 监事。
        \end{enumerate}
\end{enumerate}
