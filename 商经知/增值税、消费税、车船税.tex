\section{增值税、消费税、车船税}
\begin{enumerate}
  \item 不重要。重点在它们的优惠措施。
  \item 增值税。考的少。
        \begin{enumerate}
          \item 进口货物要交，出口不用。
          \item 免征。自产农产品；古旧图书；避孕物品；科技实验；残疾人；二手货。
        \end{enumerate}
  \item 消费税。入条例的才需要。奢侈品；环境压力。
  \item 车船税。
        \begin{enumerate}
          \item 免征。捕捞养殖渔船；武警军队；警用；救援；外国驻华使领馆。
          \item 办理机动车强制保险的保险机构代缴代扣。
          \item 取得管理权的当月。
        \end{enumerate}
\end{enumerate}
