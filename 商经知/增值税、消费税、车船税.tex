\section{增值税、消费税、车船税}
\begin{enumerate}
  \item 不重要。重点在它们的优惠措施。
  \item 增值税。考的少。
        \begin{enumerate}
          \item \zd{进口货物}要交，出口不用。
          \item 销售货物、提供应税劳务（范围非常广）。
          \item \zd{起征点的范围只限于个人}。
          \item 免征。\zx{自产}农产品、古籍、避孕物品、科技实验、残疾人、二手货。
        \end{enumerate}
  \item 消费税。\zd{纳入条例的才需要}。奢侈品、\zx{环境压力}。
  \item 车船税。
        \begin{enumerate}
          \item \zx{免征}。捕捞养殖渔船、武警、军队、警用、救援、外国驻华使领馆。
          \item \zx{取得管理权的当月}。
          \item 办理机动车强制保险的\zx{保险机构代缴代扣}。
        \end{enumerate}
\end{enumerate}
