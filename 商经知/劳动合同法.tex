\section{劳动合同法}
\begin{enumerate}
  \item 最重要。
  \item 劳动关系。主体特定，一方是劳动者，另一方是\zd{单位}。
  \item 兼具人身性、财产性、平等性和\zd{从属性}（管理和被管理）。快递用工，用承包合同规避。
        \begin{enumerate}
          \item 可以自己安排工作强度、节奏，不需要听从安排。
          \item 丢件罚你钱。
          \item 都是虚的，关键是如何转化为实招（运用到实践）。
          \item 劳动争议，首先注意认定劳动关系是起点，从从属性着手。
        \end{enumerate}
  \item 无固定期限合同。
        \begin{enumerate}
          \item 协商一致。
          \item \zd{法定情形}。连续满 10 年（国企退休不到 10 年）；2 次固定，第 3 次无固定，2 + 1 规则。
          \item 视为。没签合同，工作满 1 年。
          \item 违反。从应当订立之日起，每月 2 倍工资。
        \end{enumerate}
  \item 劳动合同。必须书面。
        \begin{enumerate}
          \item 签订。
                \begin{enumerate}
                  \item 签合同在先，用工在后，用工之日起建立劳动关系（应届生）。
                  \item 个人原因拒签，第 1 个月只给工资，2 - 12 单位终止工资 + 经济补偿。
                \end{enumerate}
          \item 内容。
                \begin{enumerate}
                  \item 当事人信息；期限；工作内容和地点；工作时间、休息、休假；劳动报酬；社会保险。
                  \item 可备条款。
                        \begin{enumerate}
                          \item 试用期。
                                \begin{itemize}
                                  \item 3 月内 \yjt 不能约定；3 - 1 年 \yjt 1 月；1 - 3 \yjt 2 月；3+ \yjt 6 月。
                                  \item 只约定试用期无效；只能约定 1 次；包含在劳动期限内。
                                \end{itemize}
                          \item 服务期。专项培训费用，专业技术培训，5 年；违约金不超过分摊费用。
                          \item 保密条款。约定的；可有偿可无偿。
                          \item \zd{竞业限制}。焦土政策，无所不用其极。
                                \begin{itemize}
                                  \item 2 高 1 保人员；需单独约定；最长 2 年。
                                  \item 竞争关系。不能仅以营业范围重合认定；主营业务。
                                  \item 补偿。有约从约；无约 12 月平均工资 30\% 按月支付；3 个月没支付，免除。
                                  \item \zd{单位可以要求劳动者支付违约金 + 继续履行竞业限制}。
                                  \item \qd{按照国家规定、标准、行业规定，不要默认这个是对你有利的}。
                                \end{itemize}
                        \end{enumerate}
                  \item \zd{只有服务期和竞业限制可以要求违约金}。\al{解决户口，如果 xx 违约金}。
                \end{enumerate}
          \item 解除。考题集中在这。
                \begin{enumerate}
                  \item 协议解除。单位先提要给补偿金。
                  \item 劳动者单方解除/预告解除。试用期提前 3 天，口头书面均可；正式期提前 30 天，书面。
                  \item 劳动者任意解除/过错解除。当天，说走就走。
                        \begin{enumerate}
                          \item 未提供劳动保护，劳动条件；欠薪；没有缴纳社会保险。
                          \item 违法违规，\al{996、007、末位淘汰}。
                          \item 因为单位采取 996 这种规章制度，违反法律法规损害我的利益，所以我今天就离职了。
                        \end{enumerate}
                  \item 单位。
                        \begin{enumerate}
                          \item 协商、调岗前置。
                          \item 严重违反单位规章制度。不能违反法律法规。这个规章制度得告知员工。\al{禁止办公室恋情}。
                          \item 经济性裁员。20 人 \hz 10\%；仅这 3 个程序。30 天\zd{说明}情况，\zd{听取}意见，报告；应当\zd{优先}留/招用。
                          \item 职业病，离职前健康检查。
                          \item 单方解除，通知工会。
                        \end{enumerate}
                \end{enumerate}
          \item 终止。届满有留人义务。
          \item 经济补偿金。0、n、n + 1、2n。预告或裁员等方式，合法与劳动者解除劳动合同。
                \begin{enumerate}
                  \item 每满 1 年，多支付 1 个月；6 月 - 1 年算满 1 年；不满 6 月，算半个月。
                  \item 上限。所在地上年度职工月平均工资 * 36。
                  \item 违法解除 \hz 终止。继续履行 \hz 拿赔偿金，2 倍。
                  \item 可协商。
                \end{enumerate}
          \item 延长工时。\zd{136}。一般每日不得超过 1 小时，特殊每日不得超过 3 小时，每月不得超过 36 小时。
        \end{enumerate}
  \item 集体合同。
  \item 劳务派遣。同民法。补充形式；不得超过 10\%。侵权参照民法。
        \begin{enumerate}
          \item 用人单位，用工单位。
          \item 临时性 \yjt 6 月 \hz 辅助性 \yjt 非主营业务/核心/管理岗位 \hz 替代性 \yjt 正式工脱产了。
          \item 劳务派遣单位。行政许可前置；1 次签 2 年；禁止自设自派。
          \item 不得分割用工期限。
          \item 过错，不适岗用工单位才能退。
          \item 造成他人的损害应由用工单位承担责任，劳务派遣单位有过错的，相应的责任。并非连带责任。
        \end{enumerate}
  \item 非全日制用工。
        \begin{enumerate}
          \item 小时计酬，每天不超 4 小时，每周不超 24 小时。
          \item 工资支付周期最长不得超过 15 日。
        \end{enumerate}
  \item 工会。
\end{enumerate}
