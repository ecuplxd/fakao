\section{环境影响评价法}
\begin{enumerate}
  \item 适用范围。编制\zd{规划}、建设\zd{项目}（全局的）。
  \item 没有环评 \yjt \zd{城乡规划部门}责令停止建设、恢复原状、拆除相关建设。
  \item 规划两类。
        \begin{enumerate}
          \item 土地利用。区域、流域、海域 \yjt 规划编制过程中环评。
          \item 专项规划。工业、农业、畜牧业、林业、交通 \yjt 规划、环评分别上报。
        \end{enumerate}
  \item 建设项目的环评。
        \begin{enumerate}
          \item 分类管理。重大影响 \yjt 环境影响报告书，全面评价；轻度 \yjt 表；很小 \yjt 登记表。
          \item 受委托单位不得有利益关系。中立。
        \end{enumerate}
  \item 审批。
        \begin{enumerate}
          \item 核设施、绝密、特殊、\zd{跨省}、项目国务院批的 \yjt 国务院。
          \item 其他的 \yjt 省政府。
          \item 有争议、污染可能\zd{跨区} \yjt 共同的上级生态环境主管部门。
        \end{enumerate}
  \item 大项目小规划，按项目不按规划；大规划小项目，都要但简化。
  \item 重新报批。审批后，开工前，重大变动。
  \item 后评价。审批后，运行过程中，不符合。报\zd{原审批部门}和建设项目审批部门备案。
  \item 重新审核。5 年未开工。
        \begin{enumerate}
          \item 无影响 \yjt 审核同意，原环评文件继续执行。
          \item 较大影响 \yjt 重新评价。
          \item 根本性变化 \yjt 否决项目。
        \end{enumerate}
\end{enumerate}
