\section{环境影响评价法}
\begin{enumerate}
  \item 适用范围。编制规划、建设项目（全局的）。
        \begin{enumerate}
          \item 规划的环评。
                \begin{enumerate}
                  \item 土地利用。区域、流域、海域 \yjt 规划编制过程中环评。
                  \item 专项规划。工业、农业、畜牧业、林业、交通 \yjt 规划、环评分别上报。
                \end{enumerate}
          \item 建设项目的环评。
                \begin{enumerate}
                  \item 分类管理。书、表、登。重大影响 \yjt 全面评价，环境影响报告书。轻度 \yjt 表。很小 \yjt 登记表。
                  \item 可以委托，但受委托单位不得有利益关系。中立。
                \end{enumerate}
        \end{enumerate}
  \item 审批。
        \begin{enumerate}
          \item 跨省、核、特、密。跨省、核设施、特殊、绝密、项目国务院批的 \yjt 国务院。
          \item 有争议、污染可能跨区 \yjt 共同的上级生态环境主管部门。
          \item 其他 \yjt 省政府。
        \end{enumerate}
  \item 大项目小规划，按项目不按规划。小项目大规划，都要但简化。
  \item 监督。
        \begin{enumerate}
          \item 重新报批。审批后，开工前有重大变动。
          \item 后评价。审批后，运行中，不符合。原批、建批双备案。原审批部门、建设项目审批部门。
          \item 重新审核。5 年未开工。原继、重评、否决。
                \begin{enumerate}
                  \item 无影响 \yjt 审核同意，原环评文件继续执行。
                  \item 较大影响 \yjt 重新评价。
                  \item 根本性变化 \yjt 否决项目。
                \end{enumerate}
          \item 没有环评 \ydy 违建 \yjt 城乡规划部门责令停止建设、责令拆除相关建设、恢复原状。
        \end{enumerate}
\end{enumerate}
