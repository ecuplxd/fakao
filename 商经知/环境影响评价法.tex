\section{环境影响评价法}
\begin{enumerate}
  \item 适用范围：编制\zd{规划}、建设\zd{项目}（全局的）。
  \item 没有环评 \yjt 城乡规划部门责令停止建设、恢复原状、拆除相关建设。
  \item 项目两类。
        \begin{enumerate}
          \item 土地利用：区域、流域、海域 \yjt 规划编制过程中环评。
          \item 专项规划：工业、农业、畜牧业、林业、交通 \yjt 规划、环评分别上报。
        \end{enumerate}
  \item 建设项目的环评。
        \begin{enumerate}
          \item 分类管理。重大影响 \yjt 环境影响报告书，全面评价；轻度 \yjt 表；很小 \yjt 登记表。
          \item 受委托单位不得有利益关系。中立。
        \end{enumerate}
  \item 审批。
        \begin{enumerate}
          \item 核设施、绝密、特殊、跨省、项目国务院批的 \yjt 国务院。
          \item 其他的 \yjt 省政府。
          \item 有争议、污染可能跨区 \yjt 共同的上级生态环境主管部门。
        \end{enumerate}
  \item 大项目小规划，按项目不按规划；大规划小项目，都要但简化。
\end{enumerate}
