\section{城乡规划法}
\begin{enumerate}
  \item 不重要。
  \item 规划种类。
        \begin{enumerate}
          \item 城镇体系规划。总体和详细\blh。
          \item 城市\blh。总体和详细\blh。\zd{优先基础设施、公共服务设施}。
          \item 镇\blh。\zd{优先公共服务设施}。
          \item 乡\blh；村庄\blh。
        \end{enumerate}
  \item 建设用地规划许可。出让和划拨。
        \begin{enumerate}
          \item 出让。先规划，再出让，规划内置在土地出让合同中 \yjt 办建设用地规划许可证。
          \item 划拨。不管它。
        \end{enumerate}
  \item 土地用途管制。农用地、建设用地、未利用地。
  \item 城乡规划许可。不管它。
  \item 临时建设规划管理。\yi 城乡规划部门批准；\er 使用期限内自行拆除。
\end{enumerate}
