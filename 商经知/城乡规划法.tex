\section{城乡规划法}
\begin{enumerate}
  \item 不重要。
  \item 规划种类。
        \begin{enumerate}
          \item 城镇体系规划。总体和详细规划。
          \item 城市。总体和详细规划。\zd{优先基础设施、公共服务设施}。
          \item 镇。\zd{优先公共服务设施}。\al{镇政府办公大楼 \cuo}。
          \item 乡、村庄。
        \end{enumerate}
  \item 建设用地规划许可。出让和划拨。
        \begin{enumerate}
          \item 出让。\zd{先规划，再出让，规划内置}在土地出让合同中。办\zd{建设用地规划许可证}。
          \item 划拨。不管它。
        \end{enumerate}
  \item 土地用途管制。农用地、建设用地、未利用地。
  \item 城乡规划许可。不管它。
  \item 临时建设规划管理。
        \begin{enumerate}
          \item \bs{城乡规划部}门批准。
          \item 使用期限内自行拆除 \yjt 城乡规划部门做拆除决定 \yjt 政府实施拆除行为。行政法拆房子。
        \end{enumerate}
  \item 手续顺序。意见书 \yjt 报审 \yjt 向\zd{规划部}申请规划许可 \yjt 用地审批 \yjt \zd{自然资源部}划拨土地。
\end{enumerate}
