\section{消费者权益保护法}
\begin{enumerate}
  \item 1 - 2 道题。凭常识做题。
  \item 只限于个人。生活消费领域，不包括生产资料。
  \item 经营者（扩大解释）义务。
        \begin{enumerate}
          \item 安全保障。
          \item 召回。缺陷、危险。
          \item 保证商品质量。区别安装、使用不当。\al{甲出售的衣柜，如未被恰当固定墙上，可能倾倒伤人}。
          \item \zd{耐用产品、装饰装修 6 个月内瑕疵，经营者举证}。
          \item 三包（包修、包换、包退）；明码标价；保护消费者信息（需要同意）。
        \end{enumerate}
  \item 公平交易权。没有强买强卖；客观侵犯质量、价格、计量等内容。
  \item \zd{网购 7 天无理由}。
        \begin{enumerate}
          \item 定做、鲜活易腐、音像制品、激活软件、报纸期刊、其他不宜退货 + 确认。
          \item 只要求商品完好，不要求包装，价签完好。
          \item 7 天内退还价款。
          \item 运费消费者自己承担。
        \end{enumerate}
  \item 消费争议解决。协商、和解、调解、仲裁、诉讼。
        \begin{enumerate}
          \item 企业分立、合并后的赔偿问题。
          \item 借用营业执照。找谁都可以。
          \item 展会。结束前/后 \yjt 销售者、服务者/举办者、出租者。
          \item 网络交易平台。有打假义务，\zd{仅不能提供销售者信息下连带}。
          \item 虚假广告。制作者、发布者、参与者有打假义务。\zd{关系生命安全的，无条件连带}。\al{明星虚假代言}。
        \end{enumerate}
  \item 消协。能推荐商品，但不能收费、牟利；\zd{公益诉讼，省以上消协}。
  \item 明知产品存在缺陷仍提供，造成严重损害（死、伤残）。惩罚性赔偿（损失 + 2 倍赔偿）。
  \item 欺诈。\zd{退一赔三（价款），最低 500}。\al{知假买假；外卖配送超时自行取消不通知}。
\end{enumerate}
