\section{专利法}
\begin{enumerate}
  \item 3 分左右。
  \item 发明。创造性。自然规律 + 人类智慧结合。
  \item 实用新型。形状和构造。\al{自拍杆}。
        \begin{enumerate}
          \item 新颖性。（国内外）头一份 \hz 未提过申请（数据库里没有）。国际 \hz 政府主办展览 \yjt 6 月保护期。
          \item 创造性。（突出）特点，（显著）进步。理论可行即可。
          \item 实用性。
        \end{enumerate}
  \item 外观设计。没有功能性。新颖性。不与他人在先知识产权冲突。\al{甲委托乙设计包装盒，乙用了丙的《翠竹》}。
  \item \zd{排除范围}。非法、科学发现、智力规则、疾病诊断、\zd{动植物新品种}、\zd{核}、商标。
  \item 专利申请权。发明人、设计人（只能是自然人）。\zd{先申请原则}。\al{甲镊子实用新型专利，不久乙也自行研制出}。
        \begin{enumerate}
          \item 单位。
                \begin{enumerate}
                  \item 任务 \hz 物质条件。\zd{业余时间搞、不论类别都算}。\al{甲为鼠标设计师，业余研究出手机}。
                  \item \zd{离开 1 年内}取得算原单位。\zd{不要想当然认为和新公司共有}。
                  \item 成功 \yjt 给予奖励；有效果 \yjt 合理报酬。
                \end{enumerate}
          \item 委托。委托合同原理。有约 \yjt 受托人（完成是事实行为）。委托人免费使用、优先受偿/让、依法实施。
          \item 合作。共有制度原理。申请一票否决；放弃申请 \yjt 免费使用。
          \item 申请高的，就不能同时申请低的，但申请低的，仍有可能申请高的。
          \item \zd{公告之日起生效}；驳回找\zd{国家知识产权局}申请复审 \yjt 诉讼（复议前置）。
        \end{enumerate}
  \item 优先权。
        \begin{enumerate}
          \item 国际。发明、实用新型，同一主题 1 年。外观设计 6 个月。
          \item 国内。占坑行为。
        \end{enumerate}
  \item 保护期。
        \begin{enumerate}
          \item 发明专利临时保护制度。公开后到授予前（\zd{期间使用不构成侵权}），自愿付费（不当得利）。
          \item \zd{实际申请日计算}。发明 \yjt 20 年；新型专利 \yjt 10 年；外观设计 \yjt 15 年。
          \item 请求延长。申请日满 4 年，实质审查请求日满 3 年；依申请。药品补 [5, 14] 年
        \end{enumerate}
  \item 宣告无效。任何人都可以向国务院专利复审委员会申请 \yjt 起诉。例外：已执行、已履行。
  \item 权利内容。
        \begin{enumerate}
          \item 生产经营目的。
                \begin{enumerate}
                  \item 制造。
                  \item \zd{许诺销售}（广告宣传、展出、陈列；没卖出去）、销售（真的卖出去了）。
                  \item 进口、使用（外观设计可以不经许可进行使用）。
                \end{enumerate}
          \item 实施许可权。禁止转许可。\zd{独占（一定时间、地域范围）、排他、普通}。同民法技术合同。
        \end{enumerate}
  \item 特别许可。不是常考。
        \begin{enumerate}
          \item \zd{国有主体}发明专利的指定许可。发明；付费；有关部门指定。
          \item 开放许可。自愿；任何单位和个人都能用；给的是普通许可。实用新型，外观设计要有专利权评价报告。
          \item 强制许可。经申请。
                \begin{enumerate}
                  \item 专利休眠。自己不用，也不给别人用。授权日起满 3 年，申请日起满 4 年。
                  \item 垄断行为；公共利益。从属、交叉许可。
                \end{enumerate}
        \end{enumerate}
  \item 专利侵权。
        \begin{enumerate}
          \item 全面覆盖原则。行为是否落入\zd{权利要求书}范围。\al{甲技术特征 a + b，乙 a + c、b + c 都不构成}。
          \item 善意侵权。基本同民法善意取得。
                \begin{enumerate}
                  \item 不赔钱。仅限\zd{销售、许诺销售、使用}可行使\zd{不知情权}免除赔偿责任，制造、进口推定知道。
                  \item 停止侵权行为 \yjt 支付合理对价，继续使用。
                \end{enumerate}
          \item \zd{不视为侵权}。
                \begin{enumerate}
                  \item \zd{首次销售，权利用尽}\footnote{一旦将知识产品合法置于流通以后，原知识产权权利人所有的一些或全部排他权因此而用尽。}。
                        有权主体\zd{售出后}，物权所有人有权\zd{再使用、销售}该物品。制造环节除外。
                  \item 平行进口。同一个权利主体，不同国家进出口。
                  \item 在先使用。申请日之前；原有范围使用，不能扩大。
                  \item 外国交通工具因自身需要\zd{临时过境}。
                  \item \zd{科学研究}。仅限使用。作为科研对象。
                  \item 药品行政审批。\al{25 年到期，可以 20 年就开始做准备}。
                \end{enumerate}
        \end{enumerate}
  \item 侵权纠纷。
        \begin{enumerate}
          \item \zd{被告申请宣告发明专利无效的，可以不中止审理}（发明一开始就是实质审核，避免故意拖延诉讼）。
          \item 确定无效后又提起复议的，裁定驳回起诉，待复议完成后再重新起诉。
          \item 新产品制造方法，\zd{举证责任倒置}。
          \item \zd{现有技术抗辩}。实践中 99\% 都这么采用。
          \item 赔偿。损失 \hz 获利 \yjt 使用费 \yjt 裁量（3W - 500W）。
        \end{enumerate}
\end{enumerate}
