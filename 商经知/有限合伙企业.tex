\section{有限合伙企业}
\begin{enumerate}
  \item 普通合伙人 + （\zd{始终}）有限合伙人组成。\zd{资合性}为主。保护意思自治。
  \item 2 - 50 人。防止沦为非法集资工具。名称\zd{标明有限合伙}。不得以劳务出资。
  \item 普通合伙人执行事务。有限合伙人\zd{不得对外代表企业}，对关乎自己利益的有限参与（浅尝辄止）。
  \item 表见普通合伙。谁表见，算上他 + 普通合伙人担责。\al{甲乙普通，丙丁有限，丙表见，只能找甲乙丙}。
  \item 有限合伙主动外转财产份额的，无需同意，提前 30 日通知，无优先购买权；仅被强制执行 \yjt 有。
  \item \zd{有福可以不同享，有难必须同当}。\al{三方可以约定丙按固定数额分配红利而不承担亏损}。
  \item 只剩有限合伙人，解散。
  \item 解散与清算。不做考试要求。
  \item 责任的承担。注销后，仍然无限连带。
  \item 继承。有限合伙人是直接依法取得，无需一致同意。
\end{enumerate}
