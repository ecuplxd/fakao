\section{有限合伙企业}
\begin{enumerate}
  \item 普通合伙人 + 有限合伙人组成。\bs{资合性为主。保护意思自治}。
  \item \zx{2 - 50} 人。防止沦为非法集资工具。名称\bs{标明“有限合伙”。不得以劳务出资}。
  \item 普通合伙人。
        \begin{enumerate}
          \item 执行事务。
          \item 表见普通合伙。\zx{谁表见找谁，普通合伙人连带}。\al{甲乙普通，丙丁有限，丙表见，只能找甲乙丙}。
        \end{enumerate}
  \item 有限合伙人。\bs{自由}！！
        \begin{enumerate}
          \item \zx{不得对外代表企业}。对关乎自己利益的\zx{有限参与}（浅尝辄止）。
          \item \zx{对外转让}财产份额。\bs{无需同意}、\zx{提前 30 日通知}。\zx{仅被强制执行有优先购买权}。
          \item \zx{继承。直接依法取得}，\bs{无需同意}。
          \item \bs{有福可以不同享，有难必须同当}。\al{三方可以约定丙按固定数额分配红利而\xhx{不承担亏损} \cuo}。
          \item 只剩有限合伙人，解散（解散与清算，不做考试要求）。
        \end{enumerate}
  \item 责任的承担。注销后，仍然无限连带。
\end{enumerate}
