\section{有限合伙企业}
\begin{enumerate}
  \item 普通合伙人 + （\zd{始终}）有限合伙人组成。资合性为主。
  \item 2 - 50。防止沦为非法集资工具。
  \item 标明有限合伙。
  \item 普通合伙人执行事务。有限不得对外代表，对关乎自己利益的有限参与，浅尝辄止。
  \item 表见普通合伙。同表见代理。
  \item 有限合伙主动外转，没有优先购买权，被强制执行，有。
  \item 有福可以不同享，有难必须同当。
  \item 只剩有限，解散。
  \item 一张表格足以应对所有合伙企业法的考点。
  \item 解散与清算。不做考试要求。
  \item 责任的承担。注销后，仍然无限连带。
\end{enumerate}
