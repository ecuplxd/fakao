\section{保险合同}
\begin{enumerate}
  \item 不要式。
  \item 主体。投保人、被投保人、保险人/承保人、受益人。
  \item 保险价值。保险标的价值。
  \item 保险金额。赔付限额。
  \item 订立。
        \begin{enumerate}
          \item \zd{如实告知义务}。被动履行。
                \begin{enumerate}
                  \item 解除权。30 天不行使；成立超过 2 年；已知隐瞒情况仍收费。
                  \item 概括性条款。\al{您身体好么}。
                  \item 体检\zd{不免除}如实告知。
                  \item 故意不赔不退，重大过失不赔要退。\zd{不存在什么违约责任}。
                  \item 拒绝赔付要先解除合同。
                \end{enumerate}
          \item 保险人说明义务。
        \end{enumerate}
  \item 效力。
        \begin{enumerate}
          \item 保险人代为签字。原则无效，投保人缴纳保险费视为追认。
          \item 代填保险单。经过投保人签字确认视为同意。
          \item 合同审查期间事故的处理。就当没这个事故，本来该咋样咋样。
          \item 冲突处理。
                \begin{enumerate}
                  \item 保险单、投保单不一致。原则投保单，说明 + 同意 \yjt 保险单。
                  \item 格式、\zd{非格式}；打印、\zd{手写}；在前、\zd{在后}。
                \end{enumerate}
          \item 无效条款。同民法，排除或限制权利的条款。
          \item 保险事故发生后的通知义务。无法确定部分不担责。
        \end{enumerate}
  \item 人寿险 5 年时效，其余 3 年。
  \item 投保人任意解除权；保险公司法定解除权。
\end{enumerate}
