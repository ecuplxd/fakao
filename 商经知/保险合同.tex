\section{保险合同}
\begin{enumerate}
  \item \bs{不要式、诺成}。投保人提出保险要求，经保险人\zx{同意承保，保险合同成立}。
  \item \bs{整体偏向投保人、除非故意}。
  \item 主体。
        \begin{enumerate}
          \item 投保人、保险人/承保人、受益人。
          \item 被保险人。
                \begin{enumerate}
                  \item 在财产保险中，被保险人通常就是投保人。
                  \item 在人身保险中，若为自己投保，投保人就是被保险人。若为他人投保，他人是被保险人。
                \end{enumerate}
        \end{enumerate}
  \item 保险价值。保险标的价值。
  \item 保险金额。赔付限额。
  \item 订立。
        \begin{enumerate}
          \item 投保人。\zx{如实告知义务}。
                \begin{enumerate}
                  \item 被动履行。\bs{限于}保险人询问的范围和内容。有争议的内容，\zd{保险人负举证责任}。
                  \item \zx{不包括概括性条款}。\al{你身体好么}。
                  \item \bs{体检不免除}如实告知义务。
                  \item 保险人解除权的例外。知道后 \bs{30 日不行使}、成立\bs{满 2 年}、已知隐瞒情况\bs{仍收费}。
                  \item 后果。\yi 保费。\zx{故意不赔不退，重大过失不赔要退}。\er \bs{拒绝赔付要先解除合同}。
                \end{enumerate}
          \item 保险人。说明义务。
        \end{enumerate}
  \item 效力。
        \begin{enumerate}
          \item \zd{代填}保险单。经过投保人\zd{签字}确认 \yjt 私文书证 \yjt 视为同意。
          \item 保险人\zd{代签}字。原则无效，投保人\zd{缴费} \yjt 积极行为 \yjt 视为追认。
          \item \zx{合同审查期间事故的处理}。就当事故没发生，本来该咋样咋样。
          \item 保险单、投保单不一致。\zx{冲突处理}。
                \begin{enumerate}
                  \item 原则\zd{投保单} \dy 保险单。例外。\zd{说明 + 同意 \yjt 保险单}。
                  \item \zx{非格式} \dy 格式、\zx{手写} \dy 打印、\zx{在后} \dy 在前。
                \end{enumerate}
          \item 无效条款。排除或限制权利的条款。同民法。
        \end{enumerate}
  \item \bs{投保人。任意解除权}。
  \item 保险公司。法定解除权。条件非常严格，基本\zx{不得随意解除}，\bs{选项看到解除慎重}。
  \item \bs{不存在违约责任、不得以诉讼方式要求支付保费}。那岂不是倒贴钱。
  \item 保险事故发生后的\zd{通知义务}。因未通知导致无法确定的部分，不担责。
  \item \bs{人 5、3}。人寿 5 年，其余 3 年时效。自知道 \hz 应当知道保险事故发生之日起算。
\end{enumerate}
