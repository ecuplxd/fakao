\section{保险合同}
\begin{enumerate}
  \item \zd{不要式}。投保人提出保险要求，经保险人同意承保，保险合同成立。
  \item 主体。
        \begin{enumerate}
          \item 投保人。
          \item 被保险人。
                \begin{enumerate}
                  \item 在财产保险中，被保险人通常就是投保人。
                  \item 在人身保险中，若投保人为自己投保，投保人就是被保险人，若投保人为他人投保，他人是被保险人。
                \end{enumerate}
          \item 保险人/承保人。
          \item 受益人。
        \end{enumerate}
  \item 保险价值。保险标的价值。
  \item 保险金额。赔付限额。
  \item 订立。
        \begin{enumerate}
          \item \zd{如实告知义务}。被动履行。
                \begin{enumerate}
                  \item 解除权。例外。知道后 30 天不行使；成立超过 2 年；已知隐瞒情况仍收费。
                  \item 限于保险人询问的范围和内容（有争议保险人负举证责任）。
                  \item \zd{不包括概括性条款}。\al{你身体好么}。
                  \item \zd{体检不免除}如实告知义务。
                  \item 保费。故意未告知不赔不退，重大过失不赔要退。
                  \item \zd{拒绝赔付要先解除合同}。
                \end{enumerate}
          \item 保险人说明义务。
        \end{enumerate}
  \item 不得以诉讼方式要求支付保费。
  \item 效力。
        \begin{enumerate}
          \item 代填保险单。经过投保人签字确认视为同意。
          \item 保险人代为签字。原则无效，投保人缴纳保险费视为追认。
          \item 合同审查期间事故的处理。就当没这个事故，本来该咋样咋样。
          \item 冲突处理。
                \begin{enumerate}
                  \item 保险单、投保单不一致。原则投保单，说明 + 同意 \yjt 保险单。
                  \item 格式、\zd{非格式}；打印、\zd{手写}；在前、\zd{在后}。
                \end{enumerate}
          \item 无效条款。同民法，排除或限制权利的条款。
          \item 保险事故发生后的通知义务。无法确定部分不担责。
          \item \zd{不存在什么违约责任}（那岂不是倒贴钱）。
        \end{enumerate}
  \item 人寿险 5 年时效，其余 3 年。自知道 \hz 应当知道保险事故发生之日起算。
  \item \zd{投保人任意解除权}；保险公司法定解除权（条件非常严格，\zd{基本不得随意解除，选项看到解除慎重}）。
\end{enumerate}
