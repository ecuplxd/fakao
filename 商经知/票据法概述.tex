\section{票据法概述}
\begin{enumerate}
  \item 支票、汇票 \yjt 委托付款。本票 \yjt 本人出票本人付款。
  \item 特征。基本同国经信用证，能解决一大半题目。
        \begin{enumerate}
          \item 无因性。\yi 间接当事人之间无抗辩权。\er 该行为不影响票据效力。
          \item 独立性。独立于合同。
          \item 文义性。仅做票面审查，不做实质审查。无章无责。
          \item 设权。
          \item （严格）要式。\al{复印件 no no no}。
        \end{enumerate}
  \item 票据法律关系。基本当事人 \yjt 直接做成票据行为的当事人。非基本当事人 \yjt 票据流通中加入的。
\end{enumerate}
