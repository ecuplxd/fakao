\section{票据法概述}
\begin{enumerate}
  \item 支票、汇票 \yjt 委托付款；本票 \yjt 本人出票本人付款。
  \item 特征。基本同国经信用证，能解决一大半题目。
        \begin{enumerate}
          \item \zd{无因性}。间接当事人之间无抗辩权。
          \item （严格）要式。\al{复印件 no no no}。
          \item \zd{文义性}。仅做票面审查，不做实质审查。
          \item 设权。
          \item \zd{独立性}。独立于合同。
        \end{enumerate}
  \item 票据法律关系。基本当事人 \yjt 直接做成票据行为的当事人；非基本当事人 \yjt 票据流通中加入的。
  \item 无民、限民签章无效。
\end{enumerate}
