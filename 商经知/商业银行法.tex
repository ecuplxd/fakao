\section{商业银行法}
\begin{enumerate}
  \item 1 道题。
  \item 分支机构。不按行政区划设立、非法人组织、有程序而无实体权利、拨付资金 \xydy 总额 60\%、\zd{总行补充责任}。
  \item 组织结构适用公司法。
  \item \zd{资本充足率 8\%}。
  \item 业务规则。资产、负债、中间业务（代收水电费）。
        \begin{enumerate}
          \item 贷款。
                \begin{enumerate}
                  \item 分类。信用贷款、担保贷款。
                  \item 原则。审贷分离、分级审批。
                  \item \zd{关系人贷款}。有利益冲突，只能发担保贷款。\al{不能发放贷款 \cuo}。
                  \item \zd{禁止股本权益性投资、期货股票、房地产、转贷牟利}。
                  \item 不得强令银行发放贷款、提供担保。
                \end{enumerate}
          \item 拆借。救急用。
          \item 禁止混业。
          \item \zd{因行使抵押权、质权取得的不动产 \hz 股权，应当自取得之日起 2 年内予以处分}。
        \end{enumerate}
  \item 国务院银行业监督管理机构（旧称银保监会） \yjt 行政管理、监督。选项出现\zd{批准、审批}字眼。
  \item 央行 \yjt 业务指导、监督。
  \item 银行破产。\yi \bs{单一原因，不能清偿到期债务}。和公司破产不一样。\er 须经\zd{银保监会同意}。
\end{enumerate}
