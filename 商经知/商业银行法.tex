\section{商业银行法}
\begin{enumerate}
  \item 1 道题。
  \item 分支机构不按照行政区划设立。
  \item 不是独立法人，但可作为诉讼主体，总行补充责任。
  \item 组织结构适用公司法。
  \item 业务规则。资产、负债、中间业务（代收水电费）。
        \begin{enumerate}
          \item 贷款。
                \begin{enumerate}
                  \item 审贷分离，分级审批。
                  \item 信用贷款，担保贷款。
                  \item \zd{关系人贷款}。有利益冲突，只能发担保贷款。
                  \item \zd{禁止股本权益性投资、期货股票、房地产、转贷牟利}。
                  \item 不得强令银行发放贷款、提供担保。
                \end{enumerate}
          \item 拆借。就急用。
          \item 投资。
          \item 禁止混业。
        \end{enumerate}
  \item 银保监会 \yjt 行政管理。
  \item 央行 \yjt 业务指导。
  \item 银行破产。单一原因，不能清偿到期债务；须经\zd{银保监会}同意。
\end{enumerate}
