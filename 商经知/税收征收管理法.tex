\section{税收征收管理法}
\begin{enumerate}
  \item 一方是国家，另一方是纳税义务人。
  \item 税收法（法律）定。
  \item 四个权利。
  \item 税务登记。从事生产经营。
  \item 纳税申报。材料保存 10 年。
  \item 税款的征收。申报不实，没办法据实征收的，核定权和调整权（关联企业）。
  \item 税收征收保障。
        \begin{enumerate}
          \item 税收保全。有逃税行为；纳税期前；先责令缴纳 \yjt 担保 \yjt 查扣冻 \yjt 局长 + 强制执行。
          \item 税收强制执行。纳税义务人、担保人、扣缴义务人；划拨；拍卖变卖；滞纳金。
          \item \sjt 俩程序没先后必然顺序。除外：单价 5000 以下；生活用品。
          \item 离境清税制度。
          \item 税收优先权。无担保债权、先欠税后抵押、罚款/没收违法所得。
          \item 税务机关税收代位权和撤销权。法院起诉；费用欠税人负担；只能找主债权人。
          \item 税款的追征。税务机关原因 3 年；纳税人，失误 10W 下/上，3/5 年 + 滞纳金，无限期 + 滞纳金。
        \end{enumerate}
  \item 税务检查制度。不管它。
\end{enumerate}
