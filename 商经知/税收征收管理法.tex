\section{税收征收管理法}
\begin{enumerate}
  \item 一方是国家，另一方是纳税义务人。
  \item 税收法定 \yjt 禁止类推适用。这里的法 = 法律。
  \item 4 个权利。
  \item 税务登记。从事生产经营。
  \item 纳税申报。材料保存 10 年。
  \item 税款的征收。申报不实，没办法据实征收的 \yjt 核定权（偏低 + 无正当理由）和调整权（关联企业）。
  \item 税收征收保障。
        \begin{enumerate}
          \item 税收保全（强制措施）。纳税期前有逃税行为。责令缴纳 \yjt 担保 \yjt 查扣冻 \yjt 局长批 + 强制执行。
          \item 税收强制执行。针对纳税人、纳税担保人、扣缴义务人。划拨、拍卖变卖、滞纳金。
          \item \sjt 行政法内容。俩程序没先后必然顺序。除外。单价 5000 以下 + 生活必需品。\al{家用轿车不属生活用品}。
          \item 离境清税制度。
          \item 税收优先权。优于[无担保债权, 先欠后抵, 罚款/没收违法所得]。先看先后，再看担保。
          \item 税收代位权和撤销权。法院起诉、只能找主债权人、费用欠税人负担。
          \item 税款的追征。
                \begin{enumerate}
                  \item 税务机关原因 3 年时效。
                  \item 纳税人失误 10W 下/上/偷、抗、骗，3/5 年 + 滞纳金/无期限 + 滞纳金。
                \end{enumerate}
        \end{enumerate}
  \item 税务检查制度。不管它。
\end{enumerate}
