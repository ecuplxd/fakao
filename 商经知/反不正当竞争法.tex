\section{反不正当竞争法}
\begin{enumerate}
  \item 小法，1 道题目。
  \item 要遵守商业道德。
  \item 不正当行为。识别是哪一种。
        \begin{enumerate}
          \item 混淆 \yjt 消费者误认。名称、包装、装潢、域名、网页等\zd{特定联系}。\al{加多宝、王老吉}。
          \item 虚假宣传行为。虚假 \hz 引人误解。\al{刷好评；线上二手车比线下多 2W}。
                \begin{enumerate}
                  \item 未有科学结论的。\al{面膜}。
                  \item 歧义性语言。\al{零糖饮料}。
                  \item 组织虚假交易。\al{刷单}。
                  \item 受害方要求赔钱要证明有损失。
                \end{enumerate}
          \item 商业贿赂。暗中，不走账。界定正常佣金行为。
          \item 侵犯商业秘密。技术信息（算法、数据）、经营信息。自行研制和反向工程不构成。
          \item 诋毁他人商誉。假的 \hz 误导性的。
          \item 不正当有奖销售。锁定 5 W。区别变相打折。
          \item 网络领域的不正当竞争。插入链接，强制进行目标跳转；恶意不兼容，\al{分享链接}。
        \end{enumerate}
\end{enumerate}
