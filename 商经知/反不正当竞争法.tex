\section{反不正当竞争法}
\begin{enumerate}
  \item 小法，1 道题目。
  \item 要遵守商业道德。
  \item 不正当行为。识别是哪一种。\bs{混虚贿；谜语；2 不正当}。
        \begin{enumerate}
          \item 混淆。\zd{误认}名称、包装、装潢、域名、网页等\zd{特定联系}。\al{加多宝、王老吉}。
          \item 虚假宣传行为。虚假 \hz 引人误解。\al{刷好评、线上二手车比线下多 2W}。
                \begin{enumerate}
                  \item 未有科学结论的。\al{面膜}。
                  \item 歧义性语言。\al{零糖饮料}。
                  \item 组织虚假交易。\al{刷单}。
                  \item 受害方要求赔钱要证明有损失。
                \end{enumerate}
          \item 商业贿赂。暗中，不走账。vs 正常佣金行为。\sjt \zd{情节严重，可以吊销营业执照}。
          \item 侵犯商业秘密。技术信息（\al{算法、数据}）、经营信息。500W 以下罚款。\zd{自行研制和反向工程不构成}。
          \item 诋毁他人商誉。假的 \hz 有\zd{误导}性的。50 - 300W。
          \item 不正当有奖销售。锁定 \zd{5W}。区别变相打折。\al{所有奖券都是“未中奖”字样}。
          \item 互联网不正当竞争。强调\zd{技术手段}。\al{插入链接、强制跳转、恶意不兼容、不正当使用公共数据}。
        \end{enumerate}
\end{enumerate}
