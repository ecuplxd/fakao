\section{重整程序}
\begin{enumerate}
  \item 转化而来的重整。
  \item 重整期间。怎么有利重整怎么来。
        \begin{enumerate}
          \item 对营业保护的特别规定。债务人可自行管理。
          \item 暂停行使别除权。
          \item 取回权受限。
        \end{enumerate}
  \item 重整计划。
        \begin{enumerate}
          \item 通过。分组表决。出席人数 1/2 + 占财产份额 2/3。所有组别都通古
                \begin{enumerate}
                  \item 有担保的；职工；税务；普通债权（可细分小额债权组）；出资。
                \end{enumerate}
          \item 强行批准。
          \item 失败 \yjt 宣告破产。
        \end{enumerate}
\end{enumerate}
