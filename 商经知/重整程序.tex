\section{重整程序}
\begin{enumerate}
  \item 重整期间。怎么有利重整怎么来。
        \begin{enumerate}
          \item 对营业保护的特别规定。债务人可自行管理。
          \item 暂停行使别除权。\al{丙立即恢复行使质押权，要求拍卖玉石，所得价款优先受偿}。
          \item 取回权受限（\zd{符合条件也不行}）。\sjt 给他一个机会。
        \end{enumerate}
  \item 重整计划。
        \begin{enumerate}
          \item 通过。分组表决。所有组别都通过。
                \begin{enumerate}
                  \item 有担保的；职工；税务；普通债权（可细分小额债权组）；出资。
                  \item 组内出席人数 1/2 + 占财产份额 2/3 \yjt 通过。
                \end{enumerate}
          \item 获得法院强制批准（且有最终决定权）。对全体债权人（申报的、没申报的）有效。
        \end{enumerate}
  \item 失败（如未能按期提出计划；没通过；不执行）转破产。
\end{enumerate}
