\section{重整程序}
\begin{enumerate}
  \item 重整期间。怎么有利重整怎么来。[裁定重整 \yjt 裁定终止] \yjt 裁定终结。
        \begin{enumerate}
          \item 对\zd{营业}保护的特别规定。\zd{债务人可自行管理}。
          \item 别除权。暂停行使。\al{丙立即恢复行使质押权，要求拍卖玉石，所得价款优先受偿 \cuo}。
          \item 取回权。\zd{受限} \bdy 不能取回。\zd{要求符合合同解除条件}。\sjt 给他一个机会。
        \end{enumerate}
  \item 重整计划。
        \begin{enumerate}
          \item 通过。\zd{分组表决 + AllPass}。
                \begin{enumerate}
                  \item 有担保的；职工；税务；普通债权（可细分小额债权组）；出资。
                  \item 通过 = 组内出席人数 1/2 + 占财产份额 2/3。
                \end{enumerate}
          \item \zd{获得法院强制批准}（法院最终决定权）。对全体债权人（申报的、没申报的）都有效。\zd{一盘棋}。
        \end{enumerate}
  \item 失败转清算。失败 = 未能按期提出计划、没通过、不执行。
\end{enumerate}
