\section{票据权利与效力}
\begin{enumerate}
  \item 持票人的票据权利。
        \begin{enumerate}
          \item \zd{付款请求权}。
          \item \zd{追索权}（期前、期后）。提前追索。被拒绝承兑、死亡 \hz 逃匿、破产 \hz 终止营业。
        \end{enumerate}
  \item 恶意（\zd{欺诈、偷盗、胁迫}）、重大过失（\zd{是否善意}）取得的，无票据权利。
  \item \bs{不得无偿取得}票据，需支付对价。例外。\bs{税收、继承、赠与}，但权利仅和前一手一样多。
  \item 灭失、毁损、丢失等\bs{救济。挂失止付、公示催告、提起诉讼。无顺序要求}。
  \item 效力。重要考点。
        \begin{enumerate}
          \item 非完民（无民、限民）签章无效。只对其无效，其他签章仍有效。
          \item \zd{伪造}。专指\zd{签章}。\bs{被伪造者、伪造者均无票据责任}，伪造者仅承担民事赔偿责任。
          \item \zd{变造}。\zd{无权主体}变更其他记载事项。\zd{以变造前后分，落在哪对哪负责。不能辨别视为在变造前签章}。
          \item \zd{更改}。\zd{有权主体}变更票据记载事项的行为。\bs{今日收款}。金额、日期、收款人名称改了，无效。
        \end{enumerate}
\end{enumerate}
