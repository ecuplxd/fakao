\section{票据权利与效力}
\begin{enumerate}
  \item 持票人的票据权利。
        \begin{enumerate}
          \item 付款请求权。
          \item 追索权（期前、期后）。提前追索。被拒绝承兑；死亡 \hz 逃匿；破产 \hz 终止营业。
        \end{enumerate}
  \item 恶意（\al{欺诈、偷盗、胁迫}）、重大过失（\zd{是否善意}）取得的，无票据权利。
  \item 不得无偿取得票据，需支付对价。\zd{税收、继承、赠与}除外，但权利仅和前一手一样多。
  \item 灭失、毁损、丢失等救济。挂失止付、公示催告、提起诉讼。无顺序要求。
  \item 效力。重要考点。
        \begin{enumerate}
          \item 非完签章无效。只对其无效，其他签章仍有效。
          \item 伪造（签章、其他记载事项）。\zd{伪造者、被伪造者无票据责任}，伪造者承担民事赔偿责任。
          \item 更改。金额、日期、出款人名称（绝对记载事项）不能更改。
          \item 变造。无权主体的非法行为。分阶段处理。
        \end{enumerate}
\end{enumerate}
