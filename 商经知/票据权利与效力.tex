\section{票据权利与效力}
\begin{enumerate}
  \item 持票人。付款请求权 \yjt 追索权（期前、期后）。
  \item 恶意、重大过失取得无权利。
  \item 不得无偿取得票据，需支付对价。例外：税收、继承、赠与，权利和前手一样多。
  \item 挂失止付、公示催告、提起诉讼。无前后顺序要求。
  \item 效力。重要考点。
        \begin{enumerate}
          \item 非完签章无效。只对其无效，其他签章仍有效。
          \item 伪造签章。伪造者、被伪造者无票据责任，伪造者承担民事赔偿责任。
          \item 更改。金额、日期、出款人名称不能更改。
          \item 变造。无权主体的非法行为。分阶段处理。
        \end{enumerate}
\end{enumerate}
