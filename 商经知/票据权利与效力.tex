\section{票据权利与效力}
\begin{enumerate}
  \item 不得无偿取得票据（需支付对价）。
        \begin{enumerate}
          \item 恶意（\al{欺诈、偷盗、胁迫}）、重大过失（\al{非善意}）取得的 \yjt 无票据权利。
          \item 例外。税收、继承、赠与，但权利仅和前一手一样多。
        \end{enumerate}
  \item 持票人的票据权利。
        \begin{enumerate}
          \item 付款请求权。
          \item 追索权（期前、期后）。提前追索。被拒绝承兑、死亡 \hz 逃匿、破产 \hz 终止营业。
        \end{enumerate}
  \item 灭失、毁损、丢失等救济。挂失止付、公示催告、提起诉讼。无顺序要求。
  \item 效力。重要考点。
        \begin{enumerate}
          \item 非完民（无民、限民）签章无效。只对其无效，其他签章仍有效。
          \item 伪造签章。
                \begin{enumerate}
                  \item 恶意代理 \yjt 无效 \yjt 被伪造者无责。vs 票据行为的无权代理。无责理由不一样。
                  \item 无章无责 \yjt 伪造者无票据责任，仅承担民事赔偿责任。
                \end{enumerate}
          \item 变造。无权主体变更其他记载事项。变造点分前后，落在哪对哪负责。不能辨别视为在变造前签章。
          \item 更改。有权主体变更票据记载事项的行为。金日收款。金额、日期、收款人名称改了，无效。
        \end{enumerate}
\end{enumerate}
