\section{有限责任公司}
\begin{enumerate}
  \item 人合性。排斥外人，维护原有股权结构。
  \item 股权转让。章程 \yjt 有约从约 \yjt 法律。
        \begin{enumerate}
          \item 对内转让。完全自由。
          \item 对外转让。2 次通知。不同意不影响转让。被分手。
                \begin{enumerate}
                  \item 人数过半数同意。唯一一个地方算人数。
                  \item 30 天决定 \yjt 不同意 \yjt 不买 \yjt 视为同意。
                  \item 多个想买协商 \yjt 按出资\zd{认缴比例}购买。
                  \item 优先购买权。同等条件。数量、价格、期限、支付方式……
                        \begin{enumerate}
                          \item 期限。章程 \yjt 通知 \yjt\, 30 天。
                          \item 转让方反悔。缔约过失责任。
                          \item 恶意转诉讼时效。主观知道 30 \hz 登记 1 年内。
                          \item 只提确认无效，法院不予支持。要行使的是优先购买权，不买起诉个劲。非自身原因除外。
                        \end{enumerate}
                \end{enumerate}
          \item 离婚股权分割。同对外转让规则。
          \item 强制执行。法院。通知 + 告知。行使优先购买权，20 天。
          \item 继承。当然继承 \yjt 章程可以规定不允许继承。
          \item 异议股东（小股东）的回购请求权（退股）。股东股权退给公司，公司把钱退给股东。只有这 3 种。
                \begin{enumerate}
                  \item 5 年营利，5 年不分。
                  \item 合并、分立，转让主要财产。
                  \item 改章程使公司继续存续。
                  \item 协商前置。
                \end{enumerate}
          \item 股权让与担保。民商结合。不发生转让效果。
          \item 一股二卖。登记对抗，适用善意取得。
        \end{enumerate}
  \item 组织机构。人事任免找上级，不能跨（各自只对自己直接上级负责）。
        \begin{enumerate}
          \item 股东会。宏观机构。经营方针、投资计划。选董事、监事；重大方案审议。
                \begin{enumerate}
                  \item 定期会议、临时会议。1/10 表决权、1/3 董事、监事。
                  \item 召集、主持。由内而外，依次补位。
                  \item 15 天通知。全体书面同意可以不开。
                  \item 表决规则。资本多数决。
                  \item 特别 2/3。增资、减资、合并、分立、变更形式、改章程（一堆事）。34\% 一票否决权。
                  \item 一般公司法没规定（考试默认过半数）。
                  \item 实际业务。股权架构的搭建。
                  \item 决议效力。解决股东矛盾的切入点。中小公司不重视。法务：合规。合同管理、内控制度、会议管理。
                        \begin{enumerate}
                          \item 不成立。存在根本缺陷。没开会、没表决、来的人不够、同意的人 \hz 比例不够。
                          \item 无效。内容违法无效；
                          \item 可撤销。内容违章；召集、表决方式瑕疵（实质影响）；60 天向法院申请撤销。
                        \end{enumerate}
                  \item 决议效力之诉。内外有别。
                        \begin{enumerate}
                          \item 无效、不成立。
                          \item 撤销。仅限股东提起；可以应公司申请，要求原告提供担保。
                        \end{enumerate}
                \end{enumerate}
          \item 董事会。日常经营决策。3 - 13 人。<= 3 年一届。1 人 1 票，怎么过没规定。
                \begin{enumerate}
                  \item 经营计划、投资方案。微观。
                  \item 董事长。董事会选出。代表董事会领导公司的方向与策略。产生方式法律留白。可兼任高管。
                  \item 经理。主持生产\zd{经营管理}工作、实施董事会决议。提名权。
                        \begin{enumerate}
                          \item 拟定内部管理机构的设置方案，董事会决定。
                          \item 制度。具体规章，\al{考勤制度}，自己决定。基本管理制度，\al{财务制度}，拟定。
                        \end{enumerate}
                  \item 简化制度。执行董事。规模小 \hz 股东人数少。互斥。
                \end{enumerate}
          \item 监事会。考的少，不做记忆要求。3 人以上。监视主席 \yjt 监事过半数。3 年一届。
                \begin{enumerate}
                  \item 代表诉讼。
                  \item 聘请协助调查。费用公司承担。
                  \item 规模小 \hz 股东人数少，可以不设立监事会。设 1 - 2 名监事。
                  \item 必须有职工监事。
                  \item 董事、高管不得兼任。
                  \item 决议半数通过。
                \end{enumerate}
          \item 重大决策。董事会制定方案，股东会审议决议。常识判断。
          \item 法定代表人。董事长 \hz 执行董事 \hz 经理三选一。说全，不要简称法人、法代。
        \end{enumerate}
  \item 一人有限责任公司。就一个股东（自然人 \hz 法人）。全资子公司。
        \begin{enumerate}
          \item 自然人只能设立一个。
          \item 容易被打穿承担连带责任。注重财务规范。
        \end{enumerate}
  \item 国有独资。没考过。
\end{enumerate}
