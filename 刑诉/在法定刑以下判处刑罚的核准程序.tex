\section{在法定刑以下判处刑罚的核准程序}
\begin{enumerate}
  \item 法外开恩的案件。\al{许霆案}。
  \item 不上不抗 \yjt 上诉期满 3 日 \yjt 上报。
  \item 上诉/抗诉 \yjt 触发二审 \yjt 维持/改判 \yjt 上报/终审。\input{draw/法定刑以下.tex}
  \item 最高法复核后的处理。
        \begin{enumerate}
          \item 同意 \yjt 予以核准。
          \item 不同意 \yjt 不予核准，应当发回原审 \hz 指令其他下级法院重审。
                \begin{enumerate}
                  \item 若发回的是二审，二审可以直接改判。
                  \item 事实、证据、纠程序，应当开庭。查清事实、核实证据或者纠正原审程序违法的。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
