\section{刑事司法协助}
\begin{enumerate}
  \item 最不重要的一讲。
  \item 一个国家的法院 \hz 司法机关根据另外一个国家的司法机关的请求代为 \hz 协助实行与刑诉有关的司法行为。
  \item 狭义：送达文书、询问证人、询问鉴定人、搜查扣押有关的物品的移交、提供有关的法律资料。
  \item \zd{引渡属于广义上的司法协助}。
  \item 司法协助的依据：国际刑事司法协助法、条约、双方协商。
  \item 主体：国与国之间的司法机关。我国就是公检法。
  \item 拒绝的情形。国家主权安全、社会公共利益、基本原则。
  \item 最高院审核同意 \yjt 外交部。
  \item 域外的送达三国法为准。
  \item 中国驻美国使领馆要想代为送达文书给中国及当事人，现在需要\zd{经过所在国允许 \hz 所在国同意}。
\end{enumerate}
