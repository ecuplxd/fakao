\section{刑事代理}
\begin{enumerate}
  \item 案件类型。
        \begin{enumerate}
          \item 公诉案件。被害人及其法代或近亲属，\zd{移送审查之日}起，可以委托。
          \item 自诉。自诉人及其法代有权\zd{随时}委托。
          \item 附民。随公诉自诉。
          \item 没收程序中的代理。犯罪嫌疑人、被告人的近亲属和其他利害关系人。
          \item 强制医疗。被申请人或者被告人。
        \end{enumerate}
  \item 范围以及人数直接类推辩护人。
  \item \zd{没有会见、通信以及申请强制变更措施的权利}。
\end{enumerate}
