\section{执行}
\begin{enumerate}
  \item 财产性的执行是重点。
  \item \zd{生效裁判}。
  \item 法院/监狱/公安/社区矫正。\zd{收钱杀人不干活，徒刑监禁 3 月起，不足 3 拘夺政权，社区最闲陪你玩}。
  \item 死刑。
        \begin{enumerate}
          \item 最高院院长签发死刑令。
          \item 原则上一审法院执行，死缓在监狱执行，\zd{死立执服刑地中院}。
          \item 收到执行令后 7 天内；刑场 \hz 羁押场所；枪决 \hz 注射，其他方法最高院批准。
          \item 会见权。
                \begin{enumerate}
                  \item 临死前有会见\zd{近亲属}的权利，应当告知；申请会见并提供联系方式的应当通知。
                  \item 近亲属以外 = 申请 + 审查 + 正当理由 + 确保安全。
                  \item 会见未成年子女经监护人同意。
                  \item 检察院派员\zd{到场监督}，临死前要\zd{验明正身}，问他有没有什么遗言。
                \end{enumerate}
        \end{enumerate}
  \item 死缓 2 年、无期徒刑、有期徒刑和拘役。
        \begin{enumerate}
          \item 生效后 10 天内\zd{只交文书不交罪犯}。判决书、裁定书、起诉书副本。
          \item 同案犯如果和死刑犯有牵连，最高法\zd{复核问讯死刑犯后}即可交付执行。
          \item 执行期满发释放证明书。
        \end{enumerate}
  \item 管制、有期徒刑缓刑、拘役缓刑。家里蹲。
        \begin{enumerate}
          \item \zd{经常居住地}社区矫正机构；生效后 10 日内报道。
          \item 缓刑考验。
                \begin{enumerate}
                  \item 漏罪 \hz 新罪。\zd{谁判谁撤}。
                  \item 违法违规。谁决定谁来撤，做出生效不能上诉不能抗。
                  \item 遵守规定。不再执行。
                \end{enumerate}
                \item 管制。判决执行以前先行羁押的，羁押 1 日折抵刑期 2 日。
        \end{enumerate}
  \item 剥夺政治权利。不重要。
  \item \zd{财产刑}。
        \begin{enumerate}
          \item 一审法院；财产所在地的同级法院来代。
          \item 罚金、没收财产（立即，现有财产）。
                \begin{enumerate}
                  \item 一次缴纳 \hz 分期缴纳，交够为止，及时追缴。
                  \item 申请免除罚金，一定是不可抗拒的灾祸。
                  \item 所有 = 合法拥有；追缴赃款赃物一追到底（包括孳息）。
                  \item \zd{按顺序清偿}不是按比例，医赔债罚没，优先受偿权插队：医债赔罚没。
                  \item \zd{执行回转（只有财产刑有）}，返还原物/价金，赔偿相关的损失。
                \end{enumerate}
        \end{enumerate}
  \item \zd{执行的变更}。刑种发生变化。
        \begin{enumerate}
          \item 死刑。
                \begin{enumerate}
                  \item 暂停执行。发现\d{其他}犯罪，\zd{共犯}到案，\zd{立功}，怀\zd{孕}。
                  \item 下级法院发现错，暂停，层报最高院 \yjt 裁定停止 \yjt 核实后 \yjt 层报最高院。N 字。
                  \item 最高院发现错，裁定停止 \yjt 核实后 \yjt 层报最高院。V 字。
                  \item \yjt 最高院处理。依法改判；不予核准，发回重审；继续执行。
                \end{enumerate}
          \item 死缓 2 年。
                \begin{enumerate}
                  \item 从裁判宣告 \hz 送达之日起算考验期；
                  \item 转死刑：2 年内故意犯罪，情节恶劣，层报核准。
                  \item 减刑：2 年期满 \yjt 无期；重大立功 \yjt\, 25 年有期。2 年期满起算。
                \end{enumerate}
          \item 暂予监外执行。
                \begin{enumerate}
                  \item 有期、拘役、特殊的无期；疾病、孕乳、不自理。省级政府指定的医院。
                  \item 执行前法院；执行后具体分析。
                  \item 收监：不符条件、违规定、情形消失期未满。谁决定出去，谁决定回来。
                  \item 社区矫正机关执行。
                  \item 刑期计算。贿赂非法、\zd{脱逃}出去的期间不计入。
                \end{enumerate}
          \item 减刑 \yjt 管制、拘役；假释 \yjt 有期、无期。
                \begin{enumerate}
                  \item 乖乖的听话，有期要关 1/2，无期 1/3；
                  \item 无期死刑在高院，剩下在中院；审理期限 1 个月；
                  \item 漏罪新罪 \yjt 谁判谁撤；违法违规 \yjt 原来决定的法院来撤；遵守规定 \yjt 视为执行完毕。
                  \item \zd{一定要开庭：重大立功不一般；影响重大有意见；有权有势又有钱}。幅度等突破一般规定；职权类，黑社会性质，金融类犯罪。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
