\section{执行}
\begin{enumerate}
  \item 财产性的执行是重点。执行阶段已不是被告人身份了 \yjt 无辩护权！！
  \item 生效裁判。
  \item 法院/监狱/公安/社区矫正。收钱杀人不干活/徒刑监禁 3 月起/不足 3 拘夺政/社区最闲陪你玩。
  \item 死刑。地点、方式、会见、监督。
        \begin{enumerate}
          \item 最高法院长签发死刑令。
          \item 原则上一审法院执行。死缓期间被处死 \yjt 服刑地中院。不要把执行主体和执行地点混了！！
                \al{由法院\xhx{交由监狱} \hz 指定的羁押场所执行 \cuo}。
          \item 收到执行令后 7 日内、地点[刑场 \hz 羁押场所]、方式[枪决 \hz 注射]（其他方法最高法批准）。
          \item 会见权。
                \begin{enumerate}
                  \item 应当告知临死前有权会见、近亲属。应当通知 = 申请会见 + 提供联系方式。
                  \item 会见未成年子女经监护人同意。
                  \item 会见近亲属以外，一系列操作 = 申请 + 审查 + 正当理由 + 确保安全。
                  \item 检派员到场监督，临死前要验明正身，问他有没有什么遗言。
                \end{enumerate}
          \item 死刑变更。\zd{发现其他犯罪/证据、共犯到案、重大立功、怀孕}。刀下留人。
                \begin{enumerate}
                  \item \zd{下级法院发现错。暂停 \yjt 层报高院 \yjt 裁定停止 \yjt 核实后 \yjt 层报最高法}。N 字。
                  \item 高院发现错。裁定停止 \yjt 核实后 \yjt 层报最高法。V 字。
                  \item \sjt 2 个 \yjt 最高法处理见死刑复核。
                \end{enumerate}
          \item 死缓变更。求生求死。
                \begin{enumerate}
                  \item 从裁判宣告 \hz 送达之日起算考验期。
                  \item 减刑。2 年期满 \yjt 无期。重大立功 \yjt 25 年有期。2 年期满起算。即刑期最低为 25 + 2 = 27。
                  \item 限制减刑（只针对死刑）。累犯、杀伤奸抢投毒火爆、绑架、有组织的暴力性犯罪。
                  \item 转死刑。2 年内故意犯罪、情节恶劣、层报核准。
                \end{enumerate}
        \end{enumerate}
  \item 死缓、无期、有期和拘役。文书、共犯死刑。
        \begin{enumerate}
          \item \zd{生效后 10 日内}只交文书不交罪犯。判决书、裁定书、起诉书副本。
          \item \zd{同案犯如果和死刑犯有牵连，最高法复核问讯死刑犯后才可交付执行}。
          \item 执行期满发释放证明书。
        \end{enumerate}
  \item 剥夺政治权利。死刑、无期，剥夺终身。减刑后，剥夺改为 3 - 10 年。\al{应改为 15 年 \cuo}。不重要。
  \item 财产刑。罚金、没收财产（立即，现有财产）。追、缴、收、赔、回转。
        \begin{enumerate}
          \item 第一审法院，也可以委托财产所在地的同级法院执行。\al{不动产}。
          \item 所有 = 合法拥有。赃款赃物及孳息一追到底。善意第三人不追缴，纠纷通过其他诉讼程序解决。
          \item 罚金。一次缴纳 \hz 分期缴纳。交够为止，有钱就应当！！\al{应当及时追缴、应当查扣冻 \dui}。
          \item \zd{一定是不可抗拒的灾祸，才能申请免除罚金 \yjt 法院自主裁定}。
          \item 不是所有债务，而是正常债务。\al{甲在案发前所负\xhx{所有}债务，经债权人请求先行予以偿还 \cuo}。
          \item 已被侦查机关查扣冻的，无需解除即可直接处置。
          \item 按顺序清偿而不按比例。医赔债罚没，优先受偿权插队 \yjt 医债赔罚没。
                \al{甲曾以该汽车\xhx{抵押}获得小额贷款，银行主张优先受偿}。
          \item 执行回转（只有财产刑有）。返还原物/价金、赔偿相关的损失。
          \item 续行查扣冻（继续冻结的意思）要与侦查机关的顺位相同。
          \item 执行担保。可以先行查扣冻 \hz 要求提供担保。
        \end{enumerate}
  \item 管制、有期缓刑、拘役缓刑。审判阶段作出、宣告。条件、考验。
        \begin{enumerate}
          \item 3；累、首。\xydy 3 年有期或拘役。累犯、首要犯罪分子不行。
          \item 生效后 10 日内到经居地、社区矫正机构报道。
                \begin{enumerate}
                  \item \al{向罪犯及原所在单位 \hz 居住地群众\xhx{公布}犯罪事实、期限及应遵守的规定 \cuo{未成年}}。
                  \item \al{应当自行前往报道 \dui}。
                \end{enumerate}
          \item 缓刑考验。
                \begin{enumerate}
                  \item 漏罪新罪。谁判谁撤。
                  \item 违法违规。谁决定谁来撤、作出生效、不能上诉不能抗。
                  \item 成功。原判刑罚不再执行。\bdy 刑罚执行完毕。
                \end{enumerate}
          \item 管制。
        \end{enumerate}
  \item 社区矫正机构。
        \begin{enumerate}
          \item 叫终止社区矫正，不叫解除！！
          \item 社区矫正期间由它负责管理一切事务。\al{因搬家变更执行地，由\xhx{作出假释的中院}作出变更裁定 \cuo}。
          \item 可以进行电子定位。
          \item 发现有逃跑的可能，提请批捕找、阶段负责机关。执行阶段 \yjt 法院。侦查阶段 \yjt 公安。
        \end{enumerate}
  \item 执行的变更。刑种发生变化。
        \begin{enumerate}
          \item 执行都找社区矫正机构。\al{由 A 区司法行政机关实行社区矫正 \dui}。
          \item \zd{暂予监外执行。一放一收}。
                \begin{enumerate}
                  \item 对象。拘役、有期、特殊的无期。\al{死缓 \cuo}。\bs{疾病、孕乳、不自理}。省政府指定的医院。
                  \item \zd{决定。分前后，谁居主导地位谁决定}。
                        \begin{enumerate}
                          \item 执行前。法院。
                          \item 执行后。监狱/看守所提书面意见 \yjt 省监狱管理机关/市以上公安批准。
                        \end{enumerate}
                  \item 收监。\zd{谁决定出去，谁决定回来。立即生效、没有救济}。
                  \item \zd{贿赂、非法脱逃出去的期间不计入刑期}。
                \end{enumerate}
          \item 减刑。针对自由刑。刑期、谁裁、开庭、出庭。
          \item 假释。针对有期、无期。有条件提前释放。执行阶段作出，用裁定。不得、特别。
                \begin{enumerate}
                  \item 无次数限制，但有幅度和限度要求。
                  \item 管制、拘役、有期至少执行原判刑期 1/2、无期至少 13 年。
                  \item 实质条件。无人身危害性、再犯可能性。确有悔改表现。\al{如退赃}。
                  \item 重大立功可以减刑。\al{不认真遵守监规、不接受教育改造不可以减刑 \cuo 只看立功}。
                  \item 不得假释。
                        \begin{enumerate}
                          \item 累犯。
                          \item 杀伤奸抢投毒火爆组。
                                \yi 单个判 \dydy 10 年。
                                \er 多个同类罪数罪并罚 \dydy 10 年。\al{投毒 8，盗窃 5 \yjt 13 \cuo。投毒 8，强奸 5 \yjt 13 \dui}。
                        \end{enumerate}
                  \item 审理。
                        \begin{enumerate}
                          \item 无期死刑在高院，剩下在中院。\al{由其\xhx{复审的高院}作出裁定 \cuo}。
                          \item 特别假释 \yjt 最高法。\al{原判刑期没执行够就被假释}。
                          \item 合议庭、书面（提讯）、审期 1 个月。\al{可以由一名法官\xhx{独任}审理 \cuo}。
                          \item 同级检收到假释裁定书副本 20 日内未提出书面纠正意见的，方可生效。
                        \end{enumerate}
                        \begin{kk}{一定要开庭的}
                          \begin{enumerate}
                            \item 重大立功不一般；重大影响有意见；有权有势又有钱。
                            \item 职务、黑、金。职务、黑社会性质、金融类犯罪。\al{受贿罪}。
                            \item 应当通知检、罪犯、执行机关出庭。
                                  \begin{itemize}
                                    \item \al{聘请\xhx{律师}到庭发表意见、有权委托律师进行辩护 \cuo{已无被告身份}}！！
                                    \item \al{应当通知\xhx{证人}出庭证明甲具有减刑事实 \cuo}。
                                  \end{itemize}
                            \item 开庭地点。执行场所 \hz 法院确定的场所。\al{可以在甲服刑的监狱开庭审理 \dui}。
                          \end{enumerate}
                        \end{kk}
                  \item 减刑、假释考验。
                        \begin{enumerate}
                          \item 漏罪新罪 \yjt 谁审谁撤。\al{审理招摇撞骗的某县法院可以直接撤销市中院作出的假释裁定 \dui}。
                          \item 违法违规 \yjt 原审法院撤。
                          \item 遵守规定 \yjt 原判刑罚视为执行完毕。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
