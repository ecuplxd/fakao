\section{涉案财物的处理}
\begin{enumerate}
  \item 简单了解，不是重点。
  \item 判前。各种阶段。\al{侦查阶段扣押}。
        \begin{enumerate}
          \item \zx{查扣冻机关没有处分权}。妥善保管，制作清单，随案移送。\al{检将已冻结的涉案财物上缴国库 \cuo}。
          \item \zd{分类处置}。
                \begin{enumerate}
                  \item 被害人的。\zx{合法应当及时返还}。\al{贪污 100W，受贿 10W \yjt 收 10W。100W 那是被害单位的}。
                  \item 违禁品、鲜活易腐。按规定处理。
                  \item 证据。不宜移送的，清单、照片或其他证明文件。\al{毒品}。
                  \item 有价证券。\zd{先行处置 = 权利人申请 + 院长批准}。
                \end{enumerate}
        \end{enumerate}
  \item 判后。
        \begin{enumerate}
          \item 财物及孳息，\zx{第一审法院}追、还、缴（公告满 1 年）。
          \item 与本案\zd{无关但在清单}的 \yjt 查扣冻机关处理。
          \item 未随案移送的 \yjt 法院 10 日内催\zd{扣押机关}在 1 个月内执行 + 回单 \hz 说明无法完成的理由。
                \al{公安根据判决书将未随案移送的被盗金条返还给被害单位 \dui}。
          \item 属于被告人合法所有的，赔偿损失、执行财产刑后返还被告。
          \item 遗漏。
                \begin{enumerate}
                  \item \zd{一审遗漏}，二审\zd{可以}发回重审。\zd{\ydy 事实不清}。
                  \item 判决\zd{生效后发现遗漏}，\zd{原审法院另行处理}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
