\section{取保候审}
\begin{enumerate}
  \item 公检法责令嫌疑人/被告人提供保证人 \hz 交纳保证金，保证不逃避侦查、起诉、审判活动，并随传随到。
  \item 各自的决定只及于各自的阶段。只能\zx{公安/国安执行}！！\al{涉及军队安全 \yjt 军队保卫部门 \cuo}。
        \begin{enumerate}
          \item 只及于各自的意思。\al{公安采用了人保，后面法院变更为人保 \dui{可以的}}。
        \end{enumerate}
  \item 条件。不能逮捕\zd{可以}转为取保候审。\zd{证据、徒刑、危险三缺一}。\zd{徒刑以下不危险，疾病孕乳超期限}。
        \begin{enumerate}
          \item 积极条件。关键看有没有\zd{危险性}。
          \item 消极条件。\zd{累、主、残、暴、严}。累犯、主犯、自伤自残、严重暴力、其他严重犯罪情形。
        \end{enumerate}
  \item 方式。\zd{2 选 1}，不能同时。
        \begin{enumerate}
          \item 保证人。\zd{1 -2 人}！！\zd{老的幼的没钱的}。
                \begin{enumerate}
                  \item \zd{无牵连有能力，有权有房又有钱}。本案无关、有政治权利、有固定住处、有钱交罚款。
                  \item 义务。\zd{监督、报告、罚款、刑责}。\al{承担民事赔偿责任 \cuo}。\al{未履行义务应处罚款的，由检察院决定 \cuo}。
                \end{enumerate}
          \item 保证金。
                \begin{enumerate}
                  \item 起点 \zd{1000}￥，上不封顶，直接交到指定的银行账户。\al{由决定机关统一收取 \cuo}。
                  \item 违反义务 \yjt 没收。\al{没收了 10000 保证金，并重新责令交纳 8000 保证金 \dui}。
                  \item 实施\zx{新的犯罪，先暂扣}。\yi 故意 \yjt 没收。\er 其他 \yjt 退还。\al{检察院暂扣 \cuo}。
                  \item 金额的确定。删除了\scx{当地经济水平}的规定。
                \end{enumerate}
        \end{enumerate}
  \item 启动。依申请 \hz 依职权。
        \begin{enumerate}
          \item 报各自的老大决定。\zd{被取保候审人居住地的派出所}执行。
          \item \zd{每个阶段 12 个月、累加制}。\al{重新交纳保证金的，取保候审期间重新计算 \cuo}。
        \end{enumerate}
  \item 解除。新增。
        \begin{enumerate}
          \item 依职权解除。\zd{撤案 \hz 终止侦查}。
          \item \zd{自动解除}。\zd{变更、不诉、无罪责，附加生效主执行}。措施已变更、不起诉、裁判生效 \hz 已执行。
        \end{enumerate}
  \item \zx{一头一尾决定机关，其他都是执行机关}。一头/一尾 \yjt 决定/解除。
  \item 义务。\zd{法定、酌定义务混着考，注意看问的是啥}。
        \begin{enumerate}
          \item 5 个法定义务。\zd{市县、报告、随传到。不扰证人、不毁证}。
                \begin{enumerate}
                  \item 活动范围市县。离开执行机关批准。
                  \item 信息变动 \zd{24} 小时内报告执行机关。\al{要求甲不得变更住址 \cuo}。
                  \item 随传随到。\al{应当在指定的居所进行讯问 \cuo}。
                  \item 不干扰证人作证、不毁灭伪造篡改证据。\bdy 不能接触。
                \end{enumerate}
          \item 4 个酌定义务。\zd{特定的地方、人、活动、证}。护照、驾驶证等交执行机关保存。\al{应当 \cuo}。
        \end{enumerate}
  \item 违反后果。
        \begin{enumerate}
          \item 交钱了 \yjt 没收部分或全部。
          \item 区别情形。更严厉的措施，往上走。
                \begin{enumerate}
                  \item 具结悔过 \yjt 重新交纳保证金、提出保证人；监视居住；予以逮捕。
                  \item 能予以逮捕 \yjt 先行拘留。\zd{把主体、措施拆分到题干和选项麻痹你}。
                        \al{乙因伪造证据而应与逮捕，对于法院适用强制措施，下列哪些选项正确的。决定逮捕前可先行拘留乙 \cuo}。
                  \item \zd{新罪、逃、杀、串毁证，还要打击报复他}。企图逃跑、自杀；串供；毁灭、伪造证据 \yjt 应当逮捕。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
