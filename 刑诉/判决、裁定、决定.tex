\section{判决、裁定、决定}
\begin{enumerate}
  \item \zx{判决。仅实体}。书面。分为有罪、无罪、无责。法院做。书面。\zd{生效仅一个}。上诉 \hz 抗诉。
  \item 裁定。\zd{就它中庸}。
        \begin{enumerate}
          \item 程序（\al{审理、原判、重审}）和部分实体（\al{减刑、假释、撤销缓刑、减免罚金}）。
          \item 法院做、可口头、可多个、上诉 \hz 抗诉。
          \item \zx{检认为裁定不当 \yjt 纠正意见 \yjt 法院应当重新组成合议庭审理}。
        \end{enumerate}
  \item \zx{决定。仅程序问题}、公检法做、多个、立即生效、\zx{可申请复议}。
  \item 民诉也适用。
\end{enumerate}
