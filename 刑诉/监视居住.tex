\section{监视居住}
\begin{enumerate}
  \item 在一定期限内不能离开特定的区域（房间）。
  \item 替代性措施。
        \begin{enumerate}
          \item 替代取保。\bs{没钱又没人}。
          \item 替代逮捕。\zx{疾病孕乳超期限；特殊、需要、唯一抚}。
                严重疾病、孕乳、羁押已超期尚未办结；特殊情况、案件需要、唯一抚养人。
                \al{聋哑人 \cuo}。
        \end{enumerate}
  \item 程序。
        \begin{enumerate}
          \item \zd{最长 6 个月}；电子监控、不定期检查；侦查期间，\zd{可以监控通信}。
          \item 住处监视 \hz 指定居所。\bs{有家就在家，没家找个家；有家要找家，就得危和恐}。
          \item 指定居所特殊规定。
                \begin{enumerate}
                  \item \zd{上一级公安批准}。居所条件是有限制的。\zd{谁办案谁开房谁掏钱}。
                  \item \zd{24 小时内通知家属}（无法通知到的除外）。\zx{除管制 1:1，其他折抵刑期，半押}。
                \end{enumerate}
          \item 解除。依职权 \hz 依申请（当法近辩）。
        \end{enumerate}
  \item 6 项必须要遵守的义务。\zx{处所会见及时到，不扰证人不毁证，保存还要身份证}。比取保候审多个身份证。
  \item 后果。
        \begin{enumerate}
          \item 情节严重 \yjt 予以逮捕。
          \item 能予以逮捕  \yjt 先行拘留。
          \item \bs{新罪、逃、杀、串毁证，还要打击报复他} \yjt 逮捕。同取保候审。
        \end{enumerate}
\end{enumerate}
