\section{证明}
\begin{enumerate}
  \item 证明对象。
        \begin{enumerate}
          \item 待证事实/证明客体。
          \item 免证事实。常识法规和定律；推定生效无异议。同民诉。
        \end{enumerate}
  \item 证明责任。提供证据 + 说服责任。同民诉。
  \item 证明标准。
        \begin{enumerate}
          \item 立案阶段 \yjt 有犯罪事实存在。
          \item 逮捕阶段 \yjt \zd{发生了；他干了；已有查证属实了}。
          \item 侦察终结、提起公诉、有罪判决：\zd{事实清楚，证据确实、充分}。55 条第 2 款。
                \begin{enumerate}
                  \item 定罪量刑的事实都有证据证明 \yjt 清楚。
                  \item 据以定案的证据均经过法定程序查证属实 \yjt 确实。
                  \item 综合全案证据，对所认定事实已排除合理怀疑 \yjt 充分。
                  \item 定罪证据存疑 \yjt 疑罪从无。
                  \item 量刑证据存疑 \yjt 疑案从轻。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
