\section{证明}
\begin{enumerate}
  \item 证明对象。
        \begin{enumerate}
          \item 待证案件事实/证明客体。
          \item 免证事实。常识法规和定律；推定生效无异议。同民诉。\zd{案件基本事实不属于}。
          \item vs 证据事实。证据本身的来源、构成等要素。\al{用于鉴定的体液检材是否被污染的事实}。
          \item 实体法事实（如量刑）+ 程序法事实（自愿性、真实性、合法性）。
        \end{enumerate}
  \item 证明责任。\zd{提供证据 + 说服责任}。兼有 \hz 居其一。
        \begin{enumerate}
          \item 公诉案件中，一般情况下，由公诉人承担证明责任，被告人、辩护人不承担任何证明责任。
          \item 持有型犯罪被告人才需要承担一定的证明责任。\al{非法持有枪支案中，被告人负有提出证据的责任}。
          \item \zd{区分辩解}。
          \item 自诉案件。主要是谁主张、谁举证，但不是法则（必须）。
        \end{enumerate}
  \item 证明标准。
        \begin{enumerate}
          \item 立案阶段 \yjt 有犯罪事实存在。
          \item 逮捕阶段 \yjt \zd{发生了；他干了；已有查证属实了}。
          \item 侦查终结、提起公诉、有罪判决：\zd{事实清楚，证据确实、充分}。55 条第 2 款。
                \begin{enumerate}
                  \item 定罪量刑的事实都有证据证明 \yjt 清楚。
                  \item 据以定案的证据均经过法定程序查证属实 \yjt 确实。
                  \item 综合全案证据，对所认定事实已排除合理怀疑 \yjt 充分。
                  \item 定罪证据存疑 \yjt 疑罪从无。
                  \item 量刑证据存疑 \yjt 疑案从轻。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
