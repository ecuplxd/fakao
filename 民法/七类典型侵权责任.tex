\section{7 类典型侵权责任}
\begin{enumerate}
  \item 民诉喜欢考谁被告，证明责任怎么分配。
  \item 产品责任。是个侵权问题（要有实害结果）。vs 瑕疵担保责任。违约问题，债权请求权。
        \begin{enumerate}
          \item 生产者、消费者、销售者。\al{京东网购扫地机器人炸到自己}。
                \begin{enumerate}
                  \item 不具备应当具备的功能 \yjt 仅违约。
                  \item 销售者 \yjt 既违约又侵权（加害给付）。
                  \item 生产者 \yjt（相对）无过错。
                  \item 消费者和生产者 \yjt 仅侵权。
                  \item \al{扫地机器人炸到老婆 \yjt 老婆不是合同当事人，销售者没有违约责任，只有侵权责任}。
                \end{enumerate}
          \item 产品的警示与召回。相对连带。投入流通、扩大部分担责。
          \item 惩罚性赔偿。明知 + 人身伤亡。法院自由裁量。\bdy 欺诈的退一赔三。
        \end{enumerate}
  \item 机动车交通事故。谁开车（使用人）找谁。\al{甲驾车撞倒乙，经查车是丙从丁处盗得。甲乙连带，丁无责 \dui}。
        \begin{enumerate}
          \item \yi 车撞车过错。\er 车撞非机无过错。
          \item 免责。受害人是否有过错。\al{闯红灯}。
          \item 违法在先，链条上所有人连带责任。\al{报废车、盗赃车}。
          \item 车辆所有人、管理人。过错补充。
        \end{enumerate}
  \item 医疗损害。过错。诊疗规范 + 病例 \yjt 医院证明。只考过一次。
  \item 环境污染和生态破坏。无过错。免责 \yjt 仅限不可抗力 + 补救措施。修负责任。3 年诉讼时效。
  \item 高度危险。无过错。\al{鱼竿甩到高压线（多多少少承担点）}。
  \item 饲养动物损害。
        \begin{enumerate}
          \item 损害扩大解释。包括致人、致物损害。\al{甲饲养的山羊将乙辛苦栽培的\xhx{珍稀药材}悉数啃光}。
          \item 动物园。过错。
          \item 饲养违禁动物。没有任何免责。\al{藏獒}。
          \item 一般/违规饲养动物损害（包括人、物）。
                \begin{enumerate}
                  \item 无过错。
                  \item 免责。受害人故意。重大制度修改。逗狗什么不算，除非明说故意。
                  \item 受害人重大过失，所有人可以减轻责任。\al{甲偷狗，被狗咬伤}。
                  \item 转移故意引起人。\al{小学生乙丙放学经过甲家，乙故意逗狗，狗被激怒咬伤丙 \dui}。
                  \item 受害人引起的损害。\al{甲下夜班未看到邻居饲养的小猪趴在路上而绊倒摔伤 \dui}。
                \end{enumerate}
          \item 也会存在所有人、饲养人、管理人分离的情况。\al{甲出国请邻居乙代为看管其饲养的宠物狗。甲不承担}。
        \end{enumerate}
  \item 建筑和物件/\zd{构筑物}损害。是工程质量问题/不是 \yjt 建设单位、施工单位连带/所有人、使用人、管理人 \yjt 第三人/其他责任人。
        \al{窗户玻璃}。
  \item 地面施工倒塌塌陷。过错。谁干的找谁。免责。\zd{设置明显标志、采取安全措施}。
  \item 高空抛物。公平补偿。看到赔偿、连带都是错的。结合小区考物业公司安保义务人。
  \item 林木折断、道路挖坑。\al{掉粪坑}。免责。尽到了管理维护、法定警示义务。\al{正在施工警示牌}。
  \item \zx{悬挂物脱落坠落}。过错。\zd{所有人、使用人、管理人}。
        \begin{enumerate}
          \item \al{广告牌}。
          \item \al{甲租乙房，阳台养花，小区物业\xhx{多次提醒}}。
        \end{enumerate}
\end{enumerate}
