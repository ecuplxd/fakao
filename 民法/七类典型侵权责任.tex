\section{7 类典型侵权责任}
\begin{enumerate}
  \item 产品责任。是个侵权问题。vs 瑕疵担保责任（违约问题，债权请求权）。
        \begin{enumerate}
          \item 生产者、消费者、销售者。\al{京东网购扫地机器人炸到自己}。
                \begin{enumerate}
                  \item 不具备应当具备的功能 \yjt 违约。
                  \item 销售者 \yjt 既违约又侵权（加害给付）。
                  \item 生产者 \yjt（相对）无过错。
                  \item 消费者和生产者 \yjt 只有侵权问题。
                  \item \al{扫地机器人炸到老婆 \yjt 老婆不是合同当事人，销售者没有违约责任，只有侵权责任}。
                \end{enumerate}
          \item 产品的警示与召回。相对连带。\zd{投入流通}，扩大部分担责。
          \item 惩罚性赔偿 \bdy 欺诈的假一赔三。\zd{明知 + 人身伤亡}。法院自由裁量。
        \end{enumerate}
  \item 机动车交通事故。谁开车（使用人）找谁。\al{甲驾车撞倒乙，经查车是丙从丁处盗得。甲乙连带，丁无责 √}。
        \begin{enumerate}
          \item \yi 车撞车过错。\er 车撞非机无过错。考免责，受害人是否有过错。\al{闯红灯}。
          \item \zd{违法在先}，\zd{链条}上所有人\zd{连带}责任。\al{报废车、盗赃车}。
          \item 车辆所有人、管理人。过错补充。
        \end{enumerate}
  \item 医疗损害。过错。诊疗规范 + 病例 \yjt 医院证明。只考过一次。
  \item 环境污染和生态破坏。无过错。免责仅限\zd{不可抗力 + 补救措施}。修负责任。\zd{3 年诉讼时效}。
  \item 高度危险。无过错。\al{鱼竿甩到高压线（多多少少承担点）}。
  \item 饲养动物损害（包括人、物）。\al{甲饲养的山羊将乙辛苦栽培的珍稀药材悉数啃光}。
        \begin{enumerate}
          \item 动物园。过错。
          \item 违禁饲养。没有任何免责。
          \item \zd{一般/违规}饲养动物损害（包括人、物）。
                \begin{enumerate}
                  \item 无过错。
                  \item 免责。\zd{受害人故意}（重大制度修改）。\al{逗狗什么不算，除非明说故意}。
                  \item 命题陷阱。转移故意引起人。\al{小学生乙丙放学经过甲家，乙故意逗狗，狗被激怒咬伤乙}。
                  \item 受害人引起的损害。\al{甲下夜班未看到邻居饲养的小猪趴在路上而绊倒摔伤 √}。
                  \item 受害人\zd{重大过失可以减轻}责任。\al{甲偷狗，被狗咬伤}。
                \end{enumerate}
          \item 也会存在所有人、饲养人、管理人分离的情况。\al{甲出国请邻居乙代位看管其饲养的宠物狗。甲不承担}。
        \end{enumerate}
  \item 建筑和物件/构筑物损害。
        \begin{enumerate}
          \item 是/不是\zd{工程质量}问题 \yjt 建设单位、施工单位\zd{连带}/所有人、使用人、管理人 \yjt 第三人/其他责任人。
          \item 地面施工。倒塌塌陷。过错。谁干的找谁。免责。\zd{设置明显标志、采取安全措施}。
          \item 高空抛物。公平\zd{补偿}。\zd{看到赔偿、连带都是错的}。结合小区考物业公司安保义务人。
          \item 林木折断、道路挖\zd{坑}。免责。尽到了\zd{管理维护、法定警示义务}。\al{掉粪坑}。
          \item 悬挂物脱落坠落。过错。所有人、使用人、管理人。\al{甲租乙房，阳台养花，小区物业多次提醒。广告牌}。
        \end{enumerate}
\end{enumerate}
