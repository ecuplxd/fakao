\section{7 类典型侵权责任}
\begin{enumerate}
  \item 产品责任。是个侵权问题。vs 瑕疵担保 \yjt 违约问题，债权请求权。
        \begin{enumerate}
          \item 生产者、消费者、销售者。\al{京东网购扫地机器人炸到自己}。
                \begin{enumerate}
                  \item 不具备应当具备的功能 \yjt 违约。
                  \item 销售者 \yjt 既违约又侵权（加害给付）。
                  \item 消费者和生产者 \yjt 只有侵权问题。
                \end{enumerate}
          \item \al{扫地机器人炸到老婆}。不是合同当事人，销售者没有违约责任。
          \item 产品的警示与召回。\zd{投入流通}，扩大损害部分担责。
          \item 惩罚性赔偿。明知 + 人身伤亡。法院自由裁量。
        \end{enumerate}
  \item 机动车交通事故。谁开车（使用人）找谁。\al{甲驾车撞倒乙，经查车是丙从丁处盗得。甲乙连带，丁无责 √}。
        \begin{enumerate}
          \item \yi 车撞车过错。\er 车撞非机无过错。考免责事由，看受害人是否有过错。\al{闯红灯}。
          \item \zd{违法在先}，链条上所有人\zd{连带}责任。\al{报废车、盗赃车}。
          \item 车辆所有人、管理人。过错范围内补充。
        \end{enumerate}
  \item 医疗损害。看有没有过错。诊疗规范 + 病例 \yjt 医院证明。只考过一次。
  \item 环境污染和生态破坏。无过错责任。免责事由。\zd{不可抗力 + 补救措施}。修负责任。
  \item 高度危险。无过错责任。\al{鱼竿甩到高压线（多多少少承担点）}。
  \item 饲养动物损害。
        \begin{enumerate}
          \item 动物园动物。过错。
          \item 违禁饲养动物。没有任何免责事由。
          \item \zd{违规}饲养动物。无过错。免责事由。\zd{受害人故意}（重大制度修改）。\al{逗狗什么不算，除非明说故意}。
        \end{enumerate}
  \item 建筑和物件损害。
        \begin{enumerate}
          \item 是/不是工程质量问题 \yjt 建设单位、施工单位连带/所有人、使用人、管理人、第三人。
          \item 地面施工。倒塌塌陷。谁干的找谁。
          \item 高空抛物。公平补偿。结合小区考，物业公司安保义务人。
          \item 道路林木/挖坑。免责。尽到了管理维护义务/\zd{法定警示义务}。
          \item 悬挂物脱落坠落。所有人、使用人、管理人。\al{甲租乙房，阳台养花，小区物业多次提醒}。小区物业不是管理人？
        \end{enumerate}
\end{enumerate}
