\section{收养关系}
\begin{enumerate}
  \item 送养人、收养人、被收养人（核心）。
  \item 被收养人>= 8 岁要征得同意。
  \item 收养人。原则（双方均）30，无配偶者收养异性 >= 40+。
  \item 一般要求。无子一子有能力，无病无罪满 30。
  \item 三代以内同辈旁系血亲（过继子女）。\zd{没有年龄限制}，如果华侨收养，还不受收养人数限制。\input{draw/收养关系.tex}
  \item 收养孤儿院、残疾、儿童福利院的，不受人数限制。
  \item 继父、继母收养，生父母同意即可。
  \item 成立时间。可以签订收养协议，但只看\zd{收养登记手续}。
  \item 收养关系的解除。成年前不得解除、有约从约、遗弃虐待 \yjt 解除登记。
\end{enumerate}
