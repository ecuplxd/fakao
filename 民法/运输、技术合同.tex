\section{运输、技术合同}
\begin{enumerate}
  \item 不是重点考试对象。
  \item 运输。
        \begin{enumerate}
          \item 客运 \yjt 人身、财产。
                \begin{enumerate}
                  \item 承运人无过错责任。不因免费而免责。
                  \item 免责事由。旅客自身健康原因、故意 \hz 重大过失。
                  \item 自带物品过错责任。\al{喇叭广播注意贵重物品}。
                  \item 托运物品无过错责任。
                \end{enumerate}
          \item 货运。托运人任意解除权、留置权。没考过。
        \end{enumerate}
  \item 技术合同。\zd{开发、转让、许可}、咨询、服务。其他内容参看知识产权。
        \begin{enumerate}
          \item 无效情形。\zd{非法垄断、不让改进、侵害他人技术成果}。
        \end{enumerate}
\end{enumerate}
