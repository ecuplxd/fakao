\section{运输、技术合同}
\begin{enumerate}
  \item 不是重点考试对象。
  \item 运输。
        \begin{enumerate}
          \item 客运 \yjt 人身、财产。\al{小甲放学回家路上，将石块仍向正常行驶的出租车，致使乘客乙受伤}。
                \begin{enumerate}
                  \item 承运人自身造成的\zd{人身损害、托运物}品 \yjt 无过错。不因免费而免责。
                  \item 乘客受到的侵权、随身财物 \yjt 过错。\al{这就是为啥喇叭广播注意贵重物品}。
                  \item 免责。\zd{旅客自身}健康原因、\zd{旅客故意 \hz 重大过失}。\al{不可抗力 \cuo}。
                \end{enumerate}
          \item 货运。托运人任意解除权、承运人留置权。没考过。
        \end{enumerate}
  \item 技术合同。\zd{开发、转让、许可}、咨询、服务。其他内容参看知识产权。
        \begin{enumerate}
          \item 无效情形。\zd{非法垄断、不让改进、侵害他人技术成果}。\al{经查该技术秘密是甲通过不正当手段从丙处获得}。
          \item \zd{命题陷阱。不能看到有“技术”就选。“纯脑力”输出}。
          \item 技术秘密（没去申请专利）。\zd{使用权、转让权、收益分配}方法有约 \yjt 均有。
          \item 独占许可，要求权利人都同意，否则无效。
        \end{enumerate}
\end{enumerate}
