\section{运输、技术合同}
\begin{enumerate}
  \item 不是重点考试对象。
  \item 运输。
        \begin{enumerate}
          \item 客运 \yjt 人身、财产。
                \begin{enumerate}
                  \item 承运人责任，无过错责任。不因免费而免责。
                  \item 免责事由。旅客自身健康原因；故意 \hz 重大过失。
                  \item 自带物品。过错责任。\al{喇叭广播注意贵重物品}。
                  \item 托运物品。无过错。
                \end{enumerate}
          \item 货运，没考过，托运人任意解除权，留置权。
        \end{enumerate}
  \item 技术合同。\zd{开发、转让、许可}、咨询、服务。
        \begin{enumerate}
          \item vs 技术秘密 \yjt 没去申请专利。使用权，转让权，收益分配方法有约 \yjt 均有。
          \item \zd{无效的技术合同}。非法垄断，不让改进；侵害他人技术成果。
          \item 开发。
                \begin{enumerate}
                  \item 委托开发。委托合同原理。
                        \begin{enumerate}
                          \item 专利申请人：谁完成归谁。事实行为。
                          \item 委托人：转让的，同等条件优先受让；依法实施。
                        \end{enumerate}
                  \item 合作开发。共有制度。申请专利一票否决权（住改商）；放弃申请，免费实施。
                \end{enumerate}
          \item 转让和许可合同同上。
          \item 许可。
                \begin{enumerate}
                  \item 内容。\yi \zd{专利}（公开）。发明 \yjt\, 20；实用新型 \yjt\, 10；外观设计 \yjt\, 15 年；\er \zd{技术秘密}（未公开）。
                  \item 方式。（独占/1 个、排他）\yjt 征得同意；普通。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
