\section{违约责任}
\begin{enumerate}
  \item 产生、承担。必考。
  \item 法律责任。
        \begin{enumerate}
          \item 刑事责任。
          \item 行政责任。
          \item \zd{民事责任}（优先）。\zd{缔约过失责任、违约责任、侵权责任}。都是债权请求权，\zd{择一选择}。
        \end{enumerate}
  \item \zd{\blx{不履行或不适当履行合同义务}而应承担的民事责任}。\zd{违什么，赔什么}。
        \begin{enumerate}
          \item 无过错责任。
          \item 例外。赠与、\zd{委托}、保管、仓储、客运对旅客自带物品的毁损 \yjt 过错。\al{律师败诉}
        \end{enumerate}
  \item 构成要件。\zd{合法有效的合同 + 违约行为 + 无免责事由}（法定免责事由仅限不可抗力）。
        \begin{enumerate}
          \item 预期违约。\yi 明示违约。\al{乙致函甲表示无力履行合同}。\er 默示违约。
          \item 实际违约。考的多。
                \begin{enumerate}
                  \item 不履行。拒绝履行 \yjt 主观；履行不能 \yjt 客观。
                  \item 不适当履行。
                        \begin{enumerate}
                          \item 瑕疵履行。\yi 瑕疵给付 \yjt 仅违约。\er \zd{加害给付} \yjt 违约 + 侵权。质量问题。
                          \item 部分（少）履行。数量问题。\zd{不是多履行}。
                          \item 延迟履行。\yi 迟延给付。\er 迟延受领。\zd{法定催告义务}。时间问题。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{表面看是违约，实质不是}。
                \al{甲出租房给乙，租赁期内\xhx{未通知乙}就过户给不知情的丙。
                  乙可以请求\xhx{解除}租赁合同，\scx{因甲出卖房屋未通知乙，构成重大违约} \cuo。
                  重点其实在前半句，不要被带偏了}。
          \item \zd{预约也是合同，违反预约同样能构成违约责任}。
        \end{enumerate}
  \item 责任形式。
        \begin{enumerate}
          \item \zd{继续履行}。债的学理分类来考虑能否继续履行。\al{甲需承担继续履行 xx 的违约责任、要求继续履行 \cuo}。
                \begin{enumerate}
                  \item 货币之债、种类之债不能被免除；劳务之债不能强迫。
                  \item \zd{合同僵局}。主观非恶意、继续履行显失公平、非违约方拒绝属于权利滥用。\al{钉子户}。
                \end{enumerate}
          \item 采取补救措施。修理、更换、重做、退货、减价。
          \item 损害赔偿金/赔偿损失。\zd{\blx{以存在实际的损失为前提}}。\al{质量与产品书不符 \yjt 要求赔偿损失 \cuo}。
                \begin{enumerate}
                  \item 预期\zd{可得利益}的损失。中间商赚差价。
                        \al{甲超市以 100 一只向乙采购 20 只母鸡，零售价 250，乙只交付了 10 只 \yjt 乙赔 1500}。
                  \item 填补性损害原理。有多少损害赔偿多少。
                        \al{甲租乙房，约定帮乙小孩补课抵房租，后甲不知所踪 1 个月，乙只能另寻他人，1 个月/2000，1 个月后，甲归来 \yjt 甲赔 2000}。
                  \item \zd{可预见性规则}。\al{电脑硬盘损坏，里面有价值 10W 书稿 \yjt 赔电脑硬盘价格}。
                  \item \zd{减损规则}。违约方应采取适当措施防止损失扩大。
                \end{enumerate}
          \item 违约金。
                \begin{enumerate}
                  \item 惩罚性违约金。增补课程出。
                  \item 补偿性违约金。\zd{司法调整规则}。
                  \item 计算。\al{甲乙约定违约金 xxW，后甲违约，给乙造成损失 100W}。\zd{不是 100 + X 来赔}！
                        \begin{enumerate}
                          \item 约定 80W \yjt 补 20W。不够可以加。
                          \item 约定 120W \yjt \zd{实际损失上下浮动 30\%}。在区间，直接用最高。
                          \item 约定 150W \yjt\, [100, 130] 法院、仲裁裁量。超过可以减。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{定金}（本质是担保制度下的金钱担保）。立约、成约、证约、\zd{违约}（考试考这个）、解约定金。
                \begin{enumerate}
                  \item 属于实践性、书面、从合同。实际\zd{交付定金时生效}。
                  \item <= 主合同标的额 \zd{20\%}（实践中大家一般都只交这么多）。
                  \item 定金罚则。要构成根本违约。\zd{给付方违约不得请求返还，收受方双倍返还}。
                  \item 违约金、定金择一。功能一样。
                  \item \zd{没有约定定金性质的，不予支持}。\al{预付款 \cuo}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
