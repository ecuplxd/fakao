\section{违约责任}
\begin{enumerate}
  \item 必考。产生、承担。
  \item \zd{民事责任：缔约过失责任、违约责任、侵权责任}。
  \item 不履行或不适当履行合同义务而应承担的民事责任；无过错责任，例外：赠予和委托（\al{律师败诉}）。
  \item 构成要件。合法有效合同 + 违约行为：
        \begin{enumerate}
          \item 预期\blh。\yi 明示\blh；\er 默示\blh
          \item 实际\blh。考的多。
                \begin{enumerate}
                  \item 不履行。拒绝履行 \yjt 主观；履行不能 \yjt 客观。
                  \item 不适当履行。
                        \begin{enumerate}
                          \item 瑕疵履行。\yi 瑕疵给付 \yjt 仅违约；\er \zd{加害给付} \yjt 违约 + 侵权。质量问题。
                          \item 部分（少）履行。数量问题。
                          \item 延迟履行。\yi 迟延给付；\er 迟延受领。\zd{法定的催告义务}。时间问题。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 责任形式。
        \begin{enumerate}
          \item \zd{继续履行}。债的学理分类来考虑能否继续履行。
                \begin{enumerate}
                  \item 货币之债、种类之债不能免除；劳务之债不能强迫。
                  \item \zd{合同僵局}。主观非恶意；继续履行显失公平；非违约方拒绝属于权利滥用。\al{钉子户}。
                \end{enumerate}
          \item 采取补救措施。修理、更换、重做、退货、减价。
          \item 损害赔偿金。范围：可得利益的损失。
                \begin{enumerate}
                  \item 填补性损害原理。有多少损害赔偿多少。
                  \item \zd{可预见性规则}，\al{电脑硬盘损坏，里面有价值 10W 书稿}。
                  \item \zd{减损规则}。违约方应采取适当措施防止损失扩大。
                \end{enumerate}
          \item 违约金。
                \begin{enumerate}
                  \item 惩罚性违约金。增补课程。
                  \item 补偿性违约金。\zd{司法调整规则}。损失 100W
                        \begin{enumerate}
                          \item 约定 80W \yjt 补 20W
                          \item 约定 120W \yjt 上下浮动 30\%
                          \item 约定 150W \yjt [100, 130] 法院、仲裁裁量。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{定金}（担保制度 \yjt 金钱担保）。立约、成约、证约、\zd{违约}（考试考这个）、解约\blh
                \begin{enumerate}
                  \item 属于实践性、书面、从合同。
                  \item 限额，20\%
                  \item 定金罚则内容 \yjt 根本违约。\zd{给付方违约不得请求返还，收受方双倍返还}。
                  \item 违约金、定金择一。功能一样。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
