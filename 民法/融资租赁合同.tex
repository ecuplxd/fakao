\section{融资租赁合同}
\begin{enumerate}
  \item 基本原则。
        \begin{enumerate}
          \item 本质是融资。租赁是手段，借钱是目的。\al{飞机、实验设备}。
          \item 未经登记，不得对抗善意第三人，不得行使取回权。
          \item 利率不受 LPR 限制。
          \item 租赁关系适用租赁合同有关规定。
        \end{enumerate}
  \item 承租人。
        \begin{enumerate}
          \item 维修义务。
          \item 不可抗力一定是风险，\zd{承租人承担}。
        \end{enumerate}
  \item \zd{出卖人}。
        \begin{enumerate}
          \item 承担瑕疵担保责任
        \end{enumerate}
  \item 传统型的融资租赁合同。三方关系，\zd{真正利他合同}。
        \begin{enumerate}
          \item 融资租赁公司（准金融机构）只收租金，不承担任何责任。
          \item \zd{留购}。支付象征性价款。没考过。
        \end{enumerate}
  \item 两方当事人的售后回租型。占有改定的应用。
        \begin{enumerate}
          \item \zd{虚构}租赁物合同无效。金融要服务实体。\al{以假乱真、偏离实际价值、欺诈、违章建筑、不存在}。
          \item \zd{融资租赁公司无行政许可不影响效力}。新增。
          \item vs 让与担保（没有金融牌照）。
        \end{enumerate}
\end{enumerate}
