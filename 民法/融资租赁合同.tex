\section{融资租赁合同}
\begin{enumerate}
  \item 本质是融资。租赁是手段，借钱是目的。\al{飞机、实验设备}。
  \item 未经登记，不得对抗善意第三人，不得行使取回权。
  \item 传统型的融资租赁合同。三方关系，真正利他合同。
        \begin{enumerate}
          \item 融资租赁公司（准金融机构）只收租金，不承担任何责任。
          \item 不可抗力一定是风险，承租人承担。
          \item \zd{留购}。支付象征性价款。没考过。
        \end{enumerate}
  \item 两方当事人的售后回租型。占有改定的应用。
        \begin{enumerate}
          \item 虚构租赁物合同无效。金融要服务实体。
          \item \zd{融资租赁公司无行政许可不影响效力}。新增，没考过。
          \item vs 让与担保（没有金融牌照）。
        \end{enumerate}
\end{enumerate}
