\section{租赁合同}
\begin{enumerate}
  \item 负担行为。\zd{移转标的物使用权的合同}。
  \item 超过 20 年（首租、续租）无效、备案登记不影响效力、租期不满 6 月可口头。
  \item 法定维修义务。承租人过错承租人自己维修。
  \item 承租人权利。
        \begin{enumerate}
          \item 法定解除权。根本违约。
          \item 买卖不破租（登记）赁。\zd{前提已合法占有租赁物}。命题陷阱，打时间差。
                \al{甲把画租给乙，约定 10 日后交付，第二天甲占有改定方式把画卖给了丙 \yjt 乙不适用买卖不破租赁}。
          \item 优先购买。
          \item 续租权。同等条件\zd{优先承租}。
        \end{enumerate}
  \item 承租人义务。
        \begin{enumerate}
          \item 禁止擅自转租。构成根本违约 \yjt 出租人解除权。主观起算\zd{6 个月除斥期间}。
          \item 未经同意不得添附。
        \end{enumerate}
  \item 第三人代为履行抗辩权。见合同的履行部分。
  \item 租赁合同无效（含续租）。\yi 违法的建筑。\er 出租人无租金（要合法），但有占有使用费（不当得利）。
  \item 装饰装修扩建。
        \begin{enumerate}
          \item 征得同意 \yjt 都有过错按份。
          \item 恢复原状、赔偿损失。
          \item 费用有约从约，无约承租人。
        \end{enumerate}
  \item 临时建筑出租。
        \begin{enumerate}
          \item 一审辩论终结前取得批准的，租赁合同有效。
          \item 租赁期超使用年限部分无效，一审辩论终结前取得延长资格的，有效。\al{无权将该房屋继续出租 \dui}。
        \end{enumerate}
  \item 不定期租赁合同。
        \begin{enumerate}
          \item \dydy 6 月以上。
          \item 没有约定 \hz 约定不明视为不定期。承租人任意解除权。
          \item \al{甲租乙房，未约定租期，仅约定甲父失踪回来后合同终止}。
        \end{enumerate}
  \item 一房数租。
        \begin{enumerate}
          \item 出租人瑕疵担保责任。
          \item 优先权。合法占有 \dy 登记 \dy 合同成立顺序。\al{甲租给乙并已交付 \yjt 甲租给丙 \yjt 丙转租给丁}。
        \end{enumerate}
\end{enumerate}
