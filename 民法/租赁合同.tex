\section{租赁合同}
\begin{enumerate}
  \item 负担行为。不发生所有权变动。
  \item 超过 20 年无效、备案登记不影响效力、租期不满 6 月可口头。
  \item 法定维修义务。承租人过错承租人自己维修。
  \item 承租人权利。法定解除权（根本违约）；买卖不破租（登记）赁；优先购买；续租权 \yjt 优先（同等条件）承租。
  \item 禁止擅自转租。构成根本违约，解除。\zd{6 个月除斥期间}。
  \item 第三人代为履行抗辩权。
  \item 无效。违法的建筑。无租金（要合法），但有占有使用费。
  \item 未经同意不得添附。
  \item 装饰装修扩建。征得同意。都有过错按份；恢复原状、赔偿损失；费用有约从约，没有不得请求。
  \item 不定期租赁合同。任意解除权。
\end{enumerate}
