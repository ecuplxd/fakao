\section{保理合同}
\begin{enumerate}
  \item 新增的。\zd{债权转让}，纯粹的金融合同；只有金融，没有实体。\al{应收账款变现金}。
  \item 虚构基础交易关系。知情 \yjt 无效；不知情 \yjt 有效。
  \item 债权转让规则 2 种。
        \begin{enumerate}
          \item \zd{有追索权}/回购型\blh。找债务人、债权人均可，担保保理人债权本息全额偿还。\input{draw/保理合同.tex}
          \item 无追索权/买断型\blh。纯粹的债权转让，没有任何担保，风险自担。现实中少。
        \end{enumerate}
  \item 规则相同。一债多保。登记 > 通知 > 比例。
        \begin{enumerate}
          \item 应收账款质押。权利质押，登记，物权效力。
          \item 债权转让。通知，债权效力。
          \item 保理合同。
        \end{enumerate}
\end{enumerate}
