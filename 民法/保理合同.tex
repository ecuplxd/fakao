\section{保理合同}
\begin{enumerate}
  \item 新增的合同类型。\bs{本质是债权转让，纯粹的金融合同。应收账款变现金}。只有金融，没有实体。
  \item 虚构基础交易关系。\zd{知情 \yjt 无效。不知情 \yjt 有效}。
  \item 债权转让规则 2 种。
        \begin{enumerate}
          \item \zd{有追索权}/回购型债权转让。找债务人、债权人均可。\bs{担保保理人债权本息全额偿还}。\input{draw/保理合同.tex}
          \item 无追索权/买断型债权转让。只能找\al{乙}。纯粹的债权转让，无担保，无选择权，风险自担。现实中少。
        \end{enumerate}
  \item 规则相同。一债多保。\bs{登记 \dy 通知 \dy 比例}。
        \begin{enumerate}
          \item 应收账款质押。登记。
          \item 债权转让。内外有别，双重通知。债权效力。
          \item 保理合同。
        \end{enumerate}
\end{enumerate}
