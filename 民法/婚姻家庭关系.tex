\section{婚姻家庭关系}
\begin{enumerate}
  \item 1 个单选，1 个多选。
  \item \zd{配偶权}（重点）、亲子（包括收养，继父继母）、亲属。没啥难度。
  \item 结婚。
        \begin{enumerate}
          \item 实质（不考）+ 形式（登记 \yjt 行政确认）。
          \item 登记瑕疵。不是民事诉讼，救济走行政复议 \hz 行政诉讼。
          \item 效力瑕疵。\zd{结婚过错损害赔偿}。物质 + 精神。
                \begin{enumerate}
                  \item 无效。宣告无效制。不允许调解、撤诉；死了也要继续审下去；无效事由要持续到起诉时，否则视为不存在。
                        \al{甲起诉乙离婚，经审理查明，两人感情确已破裂，但乙结婚时未满 20，法院应当如何处理？
                          A.判决确认婚姻关系无效 B.裁定驳回起诉 C.判决驳回离婚诉讼请求 \xhx{D.判决准予离婚}
                        }。
                  \item 可撤销。重婚、未达法定婚龄、近亲属、重大疾病未告知、胁迫。本人才能去。
                \end{enumerate}
        \end{enumerate}
  \item \zd{成年子女不能提起亲子关系否认之诉}。人伦道德。\zd{人工授精、试管婴儿视为婚生子女}。没考过。
  \item 夫妻财产。法定共同和约定共同制，共同为原则，个人为例外。
        \begin{enumerate}
          \item 法定共同。
                \begin{enumerate}
                  \item 知识产权收益。\zd{发表 \hz 获得稿酬}在婚姻期间。
                  \item 婚前存款、房产生的\zd{孳息和自然增值属个人}。
                  \item 其他共同。投资、开公司、生产经营。
                \end{enumerate}
          \item 法定个人。
                \begin{enumerate}
                  \item 一方婚前财产，除非赠予。房本加名。
                  \item 人身损害赔偿金。
                  \item 遗赠 \hz 赠予合同确定只归一方的。
                  \item \zd{夫妻间赠予可以行使任意撤销}。
                \end{enumerate}
        \end{enumerate}
  \item 婚姻持续期间共同财产的处理和分割。
        \begin{enumerate}
          \item 抚养义务。重大疾病。
          \item 债务认定和清偿。\zd{看借款目的和用途}。
                \begin{enumerate}
                  \item 共同生活、经营、意思表示。
                  \item 个人挥霍。赌博、个人事务。
                \end{enumerate}
        \end{enumerate}
  \item 离婚。
        \begin{enumerate}
          \item 方式。
                \begin{enumerate}
                  \item 协议。书面形式、冷静期、亲自去。
                  \item 诉讼。感情确已破裂、重婚或与他人同居、家暴虐待。
                \end{enumerate}
          \item 离婚过错损害赔偿。\zd{仅一方有过错}。
          \item 女方三期保护。怀孕、分娩后 1 年、终止妊娠/流产 6 个月。例外。\yi 女方可随时提出；\er 男方喜当爹。
          \item 离婚后的人身关系。
                \begin{enumerate}
                  \item 分孩子。一般给女方。
                  \item 8 岁以上问孩子 \hz 协商。
                  \item 离婚不影响监护。不得剥夺抚养、教育、保护、\zd{探望（不是义务）}的权利。
                  \item 不能强制孩子。
                \end{enumerate}
          \item 财产关系。经济补偿制度，不设条件。一方付出较多的、3 年时效。\al{全职太太}。
        \end{enumerate}
\end{enumerate}
