\section{婚姻家庭关系}
\begin{enumerate}
  \item 1 个单选，1 个多选。
  \item \zd{配偶权}（重点）、亲子（包括收养，继父继母）、亲属。没啥难度。
  \item 结婚。
        \begin{enumerate}
          \item 实质（不考）+ 形式（登记 \yjt 行政确认）。
          \item 登记瑕疵。不是民事诉讼，救济走行政复议 \hz 行政诉讼。\al{孙新孙立双胞胎，孙立拿着哥哥身份证和哥哥女友办理了结婚登记手续}。
          \item 效力瑕疵。\zd{结婚过错损害赔偿}。物质 + 精神。\zd{婚、龄、属、病、胁}。
                \begin{enumerate}
                  \item 无效。\zd{重婚、未达法定婚龄、近亲属}。宣告无效制。\al{甲起诉乙离婚，经审理查明，两人感情确已破裂，但乙结婚时未满 20，法院应当如何处理？
                          A.判决确认婚姻关系无效 B.裁定驳回起诉 C.判决驳回离婚诉讼请求 \xhx{D.判决准予离婚}}。
                        \begin{enumerate}
                          \item 不允许调解、撤诉。
                          \item 死了也要继续审下去。
                          \item 无效事由要持续到起诉时，否则视为不存在。
                        \end{enumerate}
                  \item 可撤销。\zd{重大疾病未告知、胁迫}。本人才能去。\al{甲隐瞒同性恋重大事实 × \yjt 欺诈不属于撤销情形}。
                \end{enumerate}
        \end{enumerate}
  \item \zd{成年子女不能提起亲子关系否认之诉}。人伦道德。\zd{人工授精、试管婴儿视为婚生子女}。没考过。
  \item 夫妻财产。法定共同和约定共同制，共同为原则，个人为例外。
        \begin{enumerate}
          \item 法定共同。\zd{婚姻关系存续期间}。
                \begin{enumerate}
                  \item 工资、奖金、劳务报酬。
                  \item 生产、经营、投资收益。\al{开公司}。
                  \item 知识产权收益。实际取得 \hz 已经明确可以取得的财产性收益。\al{发表 \hz 获得稿酬在婚姻期间}。
                  \item 继承 \hz 受赠的财产。\zd{确定只归一方的除外}。
                  \item 婚前存款、房产生的\zd{孳息和自然增值属个人}。
                  \item 其他共同。住房补贴、住房公积金、养老保险金、破产安置补偿费。
                \end{enumerate}
          \item 法定个人。
                \begin{enumerate}
                  \item 一方婚前财产，除非进行了赠与。\al{房本加名}。
                  \item 人身损害赔偿金。
                  \item 继承 \hz 受赠确定只归一方的。
                  \item \zd{夫妻间赠与可以行使任意撤销}。\al{甲承诺子女出生后，将婚前所有的门面房变更登记为夫妻共同财产，后女儿出生，甲不愿兑现承诺}。
                \end{enumerate}
          \item 婚前协议有效。\al{甲乙书面约定婚后各自收入归个人所有}。
        \end{enumerate}
  \item 婚姻关系存续期间共同财产的处理和分割。
        \begin{enumerate}
          \item 抚养义务（含前妻所生子女）\yjt 请求分割。\al{重大疾病}。\al{甲乙离婚后小甲和乙过，甲和丙再婚，小甲因重病需要 20W，如丙不同意甲支付医疗费，有权要求分割共有财产}。
          \item 债务认定和清偿。\zd{看借款目的和用途}。
                \begin{enumerate}
                  \item 共同生活、经营、意思表示 \yjt 无限连带。\al{应承担一半 ×}。\al{婚前借钱，婚后将借款用于婚房装修}。
                  \item 个人挥霍。赌博、个人事务。
                \end{enumerate}
          \item 家事代理权。因日常生活需要处分共同财产，任一方均有权决定。
        \end{enumerate}
  \item 离婚。
        \begin{enumerate}
          \item 法定情形。\zd{重婚同居暴虐遗}；赌博吸毒两分居；失踪生育致婚离。
          \item 方式。
                \begin{enumerate}
                  \item 协议。书面形式、冷静期、亲自去。
                  \item 诉讼。感情确已破裂、重婚或与他人同居、家暴虐待。应当进行调解。
                \end{enumerate}
          \item （附条件的）离婚协议。可以反悔 \yjt 成立但为生效，一切照旧。
          \item 离婚过错损害赔偿。\zd{仅一方有过错}。
                \begin{enumerate}
                  \item \zd{重婚}、与他人\zd{同居}；家庭\zd{暴}力；\zd{虐}待、\zd{遗}弃家庭成员；其他重大过错。
                        \begin{enumerate}
                          \item \al{甲保管财产但拒绝向乙提供治疗费 √ \yjt 虐待遗弃}。
                          \item 关于其他，没提到\zd{重大}就不算。\al{吸毒恶习 ×}。
                        \end{enumerate}
                  \item 婚姻关系存续期间，不离婚而只单独提损害赔偿的，不予受理（离婚时一起提），但可以请求《治安管理处罚法》处罚。
                  \item 仅限夫妻双方之间。\al{甲和乙同居破坏丙家庭，甲应向丙赔礼道歉 ×}。
                  \item 夫以妻\zd{擅自中止妊娠}侵犯其生育权（协议约定无效）为由请求损害赔偿的，不予支持。
                \end{enumerate}
          \item 女方三期保护。怀孕、分娩后 1 年、终止妊娠/流产 6 个月。例外。\yi 女方可随时提出；\er 男方喜当爹。
          \item 离婚后的人身关系。
                \begin{enumerate}
                  \item 分孩子。一般给女方。
                  \item 8 岁以上问孩子 \hz 协商。
                  \item 离婚不影响监护。不得剥夺抚养、教育、保护、\zd{探望}的权利。
                        \begin{enumerate}
                          \item \al{甲连续几年对小甲不闻不问，违背了法定的探望义务 ×} \yjt 是权利，不是义务，对于对方才是义务 \yjt 协助义务。
                        \end{enumerate}
                  \item 不能强制孩子。\al{可依法强制从甲处接领小甲与乙会面 ×}。\al{带小甲到指定地点让乙探望、带乙到甲住处探望 √}。
                \end{enumerate}
          \item 财产关系。
                \begin{enumerate}
                  \item 经济补偿制度。不设条件、一方付出较多的、3 年时效。\al{全职太太}。
                  \item 隐藏、转移、变卖、毁损、挥霍方少分 \hz 不分，另一方多分。\zd{不看过错啊！过错针对的是损害赔偿}。
                  \item 请求再次分割夫妻共同财产的诉讼时效为 3 年，从发现之次日起计算。\al{发现 \hz \scx{应当发现} ×}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
