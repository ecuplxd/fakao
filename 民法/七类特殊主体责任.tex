\section{7 类特殊主体责任}
\begin{enumerate}
  \item 内外有别。抓内部外部关系。人多的地方都是过错。一个侵权行为可能存在多个竞合。\al{宠物狗从阳台坠落}。
  \item 监护人。
        \begin{enumerate}
          \item 无过错。尽到监护职责，可以减轻。\al{无需承担侵权责任 \cuo}。
          \item 被监护人有独立财产 \yjt 监护人补充。
        \end{enumerate}
  \item \bs{用工}。（相对）无过错。危险控制理论。对内追偿要证明有\bs{故意 \hz 重大过失}。
        \begin{enumerate}
          \item \zd{工作人员}。\zd{执行工作任务致人损害，用人单位替代责任}。看到员工、公司 + 员工出现在选项一律错。
          \item 有用工无合同，有合同无用工。谁用工谁无过错，无用工方过错按份/相应的责任。\al{劳务派遣}。
                \begin{enumerate}
                  \item \al{甲用工，乙派遣丙。乙承担赔偿责任，甲承担相应的责任 \cuo。甲乙连带 \cuo。丙承担责任 \cuo}。
                  \item \al{甲承担赔偿责任，乙承担相应的责任 \dui}。别混了。
                \end{enumerate}
          \item \zd{执行职务行为}。外观主义认定。
                \begin{enumerate}
                  \item \al{快递小车}。
                  \item \al{公司\scx{明文禁止代驾，乙为获得高额报酬而代驾}，乙应承担赔偿责任 \cuo}。
                  \item \al{汽修厂修理人员甲偷开车上路，违章驾驶撞伤乙 }。
                        % \item 命题陷阱。\al{甲执行职务过程中，与乙发生口角，将乙打伤}。
                \end{enumerate}
          \item \sjt \zx{“员工”被侵权，双重赔偿}。\zd{存在雇佣关系}。
          \item \zd{接受劳务方}。无过错。\al{甲雇佣乙料理家务}。
        \end{enumerate}
  \item 帮工（无偿的） \ydy 用工。\al{甲家盖房，邻居乙丙前来帮忙。丙\xhx{因失误}从高处摔下受伤，乙\xhx{不小心}撞伤小孩丁}。
        \begin{enumerate}
          \item 帮工人侵权他人。免责 \yjt 明确拒绝帮工。
          \item 被他人侵权。第三人承担赔偿责任 \hz 被帮工人\zd{适当补偿}。
          \item 帮工人过错。\al{对丙的损害，甲不承担赔偿责任 \dui{与有过失}}。
        \end{enumerate}
  \item 定作人。过错（对承揽人支配力非常弱）。免责 \yjt 看选任、指示有无过错。同复代理。
  \item 网络服务提供者。避风港规则。[立即删除、屏蔽、断开链接]（权利人只能请求一次） \yjt 扩大部分连带。\zd{更正删除请求权}。
  \item \zx{安保义务人}。\zd{过错补充}。不以实际交易为前提。
        \begin{enumerate}
          \item \al{公共场所、商场、小区物业；果园。承担全部损失 \cuo，相应损失 \dui}。
          \item 注意特殊的场所。\al{甲承包了一片海域，从事采珠业务。乙\xhx{自费}前来训练潜水采珠，后不幸溺毙}。
        \end{enumerate}
  \item 教育机构。过错补充。
        \begin{enumerate}
          \item 学校不是监护人。教育、管理、保护。\al{小甲父母的监护职责已移转到学校 \cuo}。
          \item 学校组织的校外活动视为在校期间。\al{春游}。
        \end{enumerate}
\end{enumerate}
