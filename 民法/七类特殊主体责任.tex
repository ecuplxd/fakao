\section{7 类特殊主体责任}
\begin{enumerate}
  \item 内外有别，\zd{抓内部外部关系}；\zd{人多的地方都是过错责任}。
  \item 监护人。替代责任；\zd{被监护人有独立财产，监护人补充责任}。
  \item \zd{用工}。\zd{对内要证明有故意，重大过失才能追偿；危险控制理论；被侵权，双重赔偿}。
        \begin{enumerate}
          \item 员工对外没责任。
          \item 劳务派遣 \yjt 谁用工，谁无过错，反之过错，按份。有用工无合同，有合同无用工。
          \item 执行职务行为认定，\zd{外观主义}，\al{快递小车}。
        \end{enumerate}
  \item 帮工（无偿的）。\zd{不真正连带责任}。
  \item 定作人。对承揽人支配力非常弱。过错责任，看选任、指示有没有过错。
  \item 网络服务提供者。\zd{删除、屏蔽、断开链接} \yjt 避风港规则，否则\zd{对扩大损失的部分连带责任}。
  \item 安保义务人。公共场所，\al{商场}。\zd{不以实际交易为必要}，过错范围内补充责任。
  \item 教育机构责任。学校组织的校外活动视为在校期间。
\end{enumerate}
