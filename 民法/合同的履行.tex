\section{合同的履行}
\begin{enumerate}
  \item 电子合同（网购）。规则无区别。
        \begin{enumerate}

          \item 要约。发布的商品信息。
          \item 承诺。选择商品，提交订单成功。
          \item 成立。提交订单成功时。
          \item 签收时间 \yjt 凭证载明的时间 \yjt 实际提供服务的时间 \yjt 数据传输到达。
        \end{enumerate}
  \item 涉他合同 vs 束己（租赁）。是否只能约束合同当事人。利他合同。
        \begin{enumerate}
          \item 为第三人创设权利 \yjt 向第三人履行。\zd{第三人是否享有独立的请求权}。
                \begin{enumerate}
                  \item 不真正利他。不是合同当事人，纯粹的受益。\al{甲和乙花店协议，乙需每天给丙送花；给你点外卖}。
                  \item 真正利他。
                        \begin{enumerate}
                          \item 双方特别约定要第三人纳入合同的，内部通知 + 外部不反对。
                          \item 真正。是合同当事人，享有独立的请求权，却\zd{不负义务}。
                          \item \al{丙要求乙送花，乙说甲没付钱}。对于乙，先/顺序履行抗辩权对丙使用 \yjt 抗辩权的移转。
                        \end{enumerate}
                \end{enumerate}
          \item 为第三人创设义务 \yjt 由第三人履行。\al{连环买卖}。
        \end{enumerate}
  \item 第三人代为履行/涤除权。新增。明知的非债清偿。\zd{第三人履行该债务具有合法利益}。
        \begin{enumerate}
          \item 基于合同目的。\al{甲 1W 卖表 \yjt 乙 2W 卖 \yjt 丙，丙为拿到表付 1W 给甲，付 1W 给乙}。
          \item 基于特殊感情帮还钱。\zd{货币之债没有人身专属性，谁来履行都行}。无协议。
          \item 实现对债务人的赠予。\al{清空购物车}。\input{draw/合同的履行.tex}
        \end{enumerate}
  \item 双务合同履行中的抗辩权。谁先履行谁吃亏。
        \begin{enumerate}
          \item 同时履行/取货时付款。一手交钱一手交货。同时履行抗辩权。
          \item 约定先后顺序。顺序履行抗辩权。
                \begin{enumerate}
                  \item 后履行一方 \yjt 先/顺序履行抗辩权。
                  \item 先履行一方 \yjt 不安抗辩权。考点。
                        \begin{enumerate}
                          \item 有不安理由，\zd{确切证据}。
                          \item 情形法定。\zd{丧失商誉、经营状况严重、逃债}。
                          \item 通知对方。
                        \end{enumerate}
                \end{enumerate}
          \item \zd{相应的抗辩}。重点关注。\zd{主对主，从对从，全部对全部，部分对部门}。
        \end{enumerate}
\end{enumerate}
