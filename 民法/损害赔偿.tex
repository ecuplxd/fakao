\section{损害赔偿}
\begin{enumerate}
  \item 人身损害赔偿。
        \begin{enumerate}
          \item 同命同价。同一侵权行为造成多人死亡的，\zd{可以}以相同数额确定死亡赔偿金。
        \end{enumerate}
  \item \zd{精神损害赔偿}。结合婚姻家庭、人格权、产品责任。核心考点，1 个选项。
        \begin{enumerate}
          \item \zd{非财产损害}、惩罚性赔偿、\zd{严重的}精神痛苦方、\zd{仅限自然人}。
                \al{事业单位 ×、甲经常失眠 ×、甲\xhx{深}受其扰 √}。
          \item 适用范围。
                \begin{enumerate}
                  \item \zd{人身权益}。
                        \begin{enumerate}
                          \item 配偶权。结婚/离婚过错损害赔偿。
                          \item 亲子权。\al{医院抱错小孩、拐卖儿童}。
                        \end{enumerate}
                  \item 人身纪念、象征意义。\al{遗照、结婚戒指、结婚录像带}。
                  \item 违约之诉 + 人格权受到侵犯 + 因果关系。没考过。
                        \begin{enumerate}
                          \item \al{甲乘 A 公司的出租车去机场，乙超速，甲留疤}。
                          \item \al{甲乘 A 公司的出租车去机场，被后车追尾，甲留疤}。
                        \end{enumerate}
                \end{enumerate}
          \item 起诉。
                \begin{enumerate}
                  \item 原则上是受害人 \yjt 近亲属。\zd{谁痛苦谁去}。\al{甲的母亲可以甲的名义对乙提起侵权之诉 ×}。
                  \item 原则不可以继承。例外。\yi \zd{已起诉}。\er \zd{已}经书面\zd{承诺}给予赔偿。
                \end{enumerate}
        \end{enumerate}
  \item 财产损害赔偿。
        \begin{enumerate}
          \item \zd{全面赔偿原则}。
          \item 客观计算标准。\zd{损失发生时的市场价格} \hz 其他方式计算。\al{\scx{实际进货价 8W}，市价 9W}。
        \end{enumerate}
\end{enumerate}
