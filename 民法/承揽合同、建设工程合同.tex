\section{承揽合同、建设工程合同}
\begin{enumerate}
  \item 承揽。加工、定做、修理。常考。
        \begin{enumerate}
          \item \zd{强烈的人身信赖关系}。
                \begin{enumerate}
                  \item 主要工作\zd{亲自完成}。未征得同意转让主要工作 \yjt 法定解除权（根本违约）。
                  \item 辅助工作可以第三人。无需同意，干得不好 \yjt 违约责任。
                \end{enumerate}
          \item 定作人任意解除权。
                \begin{enumerate}
                  \item 已经履行的部分，按约支付\zd{报酬}；造成损害 \yjt \zd{赔偿责任}。
                  \item \zd{终止后，承揽人仍继续可能会导致侵权}。
                \end{enumerate}
          \item 承揽人留置权。
        \end{enumerate}
  \item 建设工程合同。勘察、设计、\zd{施工}。
        \begin{enumerate}
          \item 4 大禁止行为。
                \begin{enumerate}
                  \item 资质。无资质无效。
                  \item 工程质量。整体发包 + 禁止全部转包 + 主体工程亲自完成。同意也无效，否则根本违约。
                  \item 非主体工程分包需要同意。
                  \item 违法再分包。禁止分包单位再分包。
                  \item 中标备案。
                \end{enumerate}
          \item 合同无效处理。
                \begin{enumerate}
                  \item 阴阳合同。另行签订合同，背离实质（看价款）内容，无效。
                  \item \zd{无效 + 质量合格}要给农民工发钱（\zd{参照最后一份合同折价补偿}）。考试基本考这个情形。
                \end{enumerate}
          \item 垫资。承包人先垫钱。
                \begin{enumerate}
                  \item 性质。没约定垫资性质为\zd{工程欠款}，利息按同期利率计算。
                  \item 利息。无约定视为无利息。
                \end{enumerate}
          \item 交付、竣工、起诉。
          \item 诉讼地位。\zd{农民工起诉，应当受理}。本质还是债权人代位权之诉。
          \item \zd{建设工程价款（不含利息）的法定优先受偿权}。18 个月除斥期间。没考过。
        \end{enumerate}
\end{enumerate}
