\section{承揽合同、建设工程合同}
\begin{enumerate}
  \item \zx{承揽}。\bs{按照指示完成工作，交付工作成果}。加工、定做、修理、复制、测试、校验。常考。
        \begin{enumerate}
          \item 强烈的人身信赖关系。
                \begin{enumerate}
                  \item 主要工作亲自完成。未征得同意转让主要工作 \yjt 根本违约 \yjt 法定解除权。
                  \item 辅助工作可以第三人。无需同意，干得不好 \yjt 违约。
                  \item \zd{在其过错范围内承担相应的赔偿责任}。
                \end{enumerate}
          \item 定作人任意解除权。
                \begin{enumerate}
                  \item 已经履行的部分，按约支付报酬。
                  \item \bs{定作人有选任过失的，承担相应的赔偿责任}。
                  \item 终止后，承揽人仍继续可能会导致侵权。
                \end{enumerate}
          \item 承揽人留置权。不会因为主债权（报酬请求权）诉讼时效期间届满而消灭（物权原则不受）。
          \item 未完成的工作成果（半成品）归定作人。
        \end{enumerate}
  \item 建设工程合同。勘察、设计、施工。\al{合作施工协议}。
        \begin{enumerate}
          \item 4 大禁止行为。无资质则无效。
                \begin{enumerate}
                  \item 整体发包 + 禁止全部转包 + 主体工程亲自完成。同意也无效，否则根本违约。
                  \item 非主体工程分包需要同意。
                  \item 违法再分包。禁止分包单位再分包。
                  \item 中标备案。
                \end{enumerate}
          \item 合同无效。
                \begin{enumerate}
                  \item 阴阳合同。另行签订合同，背离实质（看价款）内容，无效。
                  \item 处理。无效 + 质量合格，可以参照最后一份合同关于工程价款的约定\zd{折价补偿}承包人（要给农民工发钱）。考试基本考这个情形。
                \end{enumerate}
          \item 垫资。承包人先垫钱。
                \begin{enumerate}
                  \item 没约定视为工程欠款，利息按同期利率计算。工程交付之日 \dy 提交竣工结算文件之日 \dy 起诉之日。
                  \item 对垫资利息没有约定的，视为无利息。
                \end{enumerate}
          \item 诉讼地位。
                \begin{enumerate}
                  \item 实际施工人以转包人、违法分包人为被告起诉的，应当受理。
                  \item \zd{以发包人为被告主张权利的，应当追加转包人 \hz 违法分包人为本案第三人}，判决发包人在欠付建设工程价款范围内承担责任。
                        本质是债权人代位权之诉。
                  \item 工程质量。发包人可以总承包人、分包人和实际施工人为共同被告提起诉讼，承担责任。
                  \item 法院可以收缴当事人已经取得的非法收入。
                \end{enumerate}
          \item 建设工程优先受偿权 \yjt \zd{因为是建设工程施工合同的承包人}。
                \begin{enumerate}
                  \item \zx{仅限于建设工程价款本身}（不含利息、违约金、损害赔偿金）。
                  \item \bs{应当给付工程价款之日起 18 个月除斥期间}。
                  \item \zd{就建设工程款对建设工程主张优先权}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
