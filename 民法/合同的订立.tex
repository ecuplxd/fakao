\section{合同的订立}
\begin{enumerate}
  \item 偶尔考到。要约和承诺。
  \item \zd{意思表示 = 意思 + 表示}。
        \begin{enumerate}
          \item 意思（内部/主观）。目的意思 \yjt 内容具体确定；效果意思 \yjt 受法律约束。
          \item 表示（外部/客观）。行为。明示 \yjt 书面、口头；默示 \yjt 积极/履行治愈规则、消极。
          \item 书面形式。能够以有形的方式表现所载的内容，并且可以随时调取查用。电子合同。
        \end{enumerate}
  \item 要约。意思表示。
        \begin{enumerate}
          \item 类型。
                \begin{enumerate}
                  \item 商业广告。原则上要约邀请，内容具体确定变成要约。
                  \item 自动售货机，现货要约。
                \end{enumerate}
          \item 生效。\zd{相对人知道即可}；\zd{到达主义}，不要求知悉（送信）。
          \item 撤回。尚未生效的要约，撤回意思表示；到达之前。
          \item 撤销。已生效未获承诺，到达之后承诺之前。\zd{不得撤销 \yjt 定了期限；有明示不反悔；交易习惯}。
          \item 失效。拒绝要约；被撤销；\zd{期满不答；内容实质变更}。
        \end{enumerate}
  \item 承诺。完全同意意思表示。
        \begin{enumerate}
          \item 只能撤回。因为合同已成立。
          \item 承诺迟延。受要约人超过承诺期限发出承诺 \yjt 新要约 \hz 反要约。
          \item 承诺迟到。原则有效，除非要约人及时反对。
        \end{enumerate}
  \item 成立的时间和地点。考的少。
        \begin{enumerate}
          \item 要式。签章、按指印时。
          \item 要物。交付标的物时。
          \item 非要物。承诺到达时。
          \item 地点。最后一方按指印地方。
        \end{enumerate}
  \item 合同的内容。
        \begin{enumerate}
          \item 必备条款。当事人、标的物、\zd{数量}。
          \item 主要条款。决定合同类型。
          \item 争议解决条款。\zd{独立性}。
          \item \zd{格式条款}。考的多。重复使用；预先拟定；未与对方协商。
                \begin{enumerate}
                  \item 提示和说明义务。重大利益条款。违反视为条款不存在。
                  \item 人身无价，免除无效。
                  \item 不合理免除或减轻责任；加重对方责任，限制对方权利。
                  \item 采用不利于格式方的解释。\al{解释：捆}。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
