\section{债的法定分类体系}
\begin{enumerate}
  \item 意定之债。
        \begin{enumerate}
          \item \kw{单方允诺}之债 = \zd{单方意思表示 + 设定义务 + 相对人取得权利}。\al{悬赏广告、寻物启事、假一罚十}。
                \begin{enumerate}
                  \item 一般向社会上不特定的人发出，但\bs{也可单独对特定对象作出}。
                  \item \zd{公告发布时生效}。
                  \item \zd{单方允诺说}（考试采用） \yjt 对拾得人有利。要约说 \yjt 失主。
                \end{enumerate}
          \item 合同之债。
        \end{enumerate}
  \item 自然之债。
        \begin{enumerate}
          \item 已过诉讼时效之债。债权本身仍存在的，只是\zd{丧失}了法院的\zd{强制执行力}。
          \item 违法之债。\al{赌债、毒资、嫖资}。
          \item 彩礼。\bs{未办理结婚登记、未共同生活、婚期给付导致给付人生活困难}可要求返还。
          \item 限定继承超出遗产继承范围以外之债。\al{父债子还}。
        \end{enumerate}
  \item 法定之债。
        \begin{enumerate}
          \item 缔约过失之债。
          \item 无因管理之债。事实行为 \yjt 不要求行为能力。\al{学雷锋做好事、见义勇为、英雄救美、未通知的代为清偿}。
                \begin{enumerate}
                  \item 成立要件。
                        \begin{enumerate}
                          \item 没有法定 \hz 约定义务。\al{拾得遗失物 \cuo 有法定的返还义务}。
                          \item 主观。\zd{避免他人受损}的意思（纯为自己 \cuo，适当兼顾自己 \dui）。
                                \al{图谋私利、认为有利可图 \cuo。唯恐大火蔓延自家受损 \dui}。
                          \item 客观。实施了管理他人（不能狭义理解为自然人）事务的行为（\zd{不看结果}，希望大家互帮互助）。
                                \al{丁见门前井盖被盗致路人跌伤，遂自购一井盖铺上 \yjt 市政部门}。
                          \item 不违反本人意思。否则构成\zd{不当无因管理}（本质是侵权行为）。
                                \al{10 块 1 斤的鱼，卖 1 块；丙\xhx{明知}诉讼时效已过，仍帮甲向乙还钱}。
                          \item 不违背公序良俗。\al{抢救意图自杀的人}。
                          \item vs 好意施惠。\al{甲扫雪，顺便将邻居乙小轿车上的积雪清扫干净}。
                          \item vs 误信管理。纯粹为自己。\al{喜当爹、误把他人家的牛当成自己家的牛而饲养}。
                        \end{enumerate}
                  \item 管理人 3 个权利。\al{3 岁小明头被卡在护栏上}
                        \begin{enumerate}
                          \item \zd{没有报酬请求权} \yjt 拿报酬 \yjt 构成不当得利。
                          \item 必要费用请求权。\al{小强打车将小明送医}。
                          \item 所负债务请求权。\al{小强将 2 楼空调围栏踩坏}。
                          \item 所受损害请求权。\al{小强托举小明手臂被划伤}。
                        \end{enumerate}
                  \item 3 个义务。\zd{方法有利，不得擅自中断}；及时通知、等待指示、及时转交；报告。\al{送佛送到西}。
                \end{enumerate}
          \item 不当得利之债。\bs{没有法律原因的财产损益变动}。1 个选项。
                \begin{enumerate}
                  \item 成立要件。
                        \begin{enumerate}
                          \item \zd{已经没有}法定 \hz 约定原因。\zd{为履行道德义务的不算}。\al{帮还钱、还两次、明知/误认的非债清偿}。
                          \item 一方获益。表现为取得所有、使用。\al{交警代收 6W 交通事故赔偿金、租房结果是违建}。
                          \item \zd{一方受损。主动放弃不算}。\yi \zd{强迫得利} \yjt 故意让自己受损。\er \zd{反射利益} \yjt 有人受益无人受损。
                          \item 存在因果关系。太复杂不考。
                        \end{enumerate}
                  \item \bs{返还范围}。
                        \begin{enumerate}
                          \item 善意。“现存”利益。
                                \al{甲购买一台电脑，
                                  供货商乙的配送员错送至丙家，丙的家人误以为是丙公司送的中秋礼物而签收。
                                  当晚丙家中失火导致该电脑被毁}。
                          \item 恶意。所受利益 + 赔偿损失。\al{工资多出 2W，1W 出借，约定利息 500，1W 投入股市获利 2000 \yjt 返还 2W及其孳息}。利用不当得利取得的其他利益，\zd{扣除劳务管理费}用后，应当予以收缴。
                        \end{enumerate}
                  \item 分类。有/\zd{没合同} \yjt 给付型/\zd{非给付型不当得利}。
                  \item 隐晦的在考不当得利。\al{甲应适当让利、请求返还 xx 元}。
                \end{enumerate}
          \item 侵权之债。后面侵权部分。
        \end{enumerate}
\end{enumerate}
