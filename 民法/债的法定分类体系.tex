\section{债的法定分类体系}
\begin{enumerate}
  \item 意定之债。
        \begin{enumerate}
          \item 单方允诺之债。公告发布时生效。\al{悬赏广告；寻物启事；假一罚十}。
                \begin{enumerate}
                  \item 单方允诺说 \yjt 对拾得人有利。
                  \item 要约说 \yjt 失主。
                \end{enumerate}
          \item 合同之债。
        \end{enumerate}
  \item 自然之债。
        \begin{enumerate}
          \item 已过诉讼时效之债。债权本身是存在的，只是\zd{丧失}了法院的\zd{强制执行力}。
          \item 违法之债。\al{赌债、毒资、嫖资}。
          \item 彩礼。\zd{未办理结婚登记；未共同生活；婚期给付并导致给付人生活困难}。
          \item 限定继承超出遗产继承范围以外之债。没考过。\al{父债子还}。
        \end{enumerate}
  \item 法定之债。
        \begin{enumerate}
          \item 缔约过失之债。
          \item \zd{无因管理之债}。事实行为。\al{学雷锋做好事；见义勇为；英雄救美}。
                \begin{enumerate}
                  \item 成立要件。
                        \begin{enumerate}
                          \item 没有法定 \hz 约定义务。
                          \item 主观。避免他人受损失的意思（纯粹为自己不算）。\al{喜当爹；图谋私利；认为有利可图}。
                          \item 实施了管理他人事务的行为。\zd{不看效果}（希望大家互帮互助），区分好意施惠。
                          \item 不违反本人意思。否则构成\zd{不当无因管理}（本质是侵权行为）。\al{10 块 1 斤的鱼，1 块卖出}。
                          \item 不违背公序良俗。\al{抢救意图自杀的人}。
                        \end{enumerate}
                  \item 3 个权利。必要费用请求权、所付债务请求权、所受损害请求权。\zd{没有报酬请求}。
                  \item 3 个义务。\zd{方法有利，不得擅自中断}。\al{送佛送到西}。及时通知；等待指示；及时转交和报告。
                \end{enumerate}
          \item \zd{不当得利之债}。没有法律原因的财产损益变动。1 个选项。
                \begin{enumerate}
                  \item 成立要件。
                        \begin{enumerate}
                          \item 无法定 \hz 约定原因。\zd{为履行道德义务的不算}。\al{帮还钱；还两次；明知/误认的非债清偿}。
                          \item 一方获益。
                          \item 一方受损。主动放弃不算。\zd{强迫得利} \yjt 故意让自己受损；\zd{反射利益} \yjt 有人受益无人受损。
                          \item 存在因果关系。太复杂不考。
                        \end{enumerate}
                  \item 善意 \yjt 返还现存利益；恶意 \yjt 返还所受利益 \yjt 依法赔偿损失。
                  \item 误信管理。纯粹为自己。\al{误把他人家的牛当成自己家的牛而饲养}。
                \end{enumerate}
          \item 侵权之债。
        \end{enumerate}
  \item 善意的只负返还现存利益的义务。恶意不受保护，统统返还。
\end{enumerate}
