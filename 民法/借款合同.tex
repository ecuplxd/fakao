\section{借款合同}
\begin{enumerate}
  \item 民间借贷。\zx{民间 = 没有金融机构参与 \yjt 机构间不适用}。\zd{实践性}合同。B2B、B2C、C2C。1 个选项。
        \begin{enumerate}
          \item 利息问题。
                \begin{enumerate}
                  \item \bs{未约定利息视为无利息，但不影响加收逾期利息}。
                  \item 约定不明确 \yjt 补充协议。
                  \item 借款\zd{利息}、逾期利息等 \zx{\xydy 4 倍 LPR}。
                  \item \zd{年利率} \xydy 24\% 支持，\dydy 36\% 超出部分无效（不当得利），不予支持。
                \end{enumerate}
          \item \zx{法定无效}。司法解释列了很多。强公主意恶 + 朴素价值观。
                \begin{enumerate}
                  \item 来钱手段\zd{非法}。\al{套取、骗取、非法吸收存款}。
                  \item \zd{无主体资格}。\al{放贷资格}。
                  \item 出借人\zd{事先知道 \hz 应当知道}借款人借款\zd{用于非法犯罪活动仍提供}借款。
                \end{enumerate}
          \item 成立。贷款人提供借款时。现金/转账 \yjt 借款人收到时/到达借款人账户时。
        \end{enumerate}
  \item 借款人未按照约定的借款用途使用借款。\zx{停止发放、提前收回、解除合同}。
  \item 让与担保。将担保标的物的所有权等权利转移于担保权人。\bs{名为让与（买卖合同），实为担保}。
        \begin{enumerate}
          \item \al{甲向乙借款 100W，甲房子抵押，乙害怕房子贬值太快，要求将房子登记在自己名下}。
          \item \bs{买卖合同}是双方通谋虚假意思表示 \yjt \bs{无效} \yjt \bs{所有权不发生变动 \yjt 物权变动有因性}。
          \item 标的物。\bs{动产、不动产、汇票、股权、应收账款}让与担保 \yjt \bs{类推适用}对应标的物的担保规则。
          \item 顺序问题。先/\zd{后让与担保} \yjt 有/\zd{没有登记、交付} \yjt 有/\zd{没有权力外观} \yjt 有/\zd{没有优先受偿权}。
          \item 做题。\bs{先发生借款行为，后发生买卖行为 \yjt 肯定是让与担保}。\al{售后回购}。
          \item 让与担保（大圈，有效）vs 流押流质（小圈，无效）。vs 代物清偿（借期届满后）。
                \begin{enumerate}
                  \item 都是当事人约定。
                  \item 让与担保协议合法有效、流押流质无效、代物清偿协议合法有效。
                  \item 借期届满前。让与、流押/质。
                  \item 代物清偿跑到借期届满前 = 流押/质。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
