\section{借款合同}
\begin{enumerate}
  \item 民间借贷（没有金融机构参与）。实践性合同。分类。b2b、b2c、c2c。1 个选项。
        \begin{enumerate}
          \item 未约定利息视为无利息。
          \item 借款利息、逾期利息 <= 4 倍 LPR。
          \item 没有约定借款利息，不影响加收逾期利息。
          \item 出借人事先知道 \hz 应当知道借款人借款用于非法犯罪活动仍提供借款的，应当认定合同无效。
          \item 自贷款人提供借款时成立。现金 \yjt 借款人收到时；转账 \yjt 到达借款人账户时。
        \end{enumerate}
  \item 让与担保。将担保标的物的所有权等权利转移于担保权人。\zd{名为让与（买卖合同），实为担保}。
        \begin{enumerate}
          \item \al{甲向乙借款 100W，甲房子抵押，乙害怕房子贬值太快，要求将房子登记在自己名下}。
          \item 标的物。动产、不动产、股权。
          \item \zd{物权变动有因性}。买卖合同是双方通谋的虚假意思表示，本身无效，所有权不发生变动。
          \item 先/后让与担保 \yjt 先/没有完成公示 \yjt 有/没有优先受偿权。
          \item 做题。先发生借款行为，后发生买卖行为 \yjt 肯定是让与担保。
          \item 售后回购。常考点。
          \item vs 代物清偿 \yjt 届满后。
        \end{enumerate}
  \item 借款人未按照约定的借款用途使用借款。停止发放、提前收回、解除合同。
\end{enumerate}
