\section{借款合同}
\begin{enumerate}
  \item 民间借贷（没有金融机构参与）。\zd{实践性}合同。分类。b2b、b2c、c2c。1 个选项。
        \begin{enumerate}
          \item 利息问题。
                \begin{enumerate}
                  \item 未约定利息视为无利息。
                  \item 没有约定借款利息，不影响加收逾期利息。
                  \item 借款\zd{利息}、逾期利息等 \zd{<= 4 倍 LPR}。
                  \item \zd{年利率} <= 24\% 支持，>= 36\% 超出部分无效，不予支持。
                \end{enumerate}
          \item 法定无效。出借人事先知道 \hz 应当知道借款人借款\zd{用于非法犯罪活动}仍提供借款
          \item 成立。贷款人提供借款时。现金/转账 \yjt 借款人收到时/到达借款人账户时。
        \end{enumerate}
  \item 借款人未按照约定的借款用途使用借款。停止发放、提前收回、解除合同。
  \item 让与担保。将担保标的物的所有权等权利转移于担保权人。\zd{名为让与（买卖合同），实为担保}。
        \begin{enumerate}
          \item \al{甲向乙借款 100W，甲房子抵押，乙害怕房子贬值太快，要求将房子登记在自己名下}。
          \item 标的物。\zd{动产、不动产、股权}让与担保。\zd{类推适用}对应标的物的担保规则。
          \item \zd{买卖合同}是通谋的虚假意思表示，本身\zd{无效}，\zd{所有权不发生变动 \yjt 物权变动有因性}。
          \item \zd{先/后让与担保} \yjt 先/没有登记 \yjt \zd{有/没有权力外观} \yjt 有/没有优先受偿权。顺序问题。
          \item 做题。\zd{先发生借款行为，后发生买卖行为 \yjt 肯定是让与担保}。
          \item 售后回购。常考点。
          \item vs 代物清偿（借期届满后）。
          \item 让与担保（大圈，有效）vs 流押流质（套小圈，无效）。
        \end{enumerate}
\end{enumerate}
