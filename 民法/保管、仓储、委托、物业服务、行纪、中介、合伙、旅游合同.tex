\section{保管、仓储、委托、物业服务、行纪、中介、合伙、旅游合同}
\begin{enumerate}
  \item 不是重点。
  \item 保管。
        \begin{enumerate}
          \item 李杏英案。
          \item \zd{去保管人处从事购物、就餐、住宿等活动，将物品存放在指定场所的，视为保管}。新增。
          \item 双方的任意解除权 \yjt 随时领取。
          \item 留置权。
        \end{enumerate}
  \item 仓储。没考过。就是保管合同；一定是有偿的。
  \item 委托。常考合同。强烈的人身信赖。许多合同的基础关系，一般合同。
        \begin{enumerate}
          \item 可书面可口头；可有偿可无偿；双方任意解除权。
          \item 过错责任，按份责任。
          \item 间接代理。代理人以自己名义去实施民事法律行为。没考过。
                \begin{enumerate}
                  \item 显名的\blh。没啥好考的。
                  \item 隐名的间接代理。\al{甲委托乙买茶叶，乙自己名义跟丙订茶叶，却没付钱给丙}。
                        \begin{enumerate}
                          \item 代理人披露义务。利益承受理论 + 合同相对性 \yjt 择一选择（简单形成权）。
                          \item 被代理人介入权。\al{甲给了钱，没收到茶叶}。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 物业服务。书面。
        \begin{enumerate}
          \item 和业主区分所有权结合考；前期是开发商代表业主签。
          \item \zd{公开做出的有利服务承诺，为合同组成部分}；不得以暴制暴催收物业费。
        \end{enumerate}
  \item 行纪。区别：商事合同；仍是间接代理；费用负担、报酬有约从约，无约行寄人自担/不能多要。
  \item 居间/中介。报告中介、媒介中介。
        \begin{enumerate}
          \item \zd{跳单}。新增考点。接受了中介人的服务；利用中介人提供的信息机会 \hz 媒介服务；绕开中介人。
        \end{enumerate}
  \item 合伙。民事合伙。同商法。
        \begin{enumerate}
          \item 终止前，不得请求分割合伙财产。
          \item 合伙事务的执行问题。监督权、异议权。
          \item 利润分配和亏损分担，约定 \yjt 协商 \yjt 实缴比例 \yjt 平均分。
          \item 财产份额转让，一致同意。
        \end{enumerate}
  \item 旅游。在司法解释里。旅游者权利义务的转让；旅游经营者不得擅自转让。
\end{enumerate}
