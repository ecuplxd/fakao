\section{保管、仓储、委托、物业服务、行纪、中介、合伙、旅游合同}
\begin{enumerate}
  \item 不是重点。
  \item 保管。\al{李杏英案}。
        \begin{enumerate}
          \item 去保管人处从事\zd{购物、就餐、住宿}等活动，将物品存放在指定场所的，视为保管。新增。
          \item 无期限。双方任意解除权。
          \item 留置权。
        \end{enumerate}
  \item 仓储。就是保管合同，一定是有偿的。没考过。
  \item 委托。强烈的人身信赖。委托合同是许多合同的基础关系。常考合同。
        \begin{enumerate}
          \item 可书面可口头、可有偿可无偿、双方任意解除权。
          \item 受托人。有偿的 \yjt 过错按份。无偿的 \yjt 故意 \hz 重大过失。\zd{过错 \,\,\bdy 故意、过失，两回事}。
                \al{该律所存在故意 \hz 重大过失，要对败诉承担赔偿责任 ×}。
          \item 间接代理。见代理制度部分。
        \end{enumerate}
  \item 物业服务。书面。
        \begin{enumerate}
          \item 前期是开发商代表业主签。和业主区分所有权结合考。
          \item \zd{公开做出的有利服务承诺，为合同组成部分}。
          \item 不得以暴制暴催收物业费、只能找对应欠缴的业主。
          \item 解聘提前有约从约天 \yjt\, 60 天书面通知。
        \end{enumerate}
  \item 行纪。行纪人\zd{以自己名义}为委托人\zd{从事贸易活动}。本质是间接代理。
        \begin{enumerate}
          \item 费用/报酬有约从约，无约行纪人自担/不能多要。\al{约定每公斤售价 2 元，报酬为价款 5\%，以 2.5 卖出}。
          \item 瑕疵找行纪人。\al{甲委托乙寄售行出售仪器，如仪器出现质量问题，丙应向乙主张违约责任}。
          \item vs 商事合同。
        \end{enumerate}
  \item 居间/中介。报告中介、媒介中介。
        \begin{enumerate}
          \item 费用自担。
          \item \zd{跳单}。新增考点。
                \begin{enumerate}
                  \item 接受了中介人的服务。
                  \item 利用中介人提供的信息机会 \hz 媒介服务。
                  \item 绕开中介人。
                \end{enumerate}
        \end{enumerate}
  \item （民事）合伙。
        \begin{enumerate}
          \item 题目有\zd{“合伙协议”} \yjt 商法里的合伙企业。
        \end{enumerate}
  \item 旅游。在司法解释里。旅游者权利义务可自行转让；旅游经营者不得擅自转让（否则连带）。
\end{enumerate}
