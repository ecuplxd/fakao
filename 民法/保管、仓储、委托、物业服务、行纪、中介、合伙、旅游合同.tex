\section{保管、仓储、委托、物业服务、行纪、中介、合伙、旅游合同}
\begin{enumerate}
  \item 不是重点。
  \item 保管。\al{李杏英案}。
        \begin{enumerate}
          \item 去保管人处从事\zd{购物、就餐、住宿}等活动，将物品存放在指定场所的，视为保管。新增。
          \item 双方的任意解除权 \yjt 随时领取。
          \item 留置权。
        \end{enumerate}
  \item 仓储。就是保管合同，一定是有偿的。没考过。
  \item 委托。强烈的人身信赖。委托合同是许多合同的基础关系。常考合同。
        \begin{enumerate}
          \item 可书面可口头、可有偿可无偿、双方任意解除权。
          \item 过错责任、按份责任。
          \item 间接代理。代理人以自己名义去实施民事法律行为。没考过。
                \begin{enumerate}
                  \item 显名的间接代理。没啥好考的。
                  \item 隐名的间接代理。\al{甲委托乙买茶叶，乙自己名义跟丙订茶叶，却没付钱给丙}。
                        \begin{enumerate}
                          \item 代理人披露义务。利益承受理论 + 合同相对性 \yjt 择一选择（简单形成权）。
                          \item 被代理人介入权。\al{甲给了钱，没收到茶叶}。
                        \end{enumerate}
                \end{enumerate}
        \end{enumerate}
  \item 物业服务。书面。
        \begin{enumerate}
          \item 前期是开发商代表业主签。和业主区分所有权结合考。
          \item \zd{公开做出的有利服务承诺，为合同组成部分}。
          \item 不得以暴制暴催收物业费。
        \end{enumerate}
  \item 行纪。本质是间接代理。费用负担、报酬有约从约，无约行寄人自担/不能多要。vs 商事合同。
  \item 居间/中介。报告中介、媒介中介。
        \begin{enumerate}
          \item \zd{跳单}。新增考点。
                \begin{enumerate}
                  \item 接受了中介人的服务。
                  \item 利用中介人提供的信息机会 \hz 媒介服务。
                  \item 绕开中介人。
                \end{enumerate}
        \end{enumerate}
  \item （民事）合伙。参看商法合伙企业部分。
  \item 旅游。在司法解释里。旅游者权利义务可自行转让；旅游经营者不得擅自转让。
\end{enumerate}
