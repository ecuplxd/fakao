\section{侵权责任的基本原理}
\begin{enumerate}
  \item 违约、缔约过失、侵权（无合同）3 大责任。
  \item 民事权益 = 权利 + 利益。
  \item 第三人侵害债权制度。排除债权 \yjt \zd{债权侵权，按违约处理}。避免一个行为永远处于被追责状态。
        \al{甲乙共有一台机器，卖得 10W，约定暂存在乙的账户。后该账户被执行，致乙不能按期返还甲的款项 \yjt 违约}。
  \item 侵权人、被侵权人/受害人。\zd{做题先找受害人}。
  \item 归责原则。请求行为人\zd{承担责任的理由}。我国\zd{二元归责}。
        \begin{enumerate}
          \item 过错责任。侵害行为、损害结果、因果关系、有过错（主观故意 \hz 过失）。
                \al{马大姐小区\xhx{倒垃圾}（日常生活行为）时，\xhx{不慎}（主观无过错）洒落一袋厨余垃圾在路边，\xhx{未作清理}（很难认定为加害行为），流浪狗围上抢食，拿着香肠的小学生甲路正巧路过被狗咬伤}。
          \item 无过错责任/严格责任。侵害行为、损害结果、因果关系。
                \begin{enumerate}
                  \item \al{违约责任、承运人人身损害、承运人托运物品}。
                  \item \al{环境污染、监护人、用工、车撞人、高度危险、饲养动物、生产者}。
                \end{enumerate}
          \item 公平补偿。\zd{前提系双方均无过错}。
                \begin{enumerate}
                  \item \al{请客吃饭无过错、添附、离婚经济补偿、紧急避险}。
                  \item \al{交通事故、车撞车、高空抛物、帮工人被他人侵权、建筑农民工}。
                \end{enumerate}
        \end{enumerate}
  \item 侵权责任是个弱化的刑法。vs 刑法过错。
        \begin{enumerate}
          \item 故意。题目没说就不是。
          \item 重大过失、一般过失。看身份。\yi 专业人员 \yjt 重大过失。\er 普通民众 \yjt 一般过失。
        \end{enumerate}
  \item 侵害行为。包括违法行为、合法行为。都没有过错 \yjt \zd{公平补偿}。
  \item 共同侵权。\al{三小孩捡起石子向轿车扔去}。
        \begin{enumerate}
          \item 主观共同、客观共同。\al{甲银行卡被盗刷，银行和盗刷者不是共同侵权}。
          \item 共同危险行为。每个人都实施了危险行为。\zd{必须指明具体侵权人才能免责}。
          \item \zd{无意思联络的数人侵权行为}。\yi 竞合。A \hz\, B = C \yjt 连带。\er 结合。A + B = C \yjt 按份。
        \end{enumerate}
  \item \zd{\blx{免责事由}}。基本同刑法违法阻却事由。\zd{免责 \,\,\bdy 全免}，免部分 \hz 全部。
        \begin{enumerate}
          \item 意外事件。主客观不一致 + 介入因素异常。\al{香蕉噎死小孩}。
          \item 正当防卫。
          \item 紧急避险。险情谁引起找谁；自然原因适当补偿。\al{避让不及}。
          \item 与有过失/过失相抵。受害人也有过错。\al{甲超速，乙闯红灯}。
          \item 自甘冒险/自担风险。\al{游泳、骑马、爬山、体育活动、横穿正在进行比赛的球场}。
          \item 自助行为。方法适当 + 限度必要 \yjt 合法行为。\zd{霸王餐扣人肯定非法，扣物不叫行使留置权}。
        \end{enumerate}
  \item 根据各责任主体的共同关系，对共同\zd{责任承担方式}进行分类。
        \begin{enumerate}
          \item 按份。\al{共同共有内部、租赁装饰装修扩建、有偿的委托合同、无意思联络的数人侵权、劳务派遣方}。
          \item 补充。特殊的按份，强调顺序性。
                \begin{enumerate}
                  \item \al{担保无效，一般保证人存在过错}。
                  \item \al{被监护人有独立财产、安保义务人、教育机构、xx 使用人/管理人}。
                \end{enumerate}
          \item 连带。
                \begin{enumerate}
                  \item 一因一果，行权任意选择，但最终就一个人在承担责任。
                  \item 部分的被免除，其他连带人自动免除对应比例。
                  \item 总结。
                        \begin{enumerate}
                          \item \al{恶意代理、按份共有共同侵权、债务加入、连带保证、未经同意转让旅游合同、无意思联络的数人侵权、盗脏车链条、建筑质量}。
                          \item 无限连带。\al{非法人组织、夫妻共同财产}。
                          \item 扩大部分连带。\al{网络服务提供者、产品的警示与召回}。
                        \end{enumerate}
                \end{enumerate}
          \item 不真正连带。城门失火，殃及池鱼。\al{帮工}。
                \begin{enumerate}
                  \item 医药器械。药品上市许可持有人、生产者、血液提供机构、医疗机构。
                \end{enumerate}
        \end{enumerate}
\end{enumerate}
