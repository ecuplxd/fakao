\section{侵权责任的基本原理}
\begin{enumerate}
  \item 违约、缔约过失、侵权三大责任。
  \item 民事权益 = 权利 + 利益。
  \item 第三人侵害债权制度：排除债权。\zd{债权侵权通过违约处置}。一个行为永远被追责。
  \item 侵权人、被侵权人/受害人，\zd{做题先找受害人}。
  \item 归责原则，\zd{请求行为人承担责任的理由}。我国\zd{二元归责}。
        \begin{enumerate}
          \item 过错责任。侵害行为、损害后果、因果关系、有过错。
          \item 无过错责任/严格责任。没过错也承担。侵害行为、损害后果、因果关系。\zd{环境污染；监护人；车撞人}。
          \item 公平补偿。
        \end{enumerate}
  \item 侵权责任是个弱化的刑法。和刑法过错的区别：
        \begin{enumerate}
          \item 故意，题目没说就不是。
          \item 重大过失。
          \item 一般过失。\zd{看身份，专业人员 \yjt 重大；普通民众 \yjt 一般}。
        \end{enumerate}
  \item 侵害行为包括违法行为、合法行为。\al{交通事故；车撞车；高空抛物}。都没有过错 \yjt \zd{公平补偿规则}。
  \item 共同侵权。\al{三小孩捡起石子向轿车扔去}。
        \begin{enumerate}
          \item 主观共同；客观共同。
          \item 共同危险行为。每个人都实施了危险行为，\zd{必须指明具体侵权人才能免责}。
          \item \zd{无意思联络的数人侵权行为原因的结合}，A \hz\, B = C \yjt 连带；A + B = C \yjt 按份。
        \end{enumerate}
  \item 免责事由。基本同刑法违法阻却事由。\zd{免责免责，不是全部免掉}，部分 \hz 全部。
        \begin{enumerate}
          \item 意外事件。香蕉案。
          \item 正当防卫。
          \item 紧急避险。险情谁引起找谁；自然原因适当补偿。
          \item 与有过失/过失相抵。受害人也有过错。\al{甲超速，乙闯红灯}。
          \item 自甘冒险/自担风险。\al{游泳；骑马；爬山；体育活动}。
          \item 自助行为。霸王餐；方法适当，限度必要 \yjt 合法行为。\zd{扣人肯定非法；扣物不叫行使留置权}。
        \end{enumerate}
  \item 根据各责任主体的共同关系，对共同责任进行分类。
        \begin{enumerate}
          \item 按份。
          \item 连带，一因一果，行权任意选择，但最终就一个人在承担责任。
          \item 不真正连带，殃及池鱼。
          \item 补充责任，特殊的按份，顺序性。
        \end{enumerate}
\end{enumerate}
