\section{债的学理分类体系}
\begin{enumerate}
  \item 了解一下，考的少。
  \item 主体多少。
        \begin{enumerate}
          \item 单一之债。
          \item 多数之债。\zd{共同侵权，按份\hz 连带}。
                \begin{enumerate}
                  \item 按份之债。
                  \item 连带之债。
                \end{enumerate}
        \end{enumerate}
  \item 标的物。财物之债、劳务之债（人身依附性，不得强制执行）、货币之债。
  \item 标的物可选择性。简单之债、选择之债。
\end{enumerate}
