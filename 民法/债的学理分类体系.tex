\section{债的学理分类体系}
\begin{enumerate}
  \item 了解一下，考的少。
  \item 主体多少。
        \begin{enumerate}
          \item 单一之债。
          \item 多数之债。按份之债、连带之债。典型\al{共同侵权，按份\hz 连带}。
        \end{enumerate}
  \item 标的物不同。
        \begin{enumerate}
          \item 财物之债。\yi 特定之债。\er 种类之债。
          \item 劳务之债。人身依附性，不得强制执行。
          \item 货币之债。
        \end{enumerate}
  \item 标的物可选择性。简单之债、选择之债。
\end{enumerate}
